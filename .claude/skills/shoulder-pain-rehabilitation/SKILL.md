## いつ使うか

胸のトレーニング（ペックフライ・ベンチプレス等）後に肩を痛めた時、または外転（横に上げる）時にコリッという引っ掛かり感・詰まり感が出る時に参照する。

Part111 の統合により、肩以外の「痛む場所と原因の場所が違う」ケースも扱う。以下のいずれかに当てはまるときに参照する。

- 肩の外転・前方に痛みや詰まりが出る（Part123 / Part111 トラブル①）
- 片側の僧帽筋だけが慢性的に張る・サイドレイズで先に疲れる（Part111 トラブル②）
- 前屈や運搬で片側の腰痛が出る（Part111 トラブル③）
- 痛む場所をほぐしても戻ってしまう・再発を繰り返す

## 評価ステップ（ヒアリング〜触診）

### 1. ヒアリング（15〜20分）

| 確認項目 | 目的 |
|---|---|
| いつ・どの種目・どのタイミングで痛めたか | 原因の特定 |
| フォームを最近変えたか | 過剰伸展・パッキング抜けの確認 |
| 他の部位（肘など）の既往歴 | 連動痛との切り分け |
| 安静時の痛みの有無 | 炎症の有無確認 |

### 2. 動作テスト

- **外転テスト**：2kgを持って横に上げ、コリッがどの角度で出るかを確認
- **屈曲テスト**：前方向には問題がないか確認（フロントはOKで外転のみNGが典型パターン）
- **回旋テスト**：回旋で出るかどうか確認

### 3. 触診

- 結節間溝（上腕二頭筋長頭腱）に直接的な痛みがあるかを確認
- 広背筋停止部（脇の下・前鋸筋周辺）・大円筋のコリコリ（硬結）を探る

---

## 改善アプローチ：相反抑制の活用

**原理**：広背筋・大円筋を最大収縮させることで相反抑制（拮抗筋が緩む生理反射）が起き、前方変位した上腕骨頭が求心位に戻り、詰まりが解消される。

### セルフケア（一人でできる方法）

```
1. ラットプルダウン（軽い重量）でスクイーズを最大にかける
   → 目的は重量を引くことではなく広背筋の最大収縮を起こすこと
   
2. バランスボールのプッシュ等で前鋸筋を活性化
   → 肩甲骨周りの安定性を再構築
   
3. メイントレーニングに移行
```

### トレーナーが行う場合

1. 広背筋の停止部（脇の下）を触察しコリコリを探る
2. くすぐったがり（過敏）の場合は強圧を避け、自動運動の最大収縮に切り替える
3. **最大収縮の誘導手順**：
   - 肩甲骨の下角を下方向（下制方向）に誘導
   - 「広背筋を寄せて」と指示しながら深呼吸
   - 吐くタイミングでリラックスさせる
4. 改善確認後、外転テストを再実施して効果を確かめる

## よくあるNG

| NG行動 | 理由 |
|---|---|
| 痛い前方だけをほぐす | 骨頭位置をずらしている後背部のテンションが根本原因 |
| 無理に可動域を広げる | 肩甲骨パッキングが保てない範囲のストレッチは怪我に直結 |
| ショルダーパッキングを外したまま動作する | 骨頭が前方変位し挟まりが再発する |

## 重要な気づき

「胸の動きが悪いのに胸をほぐすのではなく、動きを制限している後ろ側（広背筋）のテンションを緩めると肩の動きが正しい位置に戻る」

## 現場で多い3大トラブル（Part111）

現場で遭遇頻度が高い3つのトラブル。いずれも**症状の出る場所と、原因のある場所が違う**。

| トラブル | 症状の出る場所 | 原因のある場所 |
|---|---|---|
| ① 肩前方の痛み | 右肩の前（利き手側） | 肩の後ろ。外旋筋群が働いていない |
| ② 僧帽筋の張り | 右の首すじ〜肩の上 | 下側。右の腰方形筋・広背筋が肩を引き下げている |
| ③ 左の腰痛 | 左の腰 | 右の股関節。屈曲がうまく出ていない |

- 利き手側（右）に出やすいのが①②、左に出やすいのが③という左右差がある
- 3つとも「痛む場所を触っても戻る」パターン。触る場所を変えるのが解決の第一歩
- 既存の Part123（肩外転時の詰まり）も同じ構造で、原因は前ではなく後ろの広背筋テンションにある

## トラブル①：肩前方の痛み（上腕二頭筋長頭腱の炎症）

**症状**：ベンチプレスや投球動作などで、右肩の前方に痛みや詰まり感が出る。

**機序**：

- 利き手（特に右腕）で力を込めるとき、肩が内側に巻く**内旋**の動きが強くなる
- 右肩が強く内旋して巻き肩になった状態で腕を上げたり後ろに引いたりすると、肩の前方にある肩峰と上腕二頭筋長頭腱がぶつかり、挟み込まれる（インピンジメント）
- 挟み込みが繰り返されることで長頭腱に炎症が起きる

**改善アプローチ**：

1. **前方のリリース** — 内旋して固まっている肩前方の筋の緊張を先に抜く
2. **外旋筋群の強化** — 肩を外側に開く裏側の筋、特にローテーターカフの一部である小円筋と三角筋後部を鍛える
3. 外旋筋が働くことで上腕骨が正しい位置に引き戻され、挟み込みが解消される

> 前方をほぐすだけで終わらせない。**弱い後ろを鍛えるところまでやって初めて再発が止まる。**

## トラブル②：僧帽筋の過度な張り

**症状**：サイドレイズなどで右の僧帽筋ばかりが先に疲れる、または常に右の首すじが張っている。

**機序（ここが最も誤解されやすい）**：

- 一見、僧帽筋が縮んで固まっているように見えるが、実際は**逆**
- 右の広背筋と腰方形筋が縮んで固まり、右肩全体を下に引っ張って落としている
- その結果、上の僧帽筋は**引き伸ばされた状態で常に耐えている**（過緊張）ため、パンパンに張る
- つまり張りの正体は短縮ではなく、伸張位で耐え続けている状態

**改善アプローチ**：

- 張っている僧帽筋をマッサージするのではなく、**右の腰方形筋・広背筋をリリースして緩めるのが先決**
- 右の肋骨や肩を引き上げ、左右の肩の高さ（アライメント）を正常な位置に戻す
- アライメントを戻してからトレーニングに入ることで、僧帽筋への異常な負荷が消え、正しく三角筋を使えるようになる

## トラブル③：左の腰痛（前屈・運搬時）

**症状**：体を前に倒した際（ルーマニアンデッドリフト、物を拾う動作など）に左の腰に痛みが出る。

**機序（左右が交差する）**：

- 左の腰が痛いとき、根本原因は右の股関節の屈曲がうまくできていないことにあるケースが多い
- 右の脊柱起立筋が過剰に働き、右の腸腰筋と内腹斜筋がサボっている
- 右側がうまく引けない（曲がらない）ため、左側が代償して体を支えようとし、左腰に負担が集中する

**改善アプローチ**：

- **右の腸腰筋を活性化させる** — 仰向けになり、足首（つま先）を上に向けた状態で、右膝を胸に近づけるように引き上げる
- 誰かに抵抗をかけてもらうとより効果的
- 右の股関節がしっかり引き込めるようになると、左右のバランスが整い、左腰への代償動作が消失する

> 痛い側（左）を評価しても原因は出てこない。**先に反対側の股関節の屈曲を見る。**

## 評価の原理：対角線と拮抗筋を見る

Part111 と Part123 に共通する核心は、**痛い場所に原因があるとは限らない**ということ。対角線上・拮抗筋側のバランスを評価することで、慢性的な痛みを根本から扱える。

- 肩の前が痛いなら、肩の後ろ（外旋筋群）が弱い
- 上の僧帽筋が張るなら、下（腰方形筋・広背筋）が引っ張っている
- 左の腰が痛いなら、右の股関節がうまく動いていない
- 胸の動きが悪いなら、後ろの広背筋がテンションで制限している（Part123）

**評価の順序**：症状の出ている場所を確認したら、次に触るのは反対側・拮抗筋側。痛む場所への介入は最後に回す。
