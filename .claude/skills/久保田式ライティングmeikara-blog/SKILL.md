# メイカラ式 ブログライティングスキル

## 基本：Webライティング6つのルール

文章を書く際は必ず以下を守る：

1. **文末表現の重複禁止**：「〜です。〜です。〜です。」はNG → 表現を変える
2. **一文を短くする**：読点で区切れる文は分割する
3. **接続詞の乱用禁止**：「そして」「また」「さらに」を連発しない
4. **「〜たり〜たり」はセットで**：「〜たり、〜したりする」と必ず対にする
5. **「〜こと」の重複禁止**：同一段落内で繰り返さない
6. **冗長表現の排除**：「〜することができる」→「〜できる」、「〜という」→削除

**指示代名詞（これ・それ・あれ）は避ける**：具体的な名詞を繰り返す。

---

## PREP法（文章の基本構造）

```
Point   → 結論（先に言う）
Reason  → 理由
Example → 具体例・データ
Point   → 再結論（念押し）
```

## SEO記事の書き方（第3章）

### ペルソナ設定の5ポイント

記事を書く前に必ず設定する：

| 項目 | 内容 |
|---|---|
| 悩み | 読者が抱えている具体的な問題 |
| 現状 | 今どういう状況にいるか |
| 知りたいこと | この記事で何を知りたいか |
| 前提知識 | どのくらい知識があるか |
| 読後理想状態 | 読み終わった後どうなっていてほしいか |

### タイトル・メタの法則

- **タイトル**：28〜32文字（検索結果で切れない長さ）
- **ディスクリプション**：150〜160文字（検索結果に表示される要約）
- キーワードはタイトルの前半に入れる

### 見出し設計の8ポイント

1. H2は記事の骨格 → 見出しだけ読んで記事の内容がわかるか確認
2. H3はH2の補足・深掘り
3. キーワードを自然に含める
4. 疑問形・数字を活用（「〇〇とは？」「3つの方法」など）
5. 抽象的な見出しはNG（「まとめ」「について」だけはダメ）
6. 検索意図を反映させる
7. 競合の見出しを参考にしつつ独自性を加える
8. 読者の知りたい順番に並べる

### 本文執筆の要点

- **正確さ最優先**：誤情報は信頼を失う
- **一次情報を使う**：体験談・独自調査・公式データ
- **キーワードは自然に**：詰め込み過ぎはNG
- **滞在時間を伸ばす**：図解・箇条書き・太字で読みやすく

## サイト設計の王道（第4章）

```
SEO記事（認知・集客）
    ↓
比較記事（検討層への誘導）
    ↓
商標記事（購買層のコンバージョン）
```

**商材選定の基準**：
- EPC（1クリック単価）100円以上
- 確定率80%以上
- 自分が良いと思える・有名・高単価

## 記事の型（第6章）

### 商標記事の構成（鉄板）

1. タイトル・基本情報
2. 体験談（**最重要** → ここに一次情報を集中させる）
3. 口コミ（XのポストかAmazon公式スクショで信頼性担保）
4. メリット
5. デメリット（正直に書く → 信頼性アップ）
6. こんな人におすすめ
7. 登録・購入方法（ステップ形式）
8. FAQ
9. まとめ

### 比較ランキング記事の目的

- **メインゴール**：各商標記事への内部リンク誘導
- 比較表で一覧性を出す
- 「総合1位」「初心者向け1位」など切り口を複数持つ

## セールスライティング（第7章）

### リンクの優先順位

```
テキストリンク > ボタンリンク（マイクロコピー付き）> バナーリンク
```

**マイクロコピー**とはボタン近くの補足文：
- 「無料で試せます」「登録30秒」「今だけ〇〇特典付き」

### 改善のやり方

- **要素は1つずつ変える**（ABテスト原則）
- PV確保が最優先 → PVなしでCVR改善しても意味がない
- データに基づいて継続改善

## データ分析（第8章）

### Google Search Console の見方

| 指標 | 目標値 | アクション |
|---|---|---|
| 平均掲載順位 | 20位以内 | リライト対象 |
| 平均CTR | 10%以上 | タイトル・メタ改善 |
| インプレッション数 | 増加傾向 | キーワード拡張 |

**クエリ分析**：検索されているのに順位が低いキーワードを発見 → 記事に追加

### Microsoft Clarity の活用

- レコーディング機能でユーザーの実際の動きを確認
- どこで離脱しているかを把握 → 該当箇所を改善

### SEO→比較記事への誘導率

- 目標：SEO記事から比較記事への誘導率 **5〜10%**
- 内部リンクのテキストと位置を改善して達成する

## リライト（第9章）

> **「書いた量ではなく、直し続けた量で勝負が決まる」**

### リライト8ステップ

1. キーワード順位確認（GSCで20位以内の記事を特定）
2. タイトル・見出しの見直し（検索意図とのズレを修正）
3. 競合リサーチ（上位記事と比較して不足コンテンツを追加）
4. 内部リンク最適化（比較記事・商標記事への導線を強化）
5. 文章・装飾調整（読みやすさ改善・太字・箇条書き）
6. 画像・図解の改善（理解を助けるビジュアルを追加）
7. 広告・リンク微調整（CTR改善）
8. インデックス再登録（GSCで「URL検査 → インデックス登録をリクエスト」）

### リライト優先度の決め方

```
高優先：11〜20位の記事（少し改善で1ページ目に入る可能性が高い）
中優先：21〜50位の記事（コンテンツ充実が必要）
低優先：1〜10位の記事（情報の鮮度更新のみ）
```
