# X運用スキル

> **「フォロワーが喜ぶ投稿を、伸びる型に乗せて届ける」ための設計スキルです。**

## このスキルでできること

1. アカウントの**発信軸・ポジション**を設計する
2. **プロフィール**を診断・改善する
3. **投稿文**を添削・生成する
4. **引用リポスト・リプライ**の型を提示する
5. アルゴリズムに評価されるための**運用ルール**を提案する

---

## 📌 アルゴリズムの3原則

1. **プロフィールが命** — 検索ボリュームの多い強い単語（AI、ChatGPT、Claude Code、Google等）を複数盛り込む
2. **アカウントの一貫性** — プロフィールに書いていないカテゴリの投稿はしない（ノイズになる）
3. **エンゲージメント率を守る** — 投稿後10分以内にいいねが1つもつかなければ削除する

---

## 🏗️ アカウント設計の手順

### Step 1：ゴール（誰に何を届けたいか）を1行で書く

```
例：20代〜40代の女性にダイエットの方法ではなく「QOLが上がる体」を届けたい
例：フォロワーにAIと現場仕事の掛け合わせを届けたい
```

### Step 2：ターゲットの「日常の痛み」を逆算する

| ゴール | ターゲットの日常 | 発信ワード |
|--------|----------------|-----------|
| ダイエット・健康 | 腰痛、むくみ、睡眠不足、姿勢 | 「産後ダイエット」「腰痛改善」|
| AI×副業 | 残業、効率化したい、副収入 | 「AIで時短」「現場×AI」|
| 借金・這い上がり | 返済、生活苦、将来不安 | 「借金〇〇万」「手取り〇万」|

### Step 3：プロフィールを設計する

**プロフィール構成（160字以内）**

```
【1行目】何者か（数字＋実績）
【2行目】何をしてきたか（行動ログ）
【3行目】何を目指しているか（未来）
【4行目】フォローする理由（価値提供）
```

**プロフィール例（強者感）**

```
現場監督のおっくん

筋トレで脳を鍛え
人工知能で国家資格を二ヶ月で取った

借金五百万円を三年で完済
来年四月から自分のジムを開く

失敗も成功も全部晒す
這い上がる道が知りたければフォローしろ
```

## 📊 投稿の黄金比率（2：8の法則）

| 割合 | 内容 | 目的 |
|------|------|------|
| **20%** | バズ狙い投稿（広く浅く） | 新規流入 |
| **80%** | 既存フォロワーが有益と感じる投稿 | ファン化・エンゲージメント |

---

## 🗓️ 投稿ルーティン（忙しい人向け）

**「渾身の3投稿 ＋ リプライ10件」**

| タイミング | 内容 | 目的 |
|-----------|------|------|
| **朝** | マインド・宣言（「今日も〇〇だ。△△が◻◻を作る」） | ファン化・継続性 |
| **昼** | 役立つ知識・Tips | 新規フォロワー獲得 |
| **夜** | 物語・想い・行動ログ | 共感・人間味 |
| **隙間** | 同属性アカウントへリプライ10件 | **最重要**：認知拡大 |

## 💪 最強行動：引用リポスト

引用リポストはやればやるほど良い。ただしコツがある。

**書き方のルール**

```
【1行目】引用元への「明確な賛成」または「反対」を書く
【2行目以降】理由、または引用元に欠けている視点を補足する
```

**注意点**
- 引用リポストは画像が表示されにくい → 自分の投稿に必ず**画像か動画**を入れる
- 曖昧な感想（「これいいですね」）はNG。必ず立場を取る

---

## 🔍 リサーチ：伸びる投稿の見つけ方

Xの検索コマンドで「バズった投稿の型」を発掘する。

| コマンド | 用途 |
|---------|------|
| `from:@アカウント名 min_faves:50` | 競合のヒット投稿を抽出 |
| `キーワード min_faves:50` | テーマでバズった投稿を抽出 |

→ 「型（構成・切り口）」を分析して、自分のコンテンツに置き換える（TTP：徹底的にパクる）

---

## 🔄 バズ連鎖の作り方

1. 一度伸びた投稿は**角度・視点を変えて再投稿**する
2. 「10万インプ超え」を毎日どれか1つで目指す
3. 「連続20万インプ以上」で安定したら次のフェーズへ

---

## 🚫 NGパターン

| NG | 理由 |
|----|------|
| プロフィールにないカテゴリの投稿 | アルゴリズムのノイズになる |
| URLを検索させる誘導 | フォロワーへの不便 → 離脱 |
| 10分以内にいいねゼロの投稿を放置 | エンゲージメント率が下がる |
| 「ノウハウを教えてる感」のある投稿 | 伸びない。日常から入れ |
| 他人への交流ゼロ | エンゲージメントは伸びない |

## ✅ 投稿添削チェックリスト

- [ ] **プロフィールの発信軸と一致しているか？**
- [ ] **冒頭に「具体的な数字」または「ネガティブな状況」があるか？**
- [ ] **一文が20字以内か？**（テロップ・可読性のため）
- [ ] **「ノウハウ感」「上から目線」になっていないか？**
- [ ] **画像・動画が入っているか？**（引用リポストの場合は必須）
- [ ] **リプライ・引用の場合、冒頭で賛否を明示しているか？**

## 💡 マインドセット

> **「自分の常識は、誰かの非常識」**
> 自分に当たり前のことでも、他人には価値がある情報になる。（大事なので2回意識する）

> **まずは「たった1人」の安定したいいねを目指す。**
> フォロワー100人を超えていれば、伸びる可能性は十分にある。

## このスキルの使い方

1. ユーザーから「アカウントのテーマ」「伝えたいこと」「現在の状況」を受け取る
2. 発信軸・ターゲットを整理してポジションを設計する
3. プロフィール改善案 or 投稿案を出力する
4. チェックリストで確認する

**より効果的な投稿にするには：** `instagram-hook.md`（フック型ショート台本スキル）の「フック3パターン」と組み合わせると、Xの投稿冒頭も強くなります。
