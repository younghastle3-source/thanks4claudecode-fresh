# AIツール×ビジネス実践スキル（涼馬AIスクール）

## このスキルの使いどころ

- AIツールで何か稼げることをやりたい時
- SNS運用・コンテンツ作成を自動化・効率化したい時
- 非エンジニアとしてAIをビジネスに組み込む設計をしたい時
- 営業・副業での提案・クロージング設計

---

## AIツール基本スタック

### Cursor（コードエディタ × AI）

**何者か**：プログラミング用AIエディタだが、非エンジニアのナレッジ管理・ライティング自動化ツールとしても使える

**UI構造**
- 左：ファイル・フォルダ管理（マークダウンで情報を蓄積）
- 右：AIチャット（Ask/Agentモード切替）
- 下：ターミナル

**2つのモード**
| モード | 用途 |
|--------|-----|
| Ask | 質問・相談・下書き生成 |
| Agent | ファイルへの直接書き込み・複数タスクの自律実行 |

**コンテキストエンジニアリングが鍵**
- `@ファイル名` でAIに参照させる情報を指定
- CLAUDE.md（またはルールファイル）にトーン・スタイル・禁止事項を定義しておく
- ナレッジ（.mdファイル）を蓄積するほど精度が上がる

**実務ワークフロー例**
```
録音データ（商談・セミナー）
→ 文字起こし（SuperWhisper等）
→ Cursorにmd保存
→ Claude Sonnet 4.5で提案書・SNS投稿・リライトを自動生成
→ GitHubでバージョン管理（セーブポイント）
```

### MCP（Model Context Protocol）

**何者か**：LLMと外部ツールをつなぐ「USB Type-C規格」。Claude Desktopに外部機能を追加する仕組み

**主な活用先**
| MCP | できること |
|-----|----------|
| Brave Search | Web検索をClaudeに渡す |
| Filesystem | ローカルファイルの読み書き |
| Playwright | ブラウザ操作の自動化 |
| Notion | Notionページの読み書き |
| GitHub | リポジトリ操作 |

**導入要件**：Claude Desktop + Node.js + 各ツールのAPIキー

**注意点**：ファイル操作権限を与えるため誤削除リスクあり。GitHubで管理する環境を先に作っておく

---

### Dify（ノーコードAIワークフロー）

**何者か**：ノーコードでAIエージェント・RAG・チャットボットを構築できるプラットフォーム

**向いている用途**
- RAG（ナレッジベース検索）の簡単構築
- LINE BOT、問い合わせBot
- 社内FAQ自動応答

**n8nとの比較**
| | Dify | n8n |
|--|------|-----|
| 難易度 | 低（ノーコード） | 中（ローコード） |
| 安定性 | やや低い | 高い |
| 複雑なフロー | 不向き | 得意 |
| 推奨場面 | プロトタイプ・簡単RAG | 本番・複雑自動化 |

---

### n8n（自動化ワークフロー）

**何者か**：Make/Zapierの上位互換。より複雑な自動化フローを組める

**実績ある使い方**
- Threads自動投稿システム（コンテンツ生成→投稿スケジュール→自動アップ）
- SNSスクレイピング → AIリライト → 投稿量産
- 転職エージェントアフィリエイトの導線自動化

## SNS × AIマネタイズ戦略

### バズ投稿の量産フロー（涼馬式）

```
1. Easy Scraper でバズ投稿を収集（X/Threads）
2. Claude 3.7/Sonnet でバズ要因を分析
3. 自分のポジション・トーンでリライト
4. n8n or Cursorで投稿スケジュール管理
5. 反応分析 → 改善サイクル
```

**バズ要因の抽出ポイント**
- 冒頭の「意外性」「問い」「数字」
- 読者の現状否定 → 解決策提示の構造
- 「保存したくなる情報密度」

---

### Threadsアフィリエイト（転職エージェント）

**報酬**：1件約7万円

**導線設計**
```
Threads投稿（転職悩み層に刺さるコンテンツ）

→ 面接案内 → 成約
```

**投稿テーマ**：「転職すべき？」「年収上げた体験談」「業界別リアル年収」

## AIビジネス・営業設計

### ターゲット顧客（ICP）の定義

```
即決できる経済力（30万円以上）× 変化への意欲
```

NGパターン：「お金があっても動かない人」「意欲あっても予算ない人」

### KPIと営業プロセス

- KPI：**1日2アプローチ**（量より継続）
- プロセス：リストアップ → 呼び込み → クロージング（T-UP）

**T-UPクロージング**
第三者（権威・実績）を先に立てることで主観的な売り込みを避ける。
例：「〇〇さんがこの方法で△△を達成しています」→ 自分からではなく事実として提示

### 日本人への訴求軸

```
「攻め（稼ぐ）」より「守り（損失防止）」が刺さる
```

- セキュリティ営業：「ハッカーに狙われている」ではなく「今すぐ対策しないと失う○○万円」
- AI導入提案：「生産性UPで稼げる」より「競合がAI使って差をつけられている」

### バリュエーション（権威性）の活用

大手との提携・認定・公式パートナーシップを前面に出す。
例：ByteDance公式パートナー・国家プロジェクト関与 → 信頼獲得の時間を大幅短縮

## The Model（事業フレームワーク）

```
マーケティング（認知・集客）
→ インサイドセールス（ナーチャリング・リード選別）
→ フィールドセールス（クロージング）
→ カスタマーサクセス（継続・紹介）
```

**SNS × AI実践での適用**
- マーケ：Threads/X投稿で見込み客の集積
- インサイドセールス：LINE BOT・DM自動応答でナーチャリング
- フィールドセールス：Zoom個別面談でクロージング
- CS：Notion/Difyで情報提供・コミュニティ維持

## 実践優先順位

```
Step 1：Cursor + GitHub でナレッジ管理基盤を作る
Step 2：Claude Sonnet でコンテンツ量産フローを確立
Step 3：n8n or Dify で定型作業を自動化
Step 4：MCP で外部ツールと接続し、さらに省力化
Step 5：The Model に乗せてマネタイズ
```
