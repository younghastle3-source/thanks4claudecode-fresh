## Phase 1：アカウント設計（成功の8割はここで決まる）

### HARM × 自分の強み

人が強い関心を持つ4大テーマと自分の実体験を掛け合わせる：

| テーマ | 内容 |
|---|---|
| **H**ealth（健康） | ダイエット・筋トレ・睡眠・メンタル |
| **A**mbition（野望） | キャリア・副業・起業・成功 |
| **R**elationship（人間関係） | 恋愛・家族・職場・コミュニケーション |
| **M**oney（お金） | 投資・節約・副収入・年収UP |

```
NG：「転職情報を発信します」（ありふれている）
OK：「低学歴・社畜から年収700万UPした経験 × キャリアアップ」
```

### キャラクター設計（「軍師」ポジション）

- 単なる情報提供者ではなく「読者を理想の未来へ導くリーダー」として立つ
- 記憶に残るキャラクター名・世界観を作り込む
- 例：「キャリア孔明」→ 競合と差別化できる独自ポジション

### プロフィールの5要素

1. **キャッチフレーズ**：誰をどこへ連れて行くのか（1行で）
2. **実績**：具体的な数字で権威性（「6ヶ月で1万フォロワー」）
3. **ストーリー**：過去の苦労→現在の成功の軌跡
4. **提供価値**：フォローするメリット
5. **大義名分**：なぜ発信するのか（ビジョン）

### アルゴリズム対策（プロフィール）

- 検索ボリュームの多い「強い単語」を複数盛り込む（AI・ChatGPT・副業など）
- プロフィールの属性に沿った投稿を徹底する（一貫性が評価される）

## Phase 2：認知拡大（リサーチ＆初期ブースト）

### 競合分析の鉄則（TTP）

**狙い目**：フォロワー数1,000〜5,000人で、特定のツイートだけ異常に伸びているアカウント

**リサーチコマンド**：
```
検索ワード -filter:replies -filter:retweets min_faves:500
```

**ツール**：
- ついすぽ：CSVでバズツイートを一括収集
- Tweet Hunter X：伸びているツイートをランキング表示

### バズツイートの型を盗む（ChatGPT活用）

```
①このツイートのいいところを全部教えてください
②このツイートの組み立て方を順番に説明してください
③このツイートの組み立て方を真似して誰でも書けるテンプレートを作ってください
④そのテンプレートで[自分のジャンル]の新しいツイート例を作ってください
```

### 投稿頻度（初期戦略）

- フォロワー1,000人まで：**1日10投稿**（質より量）
- 投稿時間帯：
  - 朝6〜9時：有益情報（マス受け・保存系）
  - 昼12〜13時：経験談・考え・意見
  - 夜18〜22時：交流促進・感情系

### 黄金比率（2:8の法則）

- **2割**：バズ狙い投稿（広く浅く・拡散重視）
- **8割**：既存フォロワーが「有益だ」と感じる濃い投稿

## Phase 3：バズるツイートの作り方

### 衝撃の一行（ファーストビュー）の4技法

| 技法 | 例 |
|---|---|
| **数字** | 「6ヶ月で月収100万になりました」 |
| **疑問** | 「なぜ優秀な人ほど会社を辞めるのか？」 |
| **逆説** | 「努力しない方が結果が出る理由」 |
| **感情** | 「正直しんどいです」 |

### バズる8要素

1. **人間性を曝け出す**：喜怒哀楽を隠さず。「画面割るぞ」など強い言葉で人間味
2. **共感を生む**：「あるある」ネタ・潜在的な願望を代弁
3. **アルゴリズムを意識**：滞在時間を延ばす図解・長文・スレッド
4. **衝撃の一行**：数字・疑問・逆説・感情の4技法
5. **権威性の活用**：統計・有名人の引用・実績提示
6. **常識をぶっ壊す**：逆張り・「当たり前」に異を唱える
7. **具体的なアクションを促す**：保存・RT・リプを明示
8. **未来を語り巻き込む**：「一緒に〇〇しよう」

### 具体性の法則

```
NG（抽象的）：「節約を心がけています」
OK（具体的）：「100円の卵のために自転車で30分かけて激安スーパーへ行く」
```

### 「情報 × 経験談」の方程式

```
Before（型のみ）：「会議で全部話すな。要点だけでOK。」
After（経験入り）：「会議で全部話すな。要点だけでOK。
  私も昔は2時間ダラダラ話してたが、今じゃ15分で済ませる。」
```

### 引用リポストの極意

- **1行目**：引用元に対して明確な「賛成」または「反対」を示す
- **2行目以降**：理由 or 引用元に欠けている視点を補足
- 画像か動画を必ず添付（引用リポストは画像が表示されにくいため）

### アルゴリズム対策：削除ルール

> 投稿後**10分以内に1いいねもつかなければ削除**する（アカウント評価を守る）

## Phase 4：ファン化（「情報」から「人間」へ）

### ストーリーテリング（V字回復）

```
ダメだった過去（低学歴・社畜・借金）
    ↓
葛藤・挑戦（転職活動・勉強・失敗の連続）
    ↓
成功した現在（年収UP・独立・理想の生活）
```

弱みの開示が共感を生む：「やる気が出ない」「疲れた」→ 人間味

### 独自文化の醸成

- **共通言語**：独自フレーズ・絵文字でファンとの絆を作る
- **コミュニティ**：「〇〇ファミリーリスト」で積極的に絡むフォロワーを可視化
- **企画**：読者を巻き込む参加型コンテンツ

### 連鎖ツイートの型

単ツイートではなくストーリー性を持った複数投稿で「次はどうなる？」を演出：

```
① 成長報告（「今日+150人増えた！」）
② 素直な喜びの表現
③ 次の目標宣言（「2万人までぶち上げます！」）
```

### 願望 × 鼓舞ツイート

- 具体的な数字と期限を明示した願望表現
- 「ついてこい！」「今日もぶち上げていきましょう！」で熱い言葉でフォロワーを鼓舞
- リプ欄で交流を生み双方向のモチベーション連鎖を作る

### GIVE の精神

- 圧倒的な有益情報を無償で提供し続ける
- 将来のインフルエンサーを早期に応援する（長期的なリターン）
- 「忘己利他」：自分を忘れ他者を利する姿勢

## ツイート作成テンプレート

### 有益情報型（保存・RT狙い）

```
【冒頭1行】衝撃の数字 or 逆説
─────────
【本文】
・箇条書き3〜5点
・具体的な数字を必ず入れる
・最後に「保存推奨」or「RTで仲間に広めて」
```

### 経験談型（ファン化・共感狙い）

```
【状況設定】○○だった頃の話
【転機】あの日、〇〇が起きた
【変化】それ以来、〇〇が変わった
【学び or 問いかけ】あなたはどうですか？
```

### 鼓舞・宣言型（コミュニティ強化）

```
今日の目標：〇〇
今月の目標：〇〇

一緒に頑張りましょう！
目標をリプで教えてください💪
```

## アイサロ式 プロフィール設計

### 名前の作り方
- 呼びやすい名前（読み方不明な漢字・ローマ字はNG）
- フォロワー5000人以下は「名前＋肩書き」必須（例：えーたん｜AI×時短で仕事効率化）
- 文字数：名前のみ3〜5文字、肩書き込みで12〜15文字以内

### プロフィール文の原則
- 簡潔であるほど強い。多く語らないことで「余裕・強者感」を演出
- 詰め込みすぎ → 必死感が出る
- 一目で専門分野がわかり「フォローしたらどんなメリットか」を想像させる
- InstagramっぽいふんわりコピーはXの空気感に合わない（権威性を失う）
- 構成の目安：①何をしている人か ②どんな発信か ③フォローするメリット

### アイコン
- NG：安易なAI画像、Instagramっぽい写真、認知度の低い一般人の顔写真
- 既存キャラは著作権侵害。オリジナル人型アニメも「モブ感」が出やすい
- 顔出しなしの方がかえって強く見えることもある

### ヘッダー
- 優先度は低い。ダサい画像より黒背景・単色背景の方がマシ

### シャドウバン対策
- チェッカーで定期確認
- 短期での大量フォロー・大量投稿・同一文の繰り返しはペナルティリスク

## XポストをNote記事に変換するプロンプト

**用途**：バズ投稿・ツリー投稿を3,000字のnote記事に自動変換

```
# 役割定義
あなたはSNSの短い投稿をnote記事へ拡張・再構成するプロの編集者です。
以下の情報をもとに、最高のnote記事を1本、約3,000字で作成してください。

# プロセス
1. まず「記事構成（目次案）」のみを出力してください。
2. 私がOKと入力したら本文の執筆を開始してください。

# 入力情報
【元にするXのポスト】▼ここに貼り付け
【お手本の文章（任意）】▼文体を近づけたい場合に貼り付け
【簡単な指示】
- ターゲット読者：
- 一番伝えたいメッセージ：
- 最後に入れるCTA：

# 記事の構成要件（約3,000字）
1. 導入文（300-400字）：共感フック
2. メインコンテンツ（1,800-2,000字）：深掘り＋具体例
3. 活用メリット（400-500字）：ベネフィット提示
4. まとめ（300-400字）：要点＋CTA
```

**コツ**：1ツイートよりツリー投稿を元にすると内容が濃くなる。構成案が出た段階で修正指示を出すと意図通りになる。
