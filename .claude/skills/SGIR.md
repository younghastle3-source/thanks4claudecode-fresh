# フィットネス発信コンテンツスキル（SAM/SGIR スタイル）

## このスキルの使いどころ

- SNS投稿・リール・YouTube台本のネタ出しと構成
- 「ちゃんとした情報をわかりやすく、意外な角度で」伝えたい時
- 科学的根拠を崩さずにエンタメ性を加えたい時

---

## コンテンツ設計の基本思想

**「ノイズの中のシグナル」を届ける**

フィットネス界は情報過多。「絶対やるべき」「やってはいけない」が溢れている。
ポジション = **科学的に正しくて、かつ一般人が実践できる情報の翻訳者**

```
常識を疑う → 根拠を示す → 実践に落とす
```

## 刺さるコンテンツの型

### 型1：「意外な真実」型（切り抜き・バズ向き）

**構造**
1. 常識の提示（「〇〇がいいと思ってませんか？」）
2. 逆説的な事実（「実は××」）
3. 科学的理由（簡潔に）
4. 実践アドバイス

**ネタ例（実際の知見から）**
- 「効いてる感 ≠ 筋肉への刺激」→ ストラップを使うべき理由
- 「PS5はTikTokより健全な理由」→ ハームリダクション思考
- 「最強の昼寝は20分＋コーヒー」→ カフェインの作用タイミング活用
- 「ミリタリープレスは筋肥大に非効率」→ 安定性とモーターユニットの話
- 「飢餓モードは存在しない」→ 代謝適応の誤解を解く
- 「筋肉痛がなくても筋肥大は起きる」→ DOMS神話の解体

---

### 型2：「完全ガイド」型（保存・シェア向き）

**構造**
1. なぜこれが必要か（背景・問題提起）
2. 基本原則（2〜3点に絞る）
3. 実践ステップ（具体的な数字・行動）
4. よくある誤解の排除
5. 一言まとめ

**ネタ例**
- バルクアップ完全マニュアル
- 人生最後のダイエット戦略
- 体脂肪減少の科学
- 睡眠完全攻略ガイド

---

### 型3：「Q&A/切り抜き」型（コメント回答・LIVE切り抜き向き）

**特徴**：視聴者の悩みに直接答える形式。親近感と信頼感が同時に生まれる。

**よく刺さる質問テーマ**
- 「減量中に筋肉はつく？」→ 初心者はつく、上級者は難しい
- 「ベンチプレスのMAX更新できない」→ レップレンジを変える
- 「1200kcalで痩せない」→ ほぼ記録漏れが原因
- 「クレアチンいつ飲む？」→ タイミングより毎日継続が重要
- 「減量中に性欲が落ちた」→ カロリー不足による生理的反応（正常）

---

### 型4：「Mind×筋トレ」型（差別化コンテンツ）

筋トレと人生哲学を掛け合わせる。フィットネスインフルエンサーとしての深みを出す。

**テーマ例**
- 筋トレで得た「完璧主義を捨てる」思考
- ボディビル大会に出ない理由 → 自己認識と目的の明確化
- トレーニングの「継続」と「モチベーション依存」脱却
- SNS・TikTokの弊害と意識的なデジタル選択

## 知識ベース：発信に使える具体的なデータ

### ダイエット・カロリー

- 体脂肪1kg = 約7200kcal
- 理想の減量ペース：週0.5〜1%の体重減少
- タンパク質：減量中は体重×2〜3g（食事誘発性熱産生 + 筋肉維持）
- 脂質：総カロリーの20%以上は確保（ホルモン維持）
- 炭水化物：残り全て（エネルギー源・筋グリコーゲン）
- アルコールは脂肪酸化を低下させ、睡眠を悪化させ、ホルモンを乱す

**ダイエット失敗の4大誤解**
1. 飢餓モードで代謝が落ちて太る → 存在しない（代謝適応はあるが「飢餓モード」は誇張）
2. チートデイで代謝が上がる → 効果は限定的
3. 1200kcalで痩せない → 記録漏れがほぼ原因
4. 体脂肪10%以下が健康的 → ホルモン崩壊・性欲減退・睡眠悪化のリスク

**ダイエット成功の4ステップ**
1. 現状把握（体重・体脂肪・カロリー記録）
2. メカニズム理解（カロリー収支の原則）
3. 計画立案（無理のない数値目標）
4. 食事プランニング（継続できる食事設計）

**リバースダイエット**：長期減量後の代謝回復プロセス。毎週50〜100kcalずつ増やして体重維持ラインを引き上げる。

---

### バルクアップ

- 余剰カロリー：+200〜500kcal（初心者+500 / 上級者+200）
- 目標増量ペース：月1〜3.5kg
- 体脂肪率が15%超えたらミニカット（2〜6週間、ピーク時から-1000〜1800kcal）
- プレワークアウト：複合炭水化物+タンパク質（1.5〜2.5時間前）
- ポストワークアウト：高炭水化物+高タンパク（グリコーゲン回復）

---

### トレーニングテクニック

- **感覚 vs 刺激**：「効いている感」は指標にならない。対象筋への物理的刺激が重要
- **ストラップ・グリップ補助具**：使うべき。前腕の弱さで背中の追い込みを止めるのは本末転倒
- **TUT（タイムアンダーテンション）**：筋肥大にそれほど重要ではない。限界近くまで追い込むことが先決
- **レストポーズ・パーシャルレップ**：効果的だがストレートセットが基本
- **ミリタリープレス**：安定性が低い → モーターユニット動員数が落ちる → 純粋な筋肥大には非効率
- **減量中の筋肥大**：初心者・高体脂肪率なら可能。トレーニング歴が長く体脂肪が低いと難しい

### 睡眠・パフォーマンス最適化

**睡眠の3大柱**
1. **光のコントロール**：朝に日光浴・夜はブルーライトカット・夜間覚醒時は暗色ライト
2. **体温・室温管理**：21〜23℃・入浴で体温を上げてから下がる流れを作る
3. **カフェイン**：午後2時以降は摂取禁止

**最強の昼寝：コーヒーナップ**
→ コーヒーを飲んでから20分仮眠する。カフェインの作用が始まる（15〜20分後）タイミングで目覚める = 最高の覚醒感

**集中力アップのサプリ**：カフェイン90〜200mg + テアニン（セット）、アルファGPC 300〜600mg、チロシン500mg〜1.5g

**脳パフォーマンスの3大土台**：睡眠7時間以上・朝10分の軽い運動・電解質補給（サプリより先）

## 発信スタイルの原則

```yaml
tone:
  - 断定的に語る（「〜かもしれません」より「〜です」）
  - 数字で語る（体重×2g、週0.5%等）
  - 自分の経験・失敗を混ぜる

避けるべき表現:
  - 「個人差があります」だけで終わる
  - 専門用語の羅列（翻訳して届ける）
  - 「正解はありません」系のぼかし表現

コンテンツの長さ:
  - SNS投稿：1スクロールで読める量
  - リール台本：45〜90秒（200〜400文字）
  - 保存系：箇条書き5〜8点にまとめる
```
