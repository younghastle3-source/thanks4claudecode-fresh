# Threads投稿改善ミニ診断

## このスキルの使い方

```yaml
用途: 投稿文を貼り付けると8項目でセルフ診断・改善案を出す
タイミング: 投稿前（公開前チェック）または投稿後（反応が少ない原因を特定）
所要時間: 3分
```

---

## チェック1: 誰に向けて書くか明確？

**ポイント**: みんなに向けて書くほど、誰の心にも残りにくくなります。たった1人をイメージして書くことで言葉が刺さりやすくなる。

- [ ] 誰に向けた投稿か1人の具体的な人物像で言える？
- [ ] 相手の悩みや状況を想像できてる？
- [ ] たった1人に話しかける意識がある？

> 最初に「誰に向けてか」を決めておくと、刺さりやすくなります。

---

## チェック2: 投稿時間を適当に決めてない？

**ポイント**: 大事なのは「何時が正解か」ではなく、「お客様はいつ見てる？」を考えること。相手の生活に合わせるだけで反応が変わります。

- [ ] 誰が見るかを考えて時間を決めてる？
- [ ] 相手の生活リズムに合わせてる？（例：ママ向けなら子どもの昼寝・就寝後）
- [ ] 投稿後の反応を記録して見直してる？

> ママ向けなら昼寝・寝た後などのスマホ時間、会社員向けなら通勤・昼休み・仕事終わりが狙い目。

---

## チェック3: 読者が知りたいことを書いてる？（自分が言いたいことだけ書いてない？）

**ポイント**: 読者が知りたいのは「あなたが話したいこと」より「自分に関係あること」です。リサーチして需要のあるネタを選びましょう。

- [ ] 自分の伝えたいことだけになってない？
- [ ] 読者の悩みや関心を見てる？
- [ ] リサーチをしてネタを集めてる？

> お客様が今どんなことで悩んでいるか／どんな投稿に反応しているか／何を知りたがっているかを確認する。

---

## チェック4: 書き出しで興味づけできてる？

**ポイント**: Threadsは流し見される世界。最初の一文で「え、気になる！」と思わせることが大切。説明から入るより続きを読みたくなる言葉を意識しましょう。

- [ ] 説明やあいさつから入っていない？
- [ ] 「え、気になる！」と思わせる書き出しになってる？
- [ ] 読者の「私のことかも？」を意識してる？

> 読まれやすい書き出しの例：「これではもったいない！〇〇のコツ」「実は、そのうちやろうでは残せない瞬間があります」

---

## チェック5: 長文をひとつの投稿に詰め込んでない？

**ポイント**: 長文のままだと途中で離脱されやすくなります。伝えたいことが多い時ほど、ツリー投稿で読みやすく整えるのがおすすめです。

- [ ] ひとつの投稿に情報を詰め込みすぎてない？
- [ ] ツリーで分けて考えてる？（①興味を引く→②理由や具体例→③まとめ）
- [ ] 読みやすさを意識してる？

> 内容を減らすより、伝わる形に並べ直すイメージ。

---

## チェック6: 専門用語を使いすぎてない？

**ポイント**: 自分の中では当たり前でも、読者には難しいかもしれません。「中学生でもわかる？」を基準に書きましょう。

- [ ] 専門用語やカタカナが多くない？
- [ ] 言い換えや具体例を入れてる？
- [ ] スッと頭に入る文章になってる？

> 対処法：かんたんな言葉に言い換える／具体例を入れる／イメージしやすく伝える。

---

## チェック7: 伝えたいことを詰め込みすぎてない？

**ポイント**: 内容を広げすぎると、結局「何が言いたいの？」な投稿になりやすいです。投稿は全部を伝える場所ではなく、1つだけ持ち帰ってもらう場所でOK。

- [ ] テーマを広げすぎてない？
- [ ] 読者に持ち帰ってほしいことは1つ？
- [ ] 書く前に「誰に・何を・どうなってほしい」の軸を決めてる？

> 書く前に決めること：誰に向けて書く？ / 何を伝える？ / どうなってほしい？

---

## チェック8: 自分語りの日記になってない？

**ポイント**: 読者が知りたいのは「あなたの話」ではなく「自分に関係あること」。自分の出来事・感情を書くだけでなく、読者にとっての意味・学びに変換して届けましょう。

- [ ] 自分の出来事の報告だけになってない？
- [ ] 読者が「私に関係ある」と感じる視点になってる？
- [ ] 自分の経験を読者の学び・気づきに変換して書いてる？

> 日記→投稿への変換：「今日〇〇をした」→「〇〇をしてわかった、△△で悩む人へ伝えたいこと」
