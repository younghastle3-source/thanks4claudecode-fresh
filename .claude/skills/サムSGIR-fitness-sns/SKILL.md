## 発信テーマ別 コアナレッジ

### ■ バルクアップ

**カロリー設定の鉄則**
```
メンテナンスカロリー（TDEE）を計測してから余剰を設定：
  初心者（0-2年）: +500kcal
  中級者（2-4年）: +200〜500kcal
  上級者（5年+）: +200kcal

目標増量ペース：月1〜3.5kg
体脂肪15〜20%を超えたら → ミニカット（2〜6週間の短期減量）を挟む
```

**PFCバランス（増量期）**
- タンパク質：体重×2〜3g
- 脂質：総カロリーの20〜30%
- 炭水化物：残り全て

**SNS発信切り口例：**
- 「バルクアップで失敗する人の共通点」→ 過食・体脂肪管理なし・停滞放置
- 「ミニカットを知らずに増量してた」→ 体脂肪が増えすぎる前にリセット
- 「増量ペース月1kgが正解な理由」→ 脂肪増加を最小に抑えながら筋肉を増やす

### ■ ダイエット・減量

**体脂肪を落とす科学**
- 体脂肪1kg落とすには約7,200kcalの赤字が必要
- カロリー赤字の目安：-300〜500kcal/日（月1〜2kg減が適切）
- 極端な制限は筋肉を削り代謝を壊す

**減量中の筋肉維持 3原則**
1. 筋トレを継続する（強度を落とさない）
2. タンパク質を増やす（体重×2.5〜3g）
3. 赤字は適度に（-500kcalを超えない）

**体脂肪率別の目標設定**
| 現在の体脂肪率 | 目標 |
|---|---|
| 25%以上 | まず15%前後まで落とす |
| 15〜20% | 15%以下を目指す |
| 12%以下 | 現状維持・リバースダイエットへ |

**リバースダイエット（減量後の代謝回復）**
- 目的：落ちた代謝をリセットし、低体脂肪を維持しながらカロリーを増やす
- やり方：週ごとに10〜15%ずつカロリーを増やす
- 最初の3週間が最難関（体重増加への恐怖と戦う）
- 食事の一貫性90%以上を維持することが必須

**SNS発信切り口例：**
- 「ダイエットに失敗する人が知らない1つの事実」→ カロリー収支が全て
- 「減量中に筋肉を落とさない方法」→ タンパク質×筋トレ継続
- 「リバースダイエットをやらないと太る理由」→ 代謝崩壊のメカニズム
- 「アルコールがダイエットの敵な本当の理由」→ 脂肪燃焼停止・睡眠質低下・ホルモン悪化

### ■ 睡眠

**睡眠を最大化する5原則**

1. **光のコントロール**
   - 朝：起床後すぐ日光を浴びる（体内時計リセット）
   - 夜：日没後はブルーライトを遮断
   - 夜間に目が覚めたら暗い照明のみ使用

2. **室温管理**：理想は21〜23℃（体温低下を促す）

3. **カフェインのカットオフ**：午後2時以降NG（半減期5時間）

4. **就寝前ルーティン**
   - 入浴（就寝1〜2時間前）
   - スマホ・仕事のシャットダウン
   - ストレッチ・呼吸法

5. **30分ルール**：30分以上眠れなければベッドを出る（ベッド＝眠る場所の条件付け）

**睡眠サプリ**
- グリシン酸マグネシウム（就寝前）
- メラトニン：0.5〜1mg（少量が効果的）
- L-テアニン：100〜200mg（リラックス促進）

**SNS発信切り口例：**
- 「最強の昼寝は『20分＋コーヒー』」→ 仮眠直前にコーヒーで覚醒タイミングが最適化
- 「カフェインを午後に飲んでる人は損してる」→ 半減期5時間のメカニズム
- 「筋トレより睡眠を疎かにしてる人が多すぎる」→ 成長ホルモン分泌と回復

## SNS投稿生成モード

### リール台本（フィットネス版）

ユーザーがテーマを指定した場合、以下の構成で台本を作成：

```
【フック（0-2秒）】
数字×意外性 or 常識を崩す一言
例：「減量中にタンパク質を増やすと痩せやすくなる」

【展開（3-15秒）】
「普通はこう思うよね？でも実は〇〇」
反直感・ギャップで視聴維持

【本題（15-45秒）】
科学的根拠 or 具体的な数字・方法を提示
一文20字以内・箇条書き調

【CTA（最後の一言）】
「保存して実践してみて」「これを知ってから変わった」
```

### キャプション型投稿

```
冒頭1行：引きのある一文（絵文字可）
本文：3〜5つの箇条書き（根拠・数字あり）
締め：一言コメント or 問いかけ
ハッシュタグ：5〜10個
```

### 切り抜き型（長尺→短文変換）

長いトランスクリプトや解説文を渡された場合：
1. 最も「意外性がある」or「すぐ使える」ポイントを抽出
2. 30秒〜1分で読める分量に圧縮
3. 数字と具体例を残す（抽象化しない）
