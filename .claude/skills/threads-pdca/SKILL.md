# Threads PDCA スキル

> **参考アカウントの投稿から型を学び、自分の投稿に活かし、実績を振り返って次に繋げるための PDCA スキルです。**

## このスキルでできること

1. 参考アカウントの投稿をコピペで受け取り、**型ライブラリ（A〜G）に統合**する
2. 型ライブラリから型を選び、**投稿の下書き**を作る
3. 投稿後の実績（いいね・コメント・保存）を**投稿ログに記録**する
4. 投稿ログを**週次/月次で集計**し、傾向を振り返って次の Plan に反映する

## 参照ファイル

- `references/pattern-library.md`: A〜G の7型の構造・出典・効く理由をまとめた型ライブラリ
- `references/my-posts-log.md`: 自分の投稿実績を記録するログテンプレート

---

## ワークフロー1: 新規アカウント分析（Research → 型ライブラリ統合）

発火フレーズ: 「Threadsの投稿分析して」「このアカウントの投稿を型にして」「参考アカウントの投稿貼るね」

ユーザーが参考アカウントの投稿をコピペで手渡してきたときに実行する。Threads API やスクレイピングは使わず、常にユーザーからの手渡しを前提にする。

1. 貼られた投稿を1件ずつ読み、`references/pattern-library.md` の A〜G のどの型に近いかを判定する
2. 既存の型と骨格が重複する場合は、その型のセクションに新しい特徴・言い回しを**統合**する（型を増やさない）
3. 既存のどの型にも当てはまらない新しい骨格の場合のみ、ユーザーに確認した上で新しい型として追加する
4. 統合・追加した内容には、必ずその投稿の**出典**アカウント名を明記する
5. `references/pattern-library.md` を更新し、変更点をユーザーに要約して報告する

---

## ワークフロー2: Plan（型選択 → 投稿の下書き作成）

発火フレーズ: 「Threadsの投稿作って」「今日の投稿の下書きお願い」「このネタで投稿書いて」

1. ユーザーから伝えたい内容・状況（日常/告知/振り返り 等）を受け取る
2. `references/pattern-library.md` を参照し、状況に最も合う型（A〜G）を1つ選ぶ（複数型の組み合わせも可）
3. 選んだ型の「型の構造」に沿って**下書き**を作成する。verbatim CTA がある型（E）はそのまま流用してよい
4. 執筆時の一般注意（絵文字1〜2個・タメ口・地域名は告知系のみ）に沿っているか確認する
5. 下書きと「狙った型」をユーザーに提示し、投稿後に `references/my-posts-log.md` へ記録する旨を伝える

---

## ワークフロー3: Check（投稿後の実績記録）

発火フレーズ: 「投稿の実績を記録して」「さっきの投稿、いいね◯件だった」「投稿結果を報告するね」

投稿ごとの簡易チェックとして、投稿後にユーザーから実績が報告されたときに実行する。

1. ユーザーから日付・投稿文の要約・狙った型・**いいね**/コメント/保存数・気づきを受け取る
2. 情報が不足している項目（型やコメント数など）があればユーザーに確認する
3. `references/my-posts-log.md` の投稿実績ログの表に1行追記する（既存のヘッダ・区切り行は変更しない）
4. 追記した内容をユーザーに要約して報告する

---

## ワークフロー4: Act（週次/月次の集計・振り返り）

発火フレーズ: 「Threadsの振り返りして」「今週の投稿まとめて」「月次でどの型が効いてるか教えて」

投稿ごとのチェックとは別に、週次/月次でまとめて振り返るときに実行する。

1. `references/my-posts-log.md` の投稿実績ログを読み込み、対象期間（週次/月次）のデータ行を抽出する
2. 型（A〜G）別に実績を**集計**し、いいね・コメント・保存の平均や合計を出す
3. 効果が高い型・低い型の**傾向**を分析し、気づき欄の内容も踏まえて要因を推定する
4. 分析結果をユーザーに報告し、次の Plan（ワークフロー2）で優先すべき型を提案する

---

## このスキルの使い方

1. ユーザーからの発火フレーズに応じて、上記4ワークフローのいずれかを実行する
2. 型の判断・下書き作成には必ず `references/pattern-library.md` を参照する
3. 実績の記録・集計には必ず `references/my-posts-log.md` を参照する
4. 実データの自動取得は行わない。参考アカウントの投稿・自分の実績はいずれもユーザーからの手渡しを前提にする
