# 投稿ログ

自分が実際に投稿した Threads の実績を、投稿ごとに手入力で記録するテンプレートです。
API やスクレイピングによる自動取得は行わず、投稿後にユーザーが手渡しした実績を追記します。

## 記入方法

- 「日付」は投稿した日を `YYYY-MM-DD` 形式で記入する
- 「投稿文（要約）」は投稿本文の要点を1〜2行で要約して記入する（全文コピペは不要）
- 「狙った型」は `pattern-library.md` の A〜G の記号のいずれかを記入する（例: `E` / `E, G` のように複数併記も可）
- 「実績（いいね/コメント/保存）」は投稿後に確認した数値を `いいね数/コメント数/保存数` の形式で記入する
- 「気づき」は数値の増減理由や次に試したいことを短く記入する（週次・月次の振り返りで参照する）
- データ行は投稿の都度この表の下に追記していく。テンプレート時点ではダミーデータ・例示行を入れない
