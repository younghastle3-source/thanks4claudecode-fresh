# 型ログ

投稿ごとに「狙った型」を記録するログです。ワークフロー2で下書きを作った時点で、スキル自身が自動でこの表に1行追記します。ユーザーへの手入力は不要で、都度型を聞かないための仕組みです。

投稿URL（permalink）が確定したら該当行に追記・更新し、ワークフロー4でこの投稿URLをキーに自動収集ログの投稿と突き合わせます。
