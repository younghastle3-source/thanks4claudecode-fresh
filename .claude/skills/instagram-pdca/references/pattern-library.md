# Instagram 投稿 型ライブラリ

> このライブラリは Instagram 用に初期構築した8型の一覧です。
> リール2型（IG-R1/IG-R2）は既存の台本スキルから、リール1型・フィード4型・ストーリーズ1型は
> `.claude/skills/threads-pdca/` の型ライブラリの実績から、それぞれ Instagram のフォーマットへ
> 割り当てて導出しています。台本本文の生成・添削は本ライブラリでは行わず、既存の台本スキルに委譲します。
> Instagram での実績による裏付けはまだ無いため、各型の「効く理由」には出典側の根拠と
> 「Instagram では未検証」である旨を明記しています。

## IG-R1 フック型リール

**フォーマット**: リール

**出典**: `.claude/skills/instagram-フック型ショート台本.md`（リール冒頭のフックパターンと台本の文体）

**主指標**: リーチ/フォロワー外

### 型の構造

```
【1】最初の2秒で強いフック（一言目のテロップ）を出す。フックそのものの生成・添削は `.claude/skills/instagram-フック型ショート台本.md` に委譲する
【2】理想と現実のギャップを見せる展開パート
【3】具体的な数字・固有名詞を交えた本題パート
【4】締めの一言で余韻を残し、保存・フォローを促す
```

### 効く理由

出典スキルでは、一言目に強い数字やネガティブな結末を置くことでスクロールを止める設計になっており、リールの視聴維持率を上げる根拠として蓄積されている。Instagram のリールでも冒頭2秒の離脱率が最も高いため理屈は通るが、実際の反応データによる検証はまだ無い。

## IG-R2 日常ブリッジ型リール

**フォーマット**: リール

**出典**: `.claude/skills/instagram-日常ブリッジ台本.md`（日常の入口から本題へつなぐ構成設計）

**主指標**: リーチ/フォロワー外

### 型の構造

```
【1】視聴者が共感しやすい日常の一コマから入る
【2】日常の一コマから伝えたい本題へ自然に橋渡しする。橋渡しの構成設計そのものは `.claude/skills/instagram-日常ブリッジ台本.md` に委譲する
【3】本題を短く言い切る
【4】次のアクション（保存・プロフィール遷移）につながる一言で締める
```

### 効く理由

出典スキルでは、いきなり本題に入るより日常の入口から自然に橋渡しした方が視聴者の警戒を下げられるという構成上の根拠が蓄積されている。Instagram のリールでも同様に離脱を抑えられると見込まれるが、実際の反応データによる検証はまだ無い。

---

## IG-R3 業界考察・示唆型リール

**フォーマット**: リール

**出典**: threads-pdca の H型（okkun_lifestyle の投稿実績）

**主指標**: 保存/フォロワー外

### 型の構造

```
【1】業界・イベントの構造を観察者視点で分析する
【2】具体的な仕組みを言語化する（例: 参加の仕組みが結果的に次の参加者を呼ぶ循環になっている、等）
【3】本質を一言でまとめる
【4】自分の文脈（活動・コミュニティ運営）への応用可能性を示唆して締める
```

### 効く理由

Threads では個人の物語とは異なる読者層（ビジネス・マーケティングに関心がある層）にリーチした実績がある。Instagram のリールでも新規層の発見タブ露出につながる可能性はあるが、実際の反応データによる検証はまだ無い。

---

## IG-F1 共感質問型フィード

**フォーマット**: フィード

**出典**: threads-pdca の B型（leven_base の投稿実績）

**主指標**: コメント/保存

### 型の構造

```
【1】具体的な身体感覚・弱みの告白から入る
【2】シリアスになりすぎないよう絵文字を添える
【3】断定せず質問で終えて、読む側が自分の経験を書き込める余白を残す
```

### 効く理由

Threads では弱みの開示とコメントを誘発する質問の組み合わせで高いコメント実績がある。Instagram のフィードでもキャプションでの弱みの告白がコメントを誘発すると見込まれるが、実際の反応データによる検証はまだ無い。

---

## IG-F2 物語・哲学型カルーセル

**フォーマット**: フィード

**出典**: threads-pdca の C型（leven_base の投稿実績）

**主指標**: 保存/プロフィールへのアクセス

### 型の構造

```
【1】本音の告白から始め、1枚目のスライドで引きを作る
【2】理由の開示を中盤のスライドに配置する
【3】人生観への昇華を最後のスライドでまとめる
```

### 効く理由

Threads では連投形式で滞在時間とプロフィール遷移を稼いだ実績がある。Instagram では複数画像のカルーセル形式に置き換えることで同様に滞在時間と保存を稼げると見込まれるが、実際の反応データによる検証はまだ無い。

## IG-F3 イベント告知＋ベネフィット再定義型フィード

**フォーマット**: フィード

**出典**: threads-pdca の D型（leven_base の投稿実績）

**主指標**: プロフィールへのアクセス/コメント

### 型の構造

```
【1】日時・場所・タイムスケジュールを具体的に明示する
【2】活動そのものの価値ではなく、参加によって得られる感情的なベネフィットに言い換える
【3】ソフトなCTA（「興味ある人いますか？」等）で心理的ハードルを下げる
```

### 効く理由

Threads ではベネフィットの言い換えとソフトCTAの組み合わせで参加動機を作れた実績がある。Instagram のフィードでも同様の言い換えが告知系投稿への心理的ハードルを下げると見込まれるが、実際の反応データによる検証はまだ無い。

## IG-F4 参加者体験談型（UGC）

**フォーマット**: フィード

**出典**: threads-pdca の G型（hi.hi.hi999 / tomokazu_0008 の投稿実績）

**主指標**: いいね/保存

### 型の構造

```
【1】素直な弱み・不安の告白から入る
【2】参加した結果のギャップを描写する
【3】主催アカウントに言及・タグ付けし、第三者の信頼を橋渡しする
```

### 効く理由

Threads では参加者目線の投稿が主催者投稿を補強する第三者の社会的証明として機能した実績がある。Instagram のフィードでもタグ付けを通じた相互送客が見込まれるが、実際の反応データによる検証はまだ無い。

---

## IG-S1 日常実況型ストーリーズ

**フォーマット**: ストーリーズ

**出典**: threads-pdca の A型（leven_base の投稿実績）

**主指標**: リーチ

### 型の構造

```
【1】場所＋今やっていることを短く伝える
【2】絵文字1つで感情を添える
【3】質問スタンプ等の双方向アクションを添えて反応を集める
```

### 効く理由

Threads ではCTAなしの低負荷投稿を積み重ねることで「毎日投稿してる人」という信頼の土台を作れた実績がある。Instagram のストーリーズでも投稿頻度を上げやすく、他フォーマットの間を埋める役割が見込まれるが、実際の反応データによる検証はまだ無い。
