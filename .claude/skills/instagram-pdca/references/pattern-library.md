# Instagram 投稿 型ライブラリ

> このライブラリは Instagram 用に構築した型の一覧です（現在10型）。
> リール2型（IG-R1/IG-R2）は既存の台本スキルから、リール1型・フィード4型・ストーリーズ1型は
> `.claude/skills/threads-pdca/` の型ライブラリの実績から、それぞれ Instagram のフォーマットへ
> 割り当てて導出しています。台本本文の生成・添削は本ライブラリでは行わず、既存の台本スキルに委譲します。
> Instagram での実績による裏付けはまだ無いため、各型の「効く理由」には出典側の根拠と
> 「Instagram では未検証」である旨を明記しています。

## IG-R1 フック型リール

**フォーマット**: リール

**出典**: `.claude/skills/instagram-フック型ショート台本.md`（リール冒頭のフックパターンと台本の文体）

**主指標**: リーチ/フォロワー外

### 型の構造

```
【1】最初の2秒で強いフック（一言目のテロップ）を出す。フックそのものの生成・添削は `.claude/skills/instagram-フック型ショート台本.md` に委譲する
【2】理想と現実のギャップを見せる展開パート
【3】具体的な数字・固有名詞を交えた本題パート
【4】締めの一言で余韻を残し、保存・フォローを促す
```

### 効く理由

出典スキルでは、一言目に強い数字やネガティブな結末を置くことでスクロールを止める設計になっており、リールの視聴維持率を上げる根拠として蓄積されている。Instagram のリールでも冒頭2秒の離脱率が最も高いため理屈は通るが、実際の反応データによる検証はまだ無い。

## IG-R2 日常ブリッジ型リール

**フォーマット**: リール

**出典**: `.claude/skills/instagram-日常ブリッジ台本.md`（日常の入口から本題へつなぐ構成設計）

**主指標**: リーチ/フォロワー外

### 型の構造

```
【1】視聴者が共感しやすい日常の一コマから入る
【2】日常の一コマから伝えたい本題へ自然に橋渡しする。橋渡しの構成設計そのものは `.claude/skills/instagram-日常ブリッジ台本.md` に委譲する
【3】本題を短く言い切る
【4】次のアクション（保存・プロフィール遷移）につながる一言で締める
```

### 効く理由

出典スキルでは、いきなり本題に入るより日常の入口から自然に橋渡しした方が視聴者の警戒を下げられるという構成上の根拠が蓄積されている。Instagram のリールでも同様に離脱を抑えられると見込まれるが、実際の反応データによる検証はまだ無い。

## IG-R3 業界考察・示唆型リール

**フォーマット**: リール

**出典**: threads-pdca の H型（okkun_lifestyle の投稿実績）

**主指標**: 保存/フォロワー外

### 型の構造

```
【1】業界・イベントの構造を観察者視点で分析する
【2】具体的な仕組みを言語化する（例: 参加の仕組みが結果的に次の参加者を呼ぶ循環になっている、等）
【3】本質を一言でまとめる
【4】自分の文脈（活動・コミュニティ運営）への応用可能性を示唆して締める
```

### 効く理由

Threads では個人の物語とは異なる読者層（ビジネス・マーケティングに関心がある層）にリーチした実績がある。Instagram のリールでも新規層の発見タブ露出につながる可能性はあるが、実際の反応データによる検証はまだ無い。

## IG-R4 コスト再定義型リール

**フォーマット**: リール

**出典**: mikity__97（「22,690円の使い道まちがえました。」投稿、いいね82件）

**主指標**: 保存/フォロワー外

### 型の構造

```
【1】具体的な金額＋「使い道を間違えた」等のネガティブな言い回しでフックを作る
【2】(知らない人向けに)何にお金を使ったのか、その対象を簡潔に説明する
【3】フックで出した金額の内訳を具体的な数字で見せる(伏線回収)
【4】「冷静に考えたら◯◯」等の自虐ジョークを挟み、親近感を作る
【5】ゴール直後などの前向きな一言(「次は〜」)で、金額に見合う中毒性がある twist を見せる
【6】別カット(日常・仕事・トレーニング)で"なぜ続けるのか"という深い理由を提示し、金額の意味を再定義する
【7】断定を避けたユーモアのある一言(「〜のための投資…たぶん」)で締める
```

### 効く理由

高額な出費というネガティブな入口から入り、自虐ジョークで緩めたあと、価値の再定義で着地させる緩急のある構成。単なる「良かった」ではなく一度「イカれてる」と自分を落としてから真面目な理由に転換する構成が最後まで見せる力になっていると考えられる。

**自アカウントでの実績（2026-08-15投稿、詳細は `my-posts-log.md`）**: リーチ32,000・フォロワー外97.9%・保存30・新規フォロー21件と、主指標(保存/フォロワー外)が大きく伸びた。同時期に投稿した IG-R1(タイトルテロップのみでキャプション頼み)との比較から、以下2点が効いたと推定される。

- フックが「具体的な金額」という数字系で、抽象的なタイトル(例:「〜選」)より強い
- **動画内テロップに内容そのもの(内訳・自虐・twist・深い理由)を全ビート乗せており、キャプション頼みにしていない**。IG-R1 側の低反応(視聴維持率止まり・保存伸び悩み)の原因分析で「動画側に中身が無くキャプション頼みだったこと」が要因と推定されており、この型では実際にテロップへ中身を乗せたことが視聴維持率と保存の両立につながったとみられる

**残課題**: コメント0件。次回はこの型の最後に、コメントを誘発する問いかけ(例:「みんなは何にお金を使いすぎた?」)を追加できるか試す余地がある。

## IG-R5 種目解説・メニュー型リール

**フォーマット**: リール

**出典**: buildruncore_mizonokuchi(バーピーブロードジャンプの疲れにくい飛び方、技術解説)、tatsuki_okahashi(脚トレメニュー、種目名+回数×セット)、yutem_yutem(アスリート脚トレメニュー、種目名+目的をペアで解説)

**主指標**: 保存

### 型の構造

```
【1】種目名/テーマを冒頭で明示する(タイトルテロップ)
【2】種目ごとに、動作の映像+種目名+回数・セット数(またはコツ・目的)をテロップで重ねて実演する
【3】(あれば)なぜその動きが効くか・注意点を一言添える
【4】保存を促す一言、または「コメントで質問受付」等の軽いCTAで締める
```

### 効く理由

派手なフックや物語性よりも、実演+具体的な数字・コツが並ぶこと自体が「保存する理由」になる。技術的な正確さ・網羅性が信頼を作り、保存経由でプロフィールに戻ってきてもらいやすい構成と考えられる。出典3アカウントはいずれもHYROX/フィットネス業界での実演メニュー投稿で、個別のいいね数等の裏付けは未取得だが、業界で頻出する構造として採用する。

**自アカウントでの実績（2026-08-24投稿、詳細は `my-posts-log.md`）**: リーチ9,812・保存54・平均再生時間10.10秒と、直前の同型投稿（2026-08-23、リーチ627・保存4）から視聴者数15.6倍・保存13.5倍に急伸。両者は同じIG-R5だが、構成に以下2つの違いがあった。

- サムネ(カバー画像)を、2×2グリッド+グロー文字の凝ったタイトルカードから、**本人の実写真1枚+シンプルなタイトルテキストのみ**に変更した
- 動画内テロップを、種目名+補足情報(回数・器具代替メモ等)を複数含む構成から、**種目名+動作キュー1行のみ**に削った

2つの変更が同時に入っており厳密な要因分離はできていないが、いずれも「情報量・装飾を削ってシンプルにする」方向で共通しており、この型では**凝った演出よりも実写真+最小限のテキスト**が保存・リーチの両方を伸ばす可能性が高いと推定される。以後のIG-R5投稿では、①カバーは実写真+タイトルのみ、②テロップは種目名+1行キューのみ、を初期設定にする。

**残課題**: サムネの効果とテロップ簡略化の効果を分離検証できていない。次回以降、片方だけ変えたA/Bでの比較ができるとより確度が上がる。

## IG-F1 共感質問型フィード

**フォーマット**: フィード

**出典**: threads-pdca の B型（leven_base の投稿実績）

**主指標**: コメント/保存

### 型の構造

```
【1】具体的な身体感覚・弱みの告白から入る
【2】シリアスになりすぎないよう絵文字を添える
【3】断定せず質問で終えて、読む側が自分の経験を書き込める余白を残す
```

### 効く理由

Threads では弱みの開示とコメントを誘発する質問の組み合わせで高いコメント実績がある。Instagram のフィードでもキャプションでの弱みの告白がコメントを誘発すると見込まれるが、実際の反応データによる検証はまだ無い。
