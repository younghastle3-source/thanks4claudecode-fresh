# 投稿ログ

API やスクレイピングによる自動取得は行わず、投稿後にユーザーが手渡しした実績を追記します。

## 記入方法

- 「日付」は投稿した日を `YYYY-MM-DD` 形式で記入する
- 「投稿（要約）」は投稿本文・台本の要点を1〜2行で要約して記入する（全文コピペは不要）
- 「フォーマット」は `format-guide.md` の `リール` / `フィード` / `ストーリーズ` のいずれかを記入する
- 「狙った型」は `pattern-library.md` の型 ID（例: `IG-R1`）を記入する（複数併記も可、例: `IG-F1, IG-F4`）
- 「リーチ」「フォロワー外%」「いいね」「コメント」「保存」「シェア」「プロフアクセス」は Instagram インサイトで確認できた数値をそのまま記入する
- 各指標の定義は `format-guide.md` の `## 指標の定義` を参照する
- 数値が取得できない項目は空欄にせず `-` を記入する
- 「気づき」は数値の増減理由や次に試したいことを短く記入する（週次・月次の振り返りで参照する）
- データ行は投稿の都度この表の下に追記していく。テンプレート時点ではダミーデータ・例示行を入れない
