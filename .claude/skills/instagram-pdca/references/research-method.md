# リサーチ方法論（伸びた理由の言語化→転用）

> **出典**: `sns/insutagram/伸びるリールはリサーチで決まる.md`（marketing リポジトリ: https://github.com/younghastle3-source/marketing）
> 「伸びている投稿を見つけて真似る」で終わらせず、**なぜ伸びたのかを言語化し、自分のジャンルへ転用する**ためのリサーチ手順。ワークフロー1（分析）で参考アカウントの投稿を読む際の判断基準として使う。

## リサーチの本質

リサーチ ≠ ネタ探し。「このカフェ紹介が伸びている→自分もカフェ紹介を作ろう」で終わらせず、**伸びた理由をフック・構成・感情・心理・見せ方・切り口まで分解**する。

```
発見 → 伸びた理由を分析 → 要素を分解 → 抽象化 → 自分のジャンルへ転用 → 新しい切り口
```

真似していいのは型・構成・フックの考え方・感情設計・見せ方・切り口。そのまま真似しないのはセリフ・内容・コピー・映像そのもの。

## 同一アカウント内で比較する（絶対再生数で判断しない）

フォロワー数や絶対再生数だけでは「伸びる企画」かどうか判断できない。重要なのは**そのアカウントの直近10〜20投稿（目安: 直近3ヶ月、難しければ半年以内）の通常値と比べてどれだけ突出しているか**。

- 例: 通常1,000〜2,800再生の中に840,000再生の投稿があれば、その投稿だけ明らかに突出＝分析対象
- 再生数だけ多くいいね・コメントが極端に少ない投稿は広告/PR/タイアップの可能性があるため分析対象から外す

## 感情から逆算する4ステップ

1. どこで手が止まったか？
2. その瞬間、どんな感情が動いたか？（驚き・不安・共感・懐かしさ・違和感・好奇心 等）
3. 何がその感情を発生させたか？
4. その要素を他テーマへ使えないか？

## 「具体で止めない」抽象化の例

浅い分析: 「おばあちゃんが出ていた→だから伸びた」（これでは転用できない）

深い分析: おばあちゃん → 優しさ → 温かさ → 懐かしさ → 家族 → 故郷 → **ノスタルジー**まで抽象化すると、「地元」「昔の写真」「古民家」「学生時代」など全く別の題材へ転用できる。

## リサーチ対象の優先順位

① 同ジャンル（最優先）→ ② 隣接ジャンル（ターゲットの悩み・興味が近い分野）→ ③ 異ジャンル（構成・フック・演出のアイデア用、優先度低）。まず①②だけでも十分。

他SNS（X・TikTok）で伸びた投稿はそのままInstagramにコピーしない。「Xで伸びた＝Instagramでも伸びる」ではない（ユーザー属性・アルゴリズム・好まれる表現が異なるため）。伸びた**要素だけ**抽出して転用する。

## 実践リサーチ10ステップ

1. ベンチマークアカウントを探す（同ジャンル・隣接ジャンルから）
2. 直近10〜20投稿を見る
3. 通常値を把握する
4. 突出した投稿を探す
5. 数字の違和感を確認する（広告/PR/タイアップの可能性）
6. 投稿を分解する（テーマ・フック・映像・構成・感情・心理・切り口・トレンド・出演者・CTA）
7. なぜ伸びたか仮説を作る
8. 抽象化する
9. 自分のジャンルへ転用する
10. 型×新しいテーマで新しい切り口を作る

「型をそのままコピー」より「伸びる型×新しいテーマ」の方が伸びやすい（例: 「卵パック捨てないで」型を「サラダ油のボトル捨てないで」に転用してより伸びた事例）。ただし過去のバズをそのまま真似ると市場飽和で反応が落ちるため、切り口を変える。

## 企業/クライアント案件での追加チェック

伸びることだけを目的にしない。ファクトチェック（公的機関・一次情報を優先）・炎上リスク（極端な主張を避ける）・ブランドイメージ毀損の有無を確認する。

## instagram-pdca での使い方

- **ワークフロー1（分析）**で参考アカウントの投稿を型ライブラリへ統合する前に、この10ステップで「なぜ伸びたか」まで分析してから型の判定・統合を行う
- 型を統合・追加する際の「効く理由」欄は、表面的な内容ではなく上記の抽象化（具体→感情→心理→抽象化）まで踏み込んで記述する
- 自分の投稿ログ（`my-posts-log.md`）の振り返り（ワークフロー4）でも、「同一アカウント内の通常値との差」の考え方で自分の投稿同士を比較する
