# パーソナルセッションのコミュニケーション設計

> 「何を教えるか」ではなく「どう居るか」のスキル。
> 種目選択や解剖学ではなく、セッション中のトレーナー自身の振る舞いを扱う。

前提となる業界認識：パーソナルトレーナーは資格がなくても名乗れる職業で、知識が乏しくても月商100万円規模に届くケースが実在する。その差を作っているのは知識量ではなく、相手が今何を求めているかを察知して応える力。つまりコミュニケーションは「人柄」ではなく再現可能な技術として扱える。

## 目線とアイコンタクトの設計

一番効く介入がこれ。ほとんどのトレーナーは目を合わせすぎている。

- **基本は目を合わせない。** しっかり伝えたい場面でだけ合わせる。ずっと見られ続けることは相手の身長や性格に関係なくストレスになる
- 目を合わせる＝相手を「捉えている」状態。見続けられた相手は落ち着かなくなり、「魂が抜かれる」ような疲労感を覚える
- **配分の目安は10のうち0.5程度。** 1時間のセッションで会話に充てるのが30分だとすると、実際に目を合わせるのは8分程度で足りる
- 世間話（「今日何食べました？」等）をするときも基本は目線を外し、要所で一瞬だけ合わせる
- **例外：相手が笑顔になったとき、楽しんでいるとき、ふざけて笑っているときはしっかり合わせる。** 相手が構えず自然に笑っている様子を見るのはトレーナー側にとっても嬉しい時間になる

判断基準：目線を合わせるのは「伝える」ときと「喜びを共有する」ときだけ。それ以外は外す。

## 立ち位置とパーソナルスペース

目線と同じ効果を、体の置き方だけで出せる。

- **正面に立たない。** 正面は相手のパーソナルスペースに真正面から侵入する形になり、威圧感・怖さを与える
- **斜めに立つ／斜めに座る。** パーソナルスペースから外れることで、相手が話しやすい雰囲気が自動的に生まれる
- これは相手任せの「相性」ではなく、こちらが意図的に行う操作として扱う
- 立ち位置を先に決めておけば、目線を外すことが不自然にならない（正面に立ったまま目を逸らすと、それはそれで不自然になる）

## 段階別のセッション設計

初回と2回目以降で、やることが変わる。

### 初回セッション

- 相手の正面ではなく**斜めに座る**
- 目を合わせすぎない話し方でセッションを進める
- 初回は情報を取りにいくより、相手が構えを解ける状態を作ることを優先する

### 2回目以降のセッション

- **ストレッチから入る**など、自然と目を合わせずに済む流れで開始する
- 例：「仰向けになってもらいましょう」から入ると、相手は天井を向いた姿勢になり、構造上こちらを見続けることが難しくなる。目線を外すことを相手に強いずに済む
- その体勢のまま「今日体調どうですか」といった**アイスブレイク**から会話に入る
- ウォーミングアップのローリングなどアクチベーション中にも自然と会話が生まれる状態を作っておく

## 雑談の設計

雑談は「仲良くなるため」ではなく「糸口を拾うため」にやる。

- **世間話の内容そのものには意味がない。** 客が今日何を食べたかに興味がなくても構わない
- 客自身も自分が話した内容を全部は覚えていない。だからトレーナー側も逐一覚えておく必要はない
- **ただしトレーニング処方に関わる情報だけはメモを取る。** ここが世間話と情報収集の分かれ目
- 拾い方の型：食事 → 頻度 → 意識 → 目的 → 志向、と一段ずつ深掘りして相手の動機に着地させる
  - 「今日何食べました？」→「卵かけご飯です」
  - 「卵めちゃくちゃ好きなんですか？」→「卵毎日食べます」
  - 「栄養高いですよね」→「タンパク質を考えて摂ってる」
  - 「運動してるから意識して摂ろうという気持ちに？」→「今ちょうど減量もしているので」
  - 「上昇志向があっていいですね」→「強くなりたいですね」
- 着地したところ（この例なら「減量中」「強くなりたい」）が、その日のセッションの質と今後の情報収集につながる
- 途中で「鬼滅の刃って知ってます？」のような、覚えていなくてもいい話題を挟んで会話を膨らませてよい

## 疲れないセッション運営

1日8本〜12本こなす前提で、疲労を構造的に減らす。

- **疲れの主因はコミュニケーション不足による噛み合わなさ。** 会話なしでいきなり「スクワットやっていきましょう」と入ると、お互い納得しないまま始まってしまう
- このズレはリズムの差として現れ、セッション中の空気が悪くなる。**特にトレーナー側が疲れてきたタイミングで起きやすい**ため、疲労が噛み合わなさを呼び、噛み合わなさがさらに疲労を呼ぶ悪循環になる
- 対策は事前のコミュニケーション。セッション中盤の世間話は「お客さんの心を開く土台」として機能する
- 土台があると、トレーナー自身も無理をせず適度に力を抜いた状態で臨めるため、ストレスを抱えにくくなる
- 運動指導で最も心がけるべきは「楽しいこと・面白いこと」。運動内容そのものに限らず、会話・動き・セッション全体の充実感のどれでもよい
- 達成感を伴う面白さが生まれること自体が指導の質の高さを意味し、その対価として報酬は後からついてくる、という順序で考える

### 自己肯定感の置き場所

- 承認欲求をSNS発信で満たそうとしてマインドを崩す人が一定数いる
- 対面セッションは、その承認欲求を健全な形で満たせる場になり得る。褒められて嬉しいのは客もトレーナーも同じ
- 「疲れない接客」は我慢の技術ではなく、自分が消耗しない場を設計する技術として扱う
