## 根本：営業の本質

```yaml
売る ではなく ヘルプ（助ける）:
  - 相手に売り込むのではなく、相手の悩みを解決してあげる
  - 自分が持つ商品の最大限の価値を、相手にしっかり伝えることに集中する

セールスができれば人生がイージーモードになる:
  - ビジネスだけでなく人間関係も含めた「人生のすべて」が解決する
  - 日常の中で息を吐くようにセールスができる状態を目指す
```

## 究極の営業フレーム：4ステップテンプレート

顧客との対話・提案書・LP・DM全てに使える万能構造：

```
① 問題（Problem）
   顧客が現在抱えている課題や悩みを言語化する
   例：「毎月集客に時間を取られていませんか？」

② 限界（Limit）
   その問題を自分だけで解決しようとした際の壁を示す
   例：「SNSを試したけど続かない、外注すると高い...」

③ 解決（Solution）
   自分（の商品・サービス）が提供できる具体的な解決策
   例：「AIを使えば1日10分で投稿を自動化できます」

④ 未来（Future）
   解決策によってもたらされる理想の未来を描く
   例：「集客の心配ゼロで、本業に集中できる状態になります」
```

## AI×営業の実践戦略

### LP（ランディングページ）営業

**ターゲットの見つけ方**
- Instagramは運用しているが、LPやホームページを持っていない店・個人事業主
- ブログはあるが更新が止まっている
- SNSフォロワーはいるがオファーページがない

**営業フロー**
```
1. ChatGPT / Claude / GeminiでLP草案を作成（10〜20分）
2. 「御社のSNSを見て、もっと集客できると思いご連絡しました」
3. 簡易デモを見せる（作りかけのLPで十分）
4. 「まず無料でお試しを作成します」で信頼を得る
5. 本格版の制作・運用で継続フィーを取る
```

### ハッタリ（信念）の正しい使い方

相手がAI・技術に詳しくない場合、自信を持って提案することが成約率を左右する：

```
NG（無責任な数字の約束）:
  「絶対に売上が3倍になります」

OK（感情的コミットメント）:
  「この仕組みがあなたのビジネスに絶対に役立つと
   私は確信しています」
```

> 顧客は「もうわかんない」状態になっている。こちらが自信を持って「できます」と言い切る姿勢が通用する。

### AI活用による営業効率化

**商談録音データの活用**
1. 商談を録音（iPhone / Apple Watchで十分）
2. Google AI Studio等で文字起こし
3. AIに分析させ「この顧客への最適な提案方法を提案して」と指示
4. 顧客の性格・課題・価値観を整理した提案書を自動生成

**提案書・LP作成の時短**
- 骨子：AIに作らせる（10分以内）
- 戦略部分：自分で判断
- 浮いた時間で顧客の感情に刺さるネタをリサーチ

## マネタイズの基本モデル（The Model）

```
① マーケティング（集客）
   SNS・広告で認知獲得 → 見込み客を集める

② インサイドセールス（育成）
   LINE・メルマガで教育・興味付け

③ フィールドセールス（販売）
   商品・サービスを提案・クロージング

④ カスタマーサクセス（定着）
   顧客の成功を支援 → リピート・紹介を生む
```
