# 骨格の個人差から種目を逆算する

> 「その種目が正しいか」ではなく「その人の骨格でその種目が成立するか」を先に判定する。
> 一般論として正しいフォームが、骨格によっては負荷を目的筋から逃がす原因になる。

## 出典

- リポジトリ: `github.com/younghastle3-source/training`
- ファイル: `cj advance/ハイパフォーマンス学/2026-08-21_Part128_大胸筋の徹底解説_YouTube.md`
- 索引は `.claude/skills/クロニクルジャパンcj-advance/references/lecture-index.md`。原文が必要なときは `gh api` で取得する

出典は大胸筋を題材にしているが、抽出しているのは「骨格差 → 可動域設定 → 種目選択」という判断の順序そのもの。他部位にも同じ順序で適用する。

## 骨格の個人差を見る4つの視点

種目を決める前に、この4つを確認する。いずれもトレーニングで変えられない要素なので、変える対象ではなく前提として扱う。

| 視点 | 見るポイント | 効きへの影響 |
|---|---|---|
| **腕の長さ** | 身長に対して相対的に長いか。身長が高いほど長くなりやすい | 長いほど力点と支点の距離（モーメントアーム）が伸び、力の方向のコントロールが難しくなる |
| **鎖骨の長さ** | 長いか狭いか。加えて高さがあり反り気味かどうか | 長いと大胸筋が開いた状態になり繊維を寄せにくい。狭い人の方が内転収縮が効きやすい。反り気味のタイプは何もしなくてもストレッチが入ってしまうので別枠 |
| **肩幅** | 広いか狭いか。腕の長さとの組み合わせで見る | 肩幅が狭く腕だけが長いタイプは胸が特に効きにくい |
| **胸椎の柔軟性** | 伸展が出るか。肩甲骨が前方に出る動き（前突）が確保できているか | ここが硬いと肩甲骨が置いていかれ、上腕骨だけが動いて負荷が外側に偏る |

補足：胸郭が前に出ていて鎖骨がもとから前方に位置しているタイプは、筋量以前に大胸筋が立体的に見える。これは骨格的な才能差であり、筋の付着部の位置は組織的なものでトレーニングでは動かせない。他部位でも同様（大腿骨の付着部の位置による脚の見え方の差など）。

## ストローク幅の設定

ここが判断の核心。**「フルレンジが常に正しい」という前提を疑うところから始める。**

- フルレンジは主観的には「たくさん筋肉を使えている感覚」があり、メカニカルストレス自体も強い。しかし腕が長い人の場合、実際には負荷が大胸筋上部ではなく肩関節や上腕三頭筋側に逃げている
- 大胸筋上部が発達しない人の多くは**ストロークを取りすぎている**ことが原因で、上部に負荷が入っていない
- 仕組み：プレス系で下げていくとき、肘関節が肩の後方に来るタイミングで不安定性が高くなる。本来は大胸筋で受けたいストレッチを、肩のポジションで受けてしまう
- 腕が短い人はプレス動作の下げ幅がそもそも狭いため、胸を張ったままテンションを乗せ続けやすく、上部から負荷が逃げにくい。つまり**腕が短い人は何もしなくても正解のストロークになっている**
- 戻り動作でも肩の運動に頼ると、水平内転の可動域を制御できず、上腕骨が内転方向に迫ってくる動きを抑え込めなくなる
- 腕が長いのにインクラインフライで大きなストロークを取ると、繊維を集めたいのに逆に遠くへ伸びる。ゴムを長く引っ張り続けるような状態になり、厚みが出なくなる
- 通常のフラットな骨格の人は、ストロークを無理に狭く取らなくてよい。**狭くするのは「腕が長い」「肩幅が狭く腕だけ長い」に該当する場合の処方**

## 種目選択の判断

| 対象 | 推奨 | 理由 |
|---|---|---|
| 腕が長い（大胸筋上部が入りにくい） | スミスマシン・マシンプレスを**狭いストローク**で | 操作性が高く、テンションを上部から逃がしにくい |
| ダンベル種目全般 | 積極的には推奨しない | 操作性が低い。胸に効いている感覚があっても実際は肩関節に負荷が入り、大胸筋自体は発達していないことが多い |
| インクラインで厚みを出したい | 大きなストロークは不要。ダンベルインクラインプレス等の**収縮ポジション中心**の種目 | 腕が長いと伸ばすほど繊維が散るため、集める側に振る |
| テンションを切らしたくない | スミスマシンインクライン | 軌道が固定されているため胸を張ったポジションを保ちやすい |
| 大胸筋の内側が育たない | 種目を足す前に胸椎伸展のモビリティワーク | 肩甲骨の前突可動域がないと、何をやっても外側で受けてしまう |
| 骨格がフラット・腕が長くない | 通常のフリーウェイトでよい | ストローク制限は不要。処方を当てはめない |

### 内側が育たないケースのメカニズム

ストレッチポジションで肩甲骨が離れていく際、肩甲骨側の柔軟性がないと肩甲上腕関節あたりでしか動かず、上腕骨だけが離れていく。本来は胸の真ん中で受け取りたい負荷を、外側寄りで受けてしまう。これを繰り返すと外側へのストレスだけが毎回高くなり、外側ばかりが発達する。外側が発達すること自体は問題ではないが、筋腹は真ん中にあるためバランスとして不自然になる。

対策の順序は **胸椎伸展の確保 → 肩甲骨の前突が出る → 内側で受けられる** であって、内側狙いの種目を足すことではない。

## 判断アルゴリズム

「効かない」と相談されたときに上から順に回す。

1. **骨格を確認する。** 腕の長さ（身長比）・鎖骨の長さと反り・肩幅・胸椎伸展の4点を見る。ここを飛ばして種目の話に入らない
2. **どこで負荷が逃げているかを特定する。** 上部が入らない → ストロークの取りすぎを疑う。内側が入らない → 胸椎・肩甲骨のモビリティ不足を疑う。この2つは原因も対策も別物なので混ぜない
3. **ストローク幅を先に決める。** 種目より先。腕が長い／肩幅が狭く腕だけ長い場合は狭く取る。フラットな骨格なら制限しない
4. **決めたストロークを保持できる器具を選ぶ。** 狭いストロークを保持したいならスミスマシンかマシンプレス。ダンベルは操作性が低く意図したストロークを維持しにくいので、この局面では選ばない
5. **感覚ではなく変化で検証する。** 「効いている感覚」は肩関節に入っていても発生する。数週間単位の見た目・挙上重量の変化で判定する
6. **硬さがある状態で可動域を広げにいかない。** 柔軟性がある状態で伸ばすと気持ちよいが、硬い状態で同じ動きをすると「ビキッ」という痛みが出る。ビハインドネックのバックプレスやラットプル系で肩が前方に入って痛むケースが典型。可動域はモビリティで先に作る

## 適用範囲と限界

- **4視点は目視・簡易評価。** 画像診断ではないので、痛みが出ている場合は種目選択の前に評価プロセスへ回す（`.claude/skills/shoulder-pain-rehabilitation/`）
- **骨格は変えられない。** このスキルは「弱点を克服する」ものではなく「骨格に合う設定を選ぶ」もの。付着部の位置を動かそうとする方向には使わない
- **出典は大胸筋の解説。** 「骨格差 → 可動域設定 → 種目選択」の順序は他部位にも転用できるが、部位ごとの具体値（どの視点が効くか）までは検証されていない。転用するときは仮説として扱う
- **出典の末尾は途中で切れている。** ペクトラルフライマシンでの代償動作についての論点は文字起こしの時点で未収録。ここを詰めたい場合は原本の動画側を当たる必要がある
- **万人向けの処方ではない。** ストローク制限は腕が長いタイプへの処方であり、フラットな骨格の人に当てはめると単に可動域を削るだけになる
