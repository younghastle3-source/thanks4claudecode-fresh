# LP設計スキル（平石式）

> **「行動を起こさせるLPは、5つの問いに答えている」**

## 人が行動を起こすLPの5ヶ条

LPを見た人が「買う・申し込む・問い合わせる」を決める5つの問い。**全て答えられていないとCVしない。**

| # | 問い | 説明 |
|---|------|------|
| 1 | **何の商品・サービスか一目でわかる** | ページを開いた瞬間に提供価値が伝わること |
| 2 | **得られる未来が一目でわかる** | 利用後の理想的な結果を視覚的に示すこと |
| 3 | **なぜその方法なのかがわかる** | 他の選択肢ではなく、なぜこれが優れているか |
| 4 | **なぜあなたなのか納得できる** | なぜこの人・会社から買うのか、信頼・独自性 |
| 5 | **なぜ今なのかの理由がある** | 緊急性・限定性で「今」行動すべき理由を提供 |

---

## LPの鉄板構成（悩み解決型）

```
① キャッチコピー
   → ユーザーの注意を引き、関心を惹きつける見出し
   → 「誰の・どんな悩みを・どう解決するか」を一瞬で伝える

② 悩み・ニーズへの共感
   → 「こんな悩みありませんか？」と寄り添う
   → 問題を言語化してあげることで「これ私だ」と感じさせる

③ 得られる未来（ベネフィット）の提示
   → 問題が解決された後の理想状態を具体的に描く
   → 機能ではなく「変化後の感情・生活」を見せる

④ 根拠・実績の提示（信頼）
   → データ、実績数値、専門性、受賞歴、メディア掲載など
   → 「本当に効果があるのか？」の不安を取り除く

⑤ お客様の声（安心）
   → 実際の利用者の体験談・Before/After
   → 「自分と同じような人が成果を出している」を見せる

⑥ クロージング（簡便性・希少性・特典・保証）
   → 申し込み手順をシンプルに見せる（3ステップ等）
   → 期間限定・数量限定・特典で「今」行動させる
   → 返金保証で心理的リスクを下げる

⑦ ストーリー・想い
   → 開発背景・提供者の情熱・なぜこれを作ったか
   → 感情的なつながりを生み、ファン化する
```

## ✅ LP添削チェックリスト

**5ヶ条チェック**
- [ ] ファーストビューで「何の商品か」が1秒でわかるか
- [ ] 「使った後どうなるか」がビジュアルまたは文章で伝わるか
- [ ] 「なぜこの方法か」の理由が説明されているか
- [ ] 「なぜこの人・会社か」の信頼根拠があるか
- [ ] 「なぜ今か」の緊急性・限定性があるか

**構成チェック**
- [ ] ①〜⑦の要素が全て揃っているか
- [ ] キャッチコピーが「誰の・どんな悩み」を含んでいるか
- [ ] ベネフィットが「機能」ではなく「変化後の感情・状態」で書かれているか
- [ ] お客様の声が「Before/After」または「具体的な数字」を含むか
- [ ] CTAボタンが明確で選択肢が1つか

---

## このスキルの使い方

1. ユーザーから「商品・ターゲット・悩み・ベネフィット」を受け取る
2. 5ヶ条に沿って情報を整理する
3. ①〜⑦の構成でLPの骨格を作成する
4. チェックリストで確認する

**連携スキル：**
- `marketing-kubota.md`：ペルソナ・USP・ベネフィットの設計
- `instagram-hook.md`：キャッチコピーのフック設計（数字×ネガティブが有効）
