# 人間味ライティング

## 第1章：体験と感情が「情報」を超える原則

```yaml
情報だけでは読者は動かない理由: |
  情報過多の時代——GoogleでもChatGPTでも、知りたいことは数秒で手に入る。
  そんな時代に誰かの投稿を最後まで読む理由は「そこにしかない特別な何か」があるから。

AIには絶対に真似できない価値: |
  それは「体験」と、それに紐づく「感情」。
  
  AIが書く: 「昨日は業務上の困難に直面し、精神的に落ち込みました」
  人間が書く: 「昨日は仕事で大失敗して、もうダメだ…って思ったんです」
  
  後者の方が心に響く。自分の弱みや感情を正直に書くことで
  読者は「この人も私と同じだ」と共感し、親近感を抱く。

この人の話なら聞きたい: |
  SNSで本当に大切なのは完璧な文章や正確な情報だけじゃない。
  「この人の話なら聞きたい」「この人となら繋がれる」
  そう読者に思ってもらえるかどうか。

  あなたが書くべきなのは、どこかに書いてある情報のまとめではなく、
  あなたの人生を通して感じた「生々しい体験談」。
  共感が、情報を超えて人を動かす。
```

## 第2章：人間味ライティング3つの具体策

### 具体策①：体験ストーリーへの変換

```yaml
やりがちな失敗: |
  「今日は〇〇をしました」という単なる日記で終わってしまうこと。
  読者は「ふーん」でスクロールする。

魔法の公式: 出来事 ＋ 感情 ＋ 学び

例（Before）: 「子どもがお手伝いをしてくれた」

例（After）: |
  この前、うちの子が「自分でお茶を注ぎたい！」って言い出したんです。
  正直、私の心の声は「絶対こぼすじゃん…！」でした（笑）。
  でもその真剣な顔を見て、ハッとして——
  タオルを敷いて見守ったら、一滴もこぼさずに注げたんです！
  
  「こぼされたら嫌だ」っていう私の都合で、
  子どもの成長のチャンスを奪うところだった。
  先に失敗を恐れていたのは、私の方だったんですね。

ポイント: |
  その時感じた素直な気持ち（ネガティブなものでも）を言葉にすること。
  失敗談・挫折した話も、正直にさらけ出すことで共感を生む。
```

### 具体策②：読者との距離をゼロにする会話スタイル

```yaml
SNSはコミュニケーションの場: 論文発表の場ではない。

テクニック1_フォーマルすぎる表現をやめる: |
  ✗「〜でございます」「〜のほど、よろしくお願い申し上げます」
  ○「〜だよ！」「〜だよね？」
  
  友だちに話しかけるような言葉遣いを意識するだけで、
  ぐっと人間味が増す。

テクニック2_読者に問いかける: |
  「〜なこと、ありませんか？」「あなたはどう思いますか？」
  一方的に情報を伝えるのではなく、読者を会話に巻き込むことで
  「ああ、これは自分のための文章だ」と感じてもらえる。

感覚: 目の前にいるたった一人のお客様に語りかける
```

### 具体策③：説得力が爆上がりするPREP法

```yaml
PREP法とは: |
  P (Point)   : 結論
  R (Reason)  : 理由（共感）
  E (Example) : 具体例・エピソード
  P (Point)   : 結論の再提示
  
  この順番で書くだけで、文章はどんな人が読んでもわかりやすく、
  説得力を持つようになる。

使用場面: |
  - 専門知識や経験をわかりやすく伝えたいとき
  - お客様の声・事例を説得力を持って届けたいとき
  - サービスの魅力を「売り込みにならず」伝えたいとき

効果: 結論が最初と最後にくるのでメッセージが記憶に残りやすい
```

## 第3章：ChatGPTを「編集パートナー」として使う

### 役割分担の原則

```yaml
よくある失敗: AIに「ゼロから文章を作らせよう」とすること
→ これが無機質で冷たい「AIっぽい文章」が生まれる原因

正しい役割分担:
  あなた: 文章の「魂」となる体験談・感情を吹き込む
  AI  : あなたの下書きを整形・ブラッシュアップする

手順:
  1. 第2章の方法で、荒削りでいいので「魂のこもった下書き」を自分で書く
  2. 下書きをChatGPTに渡して整形をお願いする
```

### プロンプト①：口語調に変換する

```
以下の文章を、ペルソナさんに響くように書き直してください。

【ペルソナ】
ここに届けたい相手を書く

【元の文章】
ここに書き直したい文章を貼る

【書き方の希望】
・お客様に直接話しかけるように
・親しみやすく、温かい雰囲気で
・ペルソナさんが「わかる！」と共感できる言葉で
・私の想いや感情も自然に伝わるように
・かたい文章ではなく、やさしく読みやすく
・売り込み感は強くしすぎず、でも魅力は伝わるように

この条件で、自然な文章に整えてください。
```

### プロンプト②：冗長削除・テンポ改善する

```
以下の文章から、冗長な表現や回りくどい言い回しを削って、
もっと簡潔でテンポの良い文章にしてください。
スマホで読んでもスラスラ頭に入るように、リズムを整えてほしい。

（ここにあなたの書いた下書きを貼り付け）
```

### プロンプト③：PREP法で再構成する

```
以下の文章を、説得力のある「PREP法」に沿って再構成してください。

【元の文章】
ここに文章を貼る

【希望】
・結論 → 理由（共感） → 具体例 → 結論の流れでわかりやすく整える
・読者が「なるほど」「たしかに」と思えるように説得力を出す
・私の体験談は、事実を変えずに、読者に伝わりやすい形に整理する
・体験談の中にある感情や気づきが自然に伝わるようにする
・かたい文章ではなく、親しみやすく温かい言葉で
・最後は読者が前向きに行動したくなるように整える

この条件で、自然な文章に書き直してください。
```

## AI出力の自己チェック3視点

### チェック1：声に出して読む

```yaml
方法: AIが出した文章をそのまま声に出して音読する
気づけること:
  - 「私こんな言い方しないな」
  - 「なんかきれいすぎるな」
  - 「普段もっと違う言葉で伝えてるな」

黙って読むと気づかない違和感が、声に出した瞬間に出てくる。
違和感があった部分は、どんどん自分の言葉に変えていく。
AIが出した文章を「正解」と思わなくていい。
```

### チェック2：AIっぽい記号を整える

```yaml
見直すべき記号:
  ✗ 「——」（ダッシュ）は使わない
  ✗ 「✅」「✔」を連発しない
  ✗ " " は「 」に変えるか外す

例:
  Before: 「大事なのは——"正しい投稿"ではなく、"届く投稿"を作ること。」
  After : 「大事なのは、正しい投稿をすることじゃなくて、「届く投稿」を作ること。」

毎回同じような装飾が入っていると、一気にAIっぽく見えてしまう。
```

### チェック3：体験と感情が入っているか確認する

```yaml
AIが出しがちな文: 「発信で大切なのは継続することです。」（誰でも言える）

体験と感情を入れると:
  「実は私、インスタを半年頑張ったのに150円しかならなかった。
   スレッズも3ヶ月毎日投稿したけど売上ゼロ。
   でも諦めたくなくて、6割の完成度でもとにかく投稿・分析・また投稿。
   それを繰り返した結果、今ではスレッズ4アカウントで成果が出ています。
   
   だから私は、発信で大事なのは完璧な投稿を作ることじゃなくて、
   必要な人に届くまで諦めないことだと思うんです。」

入れるもの:
  - 自分の過去・失敗
  - その時の感情（悔しかった・嬉しかった・焦った・諦めたくなかった）
  - そこからの気づき

悔しかったこと・嬉しかったこと・本気で焦ったこと——
そこにある感情は、あなたにしか書けない。
```

## 使い方ガイド

### 投稿文作成フロー

```
1. まず自分で下書きを書く（荒削りでOK・感情むき出しで）
2. 「体験ストーリー」「会話スタイル」「PREP法」のどれを使うか決める
3. プロンプト①〜③のいずれかでChatGPTに整形を依頼
4. 出力を声に出して読み、記号と体験・感情を自己チェック
5. 違和感のある箇所を自分の言葉に直す
6. 投稿
```

### AI vs 人間の役割早見表

| やること | 担当 |
|---|---|
| 体験談・感情を書く | あなた |
| 失敗・葛藤をさらけ出す | あなた |
| 文章を口語調に整える | ChatGPT |
| 冗長な部分を削る | ChatGPT |
| PREP法に並び替える | ChatGPT |
| 「これ私の言葉か？」の最終確認 | あなた |
