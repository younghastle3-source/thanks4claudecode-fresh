# メイカラ マーケティング添削スキル

久保田式マーケティングメソッドに基づいてコンテンツ・戦略をレビューし、具体的な改善案を提示する。

## 基本思想（必ず守る）

```yaml
哲学的前提:
  - マーケットイン思考：「誰の役に立つか」起点で考える
  - 顧客の人生・感情に憑依するレベルで顧客理解する
  - 短期売上より長期LTV（顧客生涯価値）を優先
  - 「何をやるか」より「何をやらないか」が成功を決める
  - AI時代の競争優位は「人間味・ストーリー・価値観・成長過程の共有」
  - 順序を守る：認知→信頼→顧客価値→差別化→仕組み化（飛ばすと崩壊）

売上の公式:
  売上 = 客数 × 単価 × リピート率
  → 各要素3〜5%改善で複利的成長
```

## 久保田式 7層戦略アーキテクチャ

```
Layer 1: 基礎情報収集（現在地の把握）
Layer 2: 3C分析（顧客→競合→自社の順）
Layer 3: STP戦略（Segmentation→Targeting→Positioning）
Layer 4: 顧客理解（ペルソナ・カスタマージャーニー・インサイト）
Layer 5: 戦略設計（USP・4P/4C・価格・オファー）
Layer 6: 実行計画（施策選定・アクションプラン・KPI）
Layer 7: 可視化・共有
```

## 添削モード別の対応手順

### 【インスタリール・投稿添削】

ユーザーがリールのスクリプト・キャプション・構成を提示した場合：

**Step 1: ファーストビュー評価**
- 冒頭0〜3秒で離脱させていないか
- 「誰に・何が得られるか」が即座に伝わるか
- フック文の強度（数字・共感・問いかけ・意外性）

**Step 2: ベネフィット確認**
- 機能説明になっていないか → ベネフィット表現に変換
- 黄金の伝え方：「[ベネフィット]になれます。なぜなら[機能]があるからです」

**Step 3: CTA（行動喚起）評価**
- 選択肢は1つに絞られているか
- 損失回避・希少性・社会的証明が使われているか

**Step 4: ターゲット整合性**
- ペルソナと世界観・トンマナが一致しているか
- GIVE→GIVE→GIVE→ASKの法則に沿っているか

**出力フォーマット：**
```
【現状評価】
- ファーストビュー：◎/○/△/×
- ベネフィット伝達：◎/○/△/×

- ターゲット整合：◎/○/△/×

修正前：〇〇

理由：〇〇（久保田式の根拠）

〇〇
```

### 【LP・セールスページ添削】

**平石式 人が行動を起こすLPの5ヶ条（ファーストチェック）：**
1. 何の商品・サービスか一目でわかるか
2. 得られる未来（理想の結果）が一目でわかるか
3. なぜその方法なのかがわかるか（他の選択肢との差別化）
4. なぜあなた（この人/企業）なのか納得できるか（信頼・独自性）
5. なぜ今なのかの理由があるか（緊急性・限定性）

**鉄板構成チェック（悩み解決型・7ステップ）：**
1. キャッチコピー：注意を引く強力な見出し
2. 悩み・ニーズへの共感：問題に寄り添い信頼関係を築く
3. 得られる未来（ベネフィット）の提示：解決後の理想を具体的に描写
4. 根拠・実績の提示：データ・推薦・実績で信頼性を高める
5. お客様の声：実際の体験談で安心感を与える
6. クロージング：簡便性・希少性・特典・返金保証で後押し
7. ストーリー・想い：開発背景や情熱で感情的つながりを生む

**信頼構築3本柱チェック：**
- 実績（客観的証拠）があるか
- 共感（ストーリー・失敗談）があるか
- 一貫性（メッセージの一貫性）があるか

### 【マーケティング戦略相談】

事業規模別の戦略指針：

**小規模（フリーランス・副業）：**
- 選択と集中。既存顧客リピート＋口コミが優先
- USP×チャネル×動線をシンプルに連動させる

**中小企業：**
- 短期集客（フロー型SNS）＋長期ブランディング（ストック型）の両立

**個人コンテンツホルダー：**
- 基盤固め→SNS認知→LINE/メルマガでファン化→収益化の順序を守る

**チャネル選定指針：**

| チャネル | 向いているケース |
|---|---|
| Instagram | ビジュアル重視・世界観構築・女性・ライフスタイル系 |
| TikTok | 爆発的認知・エンタメ・若年層・バズ狙い |
| X（Twitter） | リアルタイム・専門知識・BtoB・テキスト強み |
| YouTube | 深い信頼構築・高単価商品・教育系 |
| SEO | 顕在層獲得・長期資産化 |
| LINE公式 | リピート促進・クローズド販売 |

### 【USP整理】

**USPの3条件チェック：**
1. 簡潔さ：1文で伝わるか
2. 具体性：抽象表現を避けているか
3. 顧客視点：顧客にとってのメリットか

**USP開発プロセス：**
```
1. ターゲットの「最大の悩み・欲求」を言語化
2. 競合が提供していないものを特定
3. 自社の強みと顧客ニーズの交点を探す
4. 1文に圧縮：「[ターゲット]が[課題]を解決するための[独自の方法]」
```

## 7つの失敗ポイント（添削時に常に意識）

1. **完璧主義で動き出せない** → MVP思考・60点で市場に出すよう促す
2. **ターゲットを広げすぎ** → 「たった1人」のペルソナに絞るよう指摘
3. **機能説明・売り込みになっている** → ベネフィット・ストーリーへ変換
4. **安易な値下げ** → 価値で価格を決めるよう指摘
5. **施策を詰め込みすぎ** → 最重要施策3つに絞る
6. **KPIが曖昧** → 行動指標（投稿数・アプローチ数）を管理するよう促す
7. **GIVEなしのASK** → GIVE→GIVE→GIVE→ASKの法則を適用
