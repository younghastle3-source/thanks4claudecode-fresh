# HYROX（ハイロックス）スキル

> 出典：わたり氏（HYROX PRO選手・認定パフォーマンスコーチ、RedBull HYROX Coaches Camp 2025参加）の実践知見

---

## 1. HYROXとは

```yaml
定義: The World Series of Fitness Racing（公式定義）
コンセプト: あらゆるフィットネスレベルの人が参加できる世界規模インドアレース
完走率: 約98%（制限時間なし）
カテゴリー区分:
  年代: 16〜24歳から5歳刻み、70歳以上まで
  重量: OPEN（軽量）/ PRO（重量）
  人数: 個人 / ペア（Doubles）/ 4人チーム（Relay）
表彰: 年代別カテゴリーごとに実施。PRO年代別優勝者は世界選手権の出場権を獲得
  （60歳以上はOPENカテゴリーでも出場権獲得可）
特徴: 世界中どの大会もコース設定・ワークアウト内容が共通 → 世界ランキングで自分の位置を比較できる
```

## 2. 競技内容・ルール（8ラン＋8ワークアウト）

「1kmランニング＋1ファンクショナルワークアウト」を8回繰り返す。合計8kmランニング＋8種目。

| # | ワークアウト | 距離/回数 |
|---|---|---|
| 1 | SkiErg（スキーエルゴ） | 1,000m |
| 2 | Sled Push（ソリを押す） | 50m |
| 3 | Sled Pull（ロープでソリを引く） | 50m |
| 4 | Burpee Broad Jumps（幅跳びバーピー） | 80m |
| 5 | Rowing（ローイング） | 1,000m |
| 6 | Farmers Carry（重りを持って歩く） | 200m |
| 7 | Sandbag Lunges（サンドバッグランジ） | 100m |
| 8 | Wall Balls（的当てスクワットスロー） | 100回 |

**注意**：会場レイアウトにより1回ごとのランニング距離は変わる（1回目が短いことが多い）。リレーは周回・交代ゾーンが異なる。

### ランニングのレーン分け
- 内側レーン：1km4分以下ペース専用
- 外側レーン：1km4分以上ペース専用
- ゆっくり走る人は外側を使う（内側で詰まると速い選手の妨げになる）
- ダブルスは横並びでなく前後で走る

### ROX ZONE
ランニングコースとワークアウトエリアの間の通路。給水ポイントがある。タイム狙いは休憩を短く・頻度少なく。

### 周回ミスはペナルティ
迷ったら早めに『IN』に入り、後でペナルティを受ける方が、過剰に周回してさらにペナルティになるより速い。

## 4. トレーニングの2本柱

### 柱① ランニング（全行程の50%以上、競技時間の約60%を占める）
```yaml
ベース走: 週1〜2回、45〜60分のゆっくりジョグで基礎体力
インターバル走: 例 1km×8本などレースペースより速い速度で心肺強化
コンプロマイズド・ラン（複合ラン）: 最重要。スクワット/ランジ等で脚を追い込んだ直後に走る
  → 「重い脚」で走る感覚に慣れる
```

### 柱② ストレングス（下半身・体幹）
```yaml
主要種目: スクワット、デッドリフト、ランジ、プッシュプレス
重視する能力: 高重量1回より中重量20〜30回繰り返せる持久的筋力
```

## 5. シューズ・ウェア

- シューズ：カーボン入り（スピード）か安定性重視か、スレッド系で滑らないグリップ力かはトレードオフ
  - おすすめ：多少の安定性を犠牲にしてスピードが出やすいランニングシューズ
- ウェア：上半身裸でなくてもよい。コスプレ参加もあり。好きなシャツでOK
  - 明るいカラーは応援する側が見つけやすい。ダブルスはお揃いシャツも醍醐味
- ギア規定：膝サポーター・手袋は可（外部からの受け渡しは禁止）。パワーグリップ等握力補助系の手袋はNG（グレーゾーン）

## 6. 食事・栄養・補給

```yaml
レース前: カーボローディング（食べ過ぎ注意）。午前早いレースは固形物を控える
レース中の補給: 1時間以上の運動なので電解質・ジェルを検討
  給水: ワークアウト2区切りごとが目安（毎回は時間ロス、ゼロは足攣りの危険）
ジェル運用例（わたり氏）:
  - シングルス: カフェイン入りジェルを召集直前に1つ（覚醒作用、練習で試してから本番投入）
  - ダブルス: パートナーのワークアウト中に気休め程度で1つ
```

## 7. レース当日の流れ

```
1. 会場到着・選手受付（スタート90〜120分前）
   → QRコード+身分証提示、リストバンド・スタートナンバー受領
   → スタートナンバー = スタート時刻+通し番号（例: 1700006 = 17:00スタート006番）
   → 電子機器・撮影器具の持込は基本禁止
2. コース確認（ステーション位置・給水・トイレ・周回モニター位置）→動線を決める
3. ウォームアップ（リストバンド保持者専用エリア。器具数は会場差あり）
4. スタートエリア集合（10分前にグループ招集→テクニカルブリーフィング→スタートゾーン）
5. レース本番（Run→8ステーションを交互に8セット）
6. フィニッシュ（最後のWall Balls後にゴール、ポーズを決めておく）
7. 公式フォト撮影（タイムチップ読み取り）
8. リカバリーエリア（補食・ドリンク提供、Finisherパッチ受領、チップ・バンド返却）
9. リザルト確認（会場モニター・速報サイト）
10. 物販・スポンサーブース
```

### 当日の重要アドバイス
1. **周回数を間違えない**：最多ミスは「ランニング周回不足」。モニターで自分の名前と残り周回を確認
2. **給水は一口程度**：飲みすぎると次ワークアウトで体が重くなる
3. **Wall Ballsのために足を残す**：最後が最も精神的・肉体的にきつい。手前のランで出し切らないペース配分が重要
4. **チップ返却を忘れない**：忘れると費用が発生する場合がある

### 撮影について
オフィシャルフォトグラファー以外は観客席から撮影可能。撮影者は対象者のペース・ステーション順序・到達タイミングを予測して動く必要がある。

## 8. クラス・練習会の設計パターン

ルールは認定ジム/HYROX Performance Coachに教わるのが前提。練習タイプは3方式＋使い分け：

| 方式 | メリット | デメリット |
|---|---|---|
| ①種目特化型 | 種目に集中して練習できる | 全種目できない、やりたい種目を選べない |
| ②トレーニング型（AMRAP中心） | ずっと動き続け体力ベースを作れる、総量を増やせる | 正規距離/回数でやらないためペース配分が分からない |
| ③実践型 | 実際の距離・回数でペース配分を把握できる | 初心者は制限時間内に完遂できない場合がある |

### わたり氏のクラス構成例
```yaml
Beginner class: 8種目のルール・コツ説明＋各種目体験（約40分）
Advanced class: 実践型メニュー（本番に近い距離・重量）
Simulation class: 550m×8 Run＋8種目を実際の距離/重量で。1人(組)ずつ8分おきウェーブスタート
Open gym class: 自主トレ形式。種目特化やペア練習向け
貸切クラス: 最低10名、要望に応じて展開
Running form/training class: フォーム作り・ランニング基礎ドリル（現在休止）
```

設計方針：施設の器具数・広さを考慮し実践型を中心に据える。HYROXはペース配分が結果を左右するため。

## 9. 種目別 必要能力 × 補強トレーニング

| 種目 | 必要な能力 | 補強トレーニング例 |
|---|---|---|
| Run | 片脚支持の安定性、ハムストリング主導の推進力、骨盤・体幹固定、疲労下のフォーム維持 | シングルレッグRDL、デフィシットスプリットスクワット、シングルレッグヒップスラスト、ステップアップ、コペンハーゲンプランク、Aスキップ |
| SkiErg | 広背筋主導の引く力＋三頭、体幹固定下の股関節ヒンジ、上下連動のリズム | バーベルロウ系、RDL、プルアップ、プルオーバー、ラットプルダウン、プレスダウン、ライイングトライセプス |
| Sled Push | 大腿四頭筋の持久力、低姿勢での体幹固定、股関節伸展パワー | フロント/バックスクワット、スプリットスクワット、ゴブレットスクワット（高回数） |
| Sled Pull / Row | 背中・腕の持久力、体幹のアンチローテーション、ヒンジパターンの持久力 | ベントオーバーロウ、ゴリラロウ、デッドリフト、スーツケーススクワット |
| Burpee Broad Jump | 全身連動、高心拍下の出力、着地耐性 | シーテッドジャンプ、ジャンプスクワット、マウンテンクライマー、スプロウル、バーピージャンプ、ボックスジャンプ |
| Farmers Carry | グリップ、体幹の抗側屈、歩行中の姿勢制御 | シングル/ダブルフロントラックキャリー、ファーマーズキャリー、オーバーヘッドキャリー、サイドプランク |
| Lunges | 片脚筋力、股関節可動域、左右差耐性 | フォワード/リバース/ペンデュラム/ウォーキングランジ、シングルレッグスクワット、コサックスクワット |
| Wall Balls | スクワット持久力、肩のスタミナ、呼吸下のリズム | スラスター、ショルダープレス、プッシュプレス |

### トレーニングの組み立て3パターン
```yaml
①Strength: パワー強化日。中負荷・高回数・休憩短め
②Running: 走力アップ日。5〜10km走 or インターバル（400m速度強化、800〜1000m×6〜8本）
③Hybrid（Compromised running）: ラン×トレーニングを混ぜる。本番に近い状態で実施
  → 練習時間が少ないならこれ一択（筋トレ・ランも最低限は継続すること）
```

## 10. トレーニング用語集

| 用語 | 正式名称 | 特徴 | 使う場面 |
|---|---|---|---|
| AMRAP | As Many Rounds(Reps) As Possible | 時間固定、できる限り回す。後半キツくなる | 体力チェック、心肺強化、限界把握 |
| EMOM | Every Minute On the Minute | 1分ごとに課題量が決まっている。強度設定が難しい（1分間最大回数の60〜80%が目安） | ペース感覚・フォーム維持の練習 |
| RFT | Rounds For Time | 量固定、速さを競う | レース練習、追い込み、全力トレーニング |
| RPE | Rate of Perceived Exertion | 自覚的運動強度（自分の感覚メーター） | 体調差を反映した強度調整 |
| RIR | Reps In Reserve | あと何回できたか（0=限界、1=ぎりぎり…5=ウォームアップ） | 筋トレの重量設定 |

### EMOM強度設定の考え方
1分間の最大回数の60〜80%を課題に設定する（例：Wall ball最大20回/分なら12〜16回/分）。高すぎると後半到達不能、低すぎると休憩過多で練習効果が薄れる。

### よくある失敗パターン
```
❌ 毎日RIR 0
❌ レース2週間前もRIR 0
❌ 疲れているのに「予定通り」
👉 強度は「予定」ではなく「状態」で決める。休む勇気も必要。
   RPEで体の声を聞き、RIRで筋肉とフォームを守る。
```

## 11. レースペース戦略（わたり流）

```yaml
ペース算出方法:
  好調時: 疲れていない状態で1000mタイムトライアル → そのままレースペースに設定
  疲労時: 2000mタイムトライアルで疲労下ペースを算出（バックアッププラン）
Ski/Rowのケイデンス: 出力を上げて動作数（回転数）を減らす作戦も選択肢
  （体格・筋力・心肺レベルにより最適値は個人差あり）
種目ごとの限界把握:
  - Burpee: 両足引き付けがキツくなる距離を把握→フォーム変更点を決めておく
  - Farmers Carry: 限界が来る距離より手前で区切って置く回数を決めておく
  - Lunges: 継ぎ足に切り替えるタイミングを把握（継ぎ足はスピード低下と引き換えに足を休める）
  - Wall Balls: 自己ベスト/目標タイムを把握しておく
Sled Push/Pull:
  - Turf摩擦は当日まで読めない。重さを段々上げて練習し動揺しないようにする
  - Push: 刻み方（区切り回数）を複数パターン用意してレース中に切替
  - Pull: バックステップで体重を活用、しゃがみ込み過多で立ち上がりが遅くならないよう注意
心拍ゾーン: HYROXは高強度で動き続ける体力（ZONE4-5）のトレーニングが必須
  （マラソン同様ZONE2のベース作りも軽視しない）
```

## 12. データで見るHYROX（HYROX Sports Science Report 2025 サイエンスレポート要旨）

```yaml
- 競技時間の約60%がランニング
- 競技時間の70%以上が高〜最大心拍数ゾーン
- HYROXは高強度ファンクショナルトレーニング（HIFT）だが本質は持久力（Endurance）
- 総合タイムと最も相関が高いのは「中盤以降のRun」
- 影響度が高い種目：Wall Balls、Burpee Broad Jumps（実体験ではLungeも差が出やすい）
- 選手タイプ分類: ① RUNNER ② HYBRID ③ POWERHOUSE
```

参考：公式ルールブック（hyroxjapan.com）は出場前に必読。

## 13. 相談対応パターン

依頼を受けたら以下のパターンから選んで対応する：

### パターンA：初めてのHYROX理解・出場判断サポート
```
使う情報: 出場予定大会、カテゴリー（OPEN/PRO・個人/ペア/リレー）、運動経験
出力: 競技概要・ルールの要約、参加費の見積もり、当日の流れチェックリスト
```

### パターンB：トレーニングメニュー設計
```
使う情報: 現在の走力（10km/フルマラソン等の記録）、筋トレ歴、苦手種目、レースまでの期間
出力: ①Strength ②Running ③Hybridの週間配分案、苦手種目の補強トレーニングメニュー
  （EMOM/AMRAP/RFTを適切に使い分けて提示）
```

### パターンC：レース当日のペース・作戦設計
```
使う情報: Ski/Rowの1000m・2000mタイムトライアル結果、種目別の失速ポイント、目標タイム
出力: 好調/疲労時の2パターンのペース設定、種目別の区切り方戦略、給水タイミング
```

### パターンD：クラス・練習会の構成設計（コーチ向け）
```
使う情報: 施設の器具数・広さ、参加者レベル、開催頻度
出力: 種目特化/トレーニング型(AMRAP)/実践型のバランス設計、クラス区分（Beginner/Advanced/Simulation等）
```
