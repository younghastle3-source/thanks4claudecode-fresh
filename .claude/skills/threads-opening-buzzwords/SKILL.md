# Threads 冒頭バズワード50選

## なぜ冒頭1行が重要か

```yaml
本質: |
  中身がいくら良くても、冒頭でスクロールされたら届かない。
  本屋の表紙と同じ——最初の1行が「手に取るかどうか」を決める。
  センスや才能ではなく、「型を知っているかどうか」の差。
使い方: |
  1. 今書いている投稿の「伝えたいこと」を確認する
  2. 6カテゴリの中から投稿の目的に合ったものを選ぶ
  3. リストから冒頭フレーズを1つ選び、〇〇部分を自分の内容に置き換える
```

## カテゴリ1：呼びかけ・お願い

```yaml
使用シーン: |
  特定の悩みや状況を持つ読者に「これは私のことだ」と気づかせたいとき。
  ターゲットを絞り込んで、刺さる人に深く刺さる投稿にしたいとき。
```

4. 教えてください！

6. 〇〇な人、聞いて
7. 〇〇してない？
8. 〇〇って思ってない？
9. 本気の人だけ読んでください

## 使い方ガイド

### カテゴリ選びの判断軸

| 投稿の目的 | 使うカテゴリ |
|---|---|
| 特定の悩みを持つ人に届けたい | カテゴリ1（呼びかけ）/ カテゴリ5（共感） |
| 知識・ノウハウを伝えたい | カテゴリ3（有益・裏技）|
| 本音・裏側を打ち明けたい | カテゴリ2（衝撃・暴露）|
| 大切なことを強調したい | カテゴリ4（重要・念押し）|
| 結論を先に出したい・保存させたい | カテゴリ6（アクション・短文）|

### 〇〇の埋め方

```
〇〇な人、聞いて → 「子育て中でも副業したい人、聞いて」
〇〇の裏技教えます！ → 「Threads集客の裏技教えます！」
〇〇で悩んでいる人へ、 → 「発信が続かないことで悩んでいる人へ、」
〇〇の人、集合！ → 「3ヶ月投稿しても反応がなかった人、集合！」
```

### 組み合わせて使う

```yaml
例1（共感＋有益）: |
  「もっと早く知りたかった。」
  ＋ Threads集客でやって正解だった3つのこと。

例2（呼びかけ＋本音）: |
  「投稿しても反応がない人、聞いて」
  ＋ 実は、内容じゃなくて〇〇が原因です。

例3（衝撃＋有益）: |
  「これ、誰も教えてくれないんだけど」
  ＋ フォロワーより大事な△△の話。
```
