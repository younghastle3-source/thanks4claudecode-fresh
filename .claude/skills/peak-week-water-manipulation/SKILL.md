# ピークウィーク調整スキル（水分移動メソッド）

> 出典：わたり氏（wataru_pmc、コンテスト選手歴10年）note「ついに解禁】たった１週間で別人！？コンテスト1週間前ピークウィークの調整方法」
> 本人の経験ベースの調整法であり、論文・専門知識との異論は前提として受け付けない、という立場で書かれたもの。再現性はあるが「個人の方法論」として扱う。

---

## 1. 核心理論：「水分の移動」

```yaml
前提知識: 炭水化物は水を引きつける（体内に水分を溜める）
よくある誤解:
  - 「糖質制限で体重が落ちる」は脂肪が減ったのではなく、保持できなくなった水分が抜けただけ
  - サウナで汗をかいて「痩せた」と喜ぶのと本質的に同じ現象
核心の考え方: |
  炭水化物と水分の量を反比例させることで、体内の水分を意図的に移動させる。
  「最後のひと絞り」ではなく「質感を上げる」調整であり、結果として体重も落ちる。
  ギャンブルではなく再現性のある手法。
2つのフェーズ:
  フェーズA（カーボディプリート×ウォーターローディング）:
    炭水化物を控えて水をたくさん飲む → 体は水を保持できず排出ループに入る → むくみが抜ける
  フェーズB（カーボリフィード×水分控え）:
    炭水化物をたくさん食べて水を控える → 体内の水分を筋肉・皮下に「吸着」させる
    → 外部からの水ではなく内部の水分を引きつける感覚
    → 食べているのに体重が落ちる「逆転現象」が起きる
```

## 2. Day別プロトコル（日曜日が大会と仮定した7日間）

| Day | 曜日 | 食事 | 水分 | 狙い |
|---|---|---|---|---|
| Day1 | 土 | チート気味のカーボアップ（体重×10〜12g） | 通常 | 翌週の追い込みに向けたエネルギーチャージ（プレピークウィーク） |
| Day2 | 日 | 通常食（米200g・鶏胸肉160g・ブロッコリー等） | 通常 | 何もしない、ベースに戻すだけ |
| Day3 | 月 | 通常食のまま変更しない | ウォーターローディング開始（6L/日） | 大量の水に慣れる、循環を良くする。食事は通常通りなのでこの日は体重が増える |
| Day4 | 火 | カーボディプリート（糖質を控える）開始。脂質でカロリー補填、塩を多めに | ウォーターローディング継続（6L/日） | 炭水化物を抜くことで保持できなくなった水分がどんどん排出される。むくみが取れていく |
| Day5 | 水 | カーボディプリート継続。脂質でカロリー補填、塩を多めに | ウォーターローディング継続（6L/日） | むくみが抜け続ける、質感の変化を確認する |
| Day6 | 木 | カーボディプリート継続。脂質でカロリー補填、塩を多めに | ウォーターローディング継続（6L/日） | フェーズA最終日、Day7の切替に向けて体を仕上げる |
| Day7前半 | 金（午前） | 最後のトレーニング | （切替前） | ラストの追い込み |
| Day7後半 | 金（トレ後〜） | カーボリフィード開始。炭水化物を戻す（体重×10g程度を2〜3時間おきに分割） | 水分は控える（喉が渇いたら飲む程度。無理に飲まない） | 反比例の切替。炭水化物が体内の水分を引きつけ、筋肉に張り・皮膚に薄い貼り付き感が出る |
| Day8 | 土（前日） | 炭水化物をコンスタントに摂取 | 最低限（1L以内） | 当日に向けた最終仕上げ |

```yaml
食材の選択理由（米＋じゃがいも）:
  - じゃがいも: カリウムが豊富で塩分排出を助ける、食物繊維が豊富で排便を促す
  - 米だけでは満たされない大食いの人向けのかさまし
  - 餅は質量に対する糖質量が多いため不採用（量が制限される）
```

## 3. 重要な注意点：「水抜き」は非推奨

```yaml
水抜き（サウナ等での強制脱水）:
  推奨しない理由: |
    水は「控える」だけで良い。意図的に強制的に抜くとガリガリになり、
    コンテストではパンプもしなくなり「かりっかり」な見た目になってしまう。
  例外: 体重制限のある競技で目的が明確な場合の最後の諸刃の剣としてはあり得る
  本メソッドの位置づけ: あくまで「水分を控える」までで、強制的な脱水とは別物
```

## 4. 適用範囲

```yaml
対象:
  - コンテスト本番1週間前の選手（メインターゲット）
  - 急な撮影など、短期的に見た目を整えたい一般の人（応用可）
調整の前提:
  - 期間や量は当人のコンディションによって微調整する
  - 「絞り切れているか」に関わらず、どんな状態でもこの調整を行う（著者の方針）
  - 理想は早期に絞りを完成させ微調整のみで当日を迎えること。間に合わなくても最後まで諸調整をやり切る価値はある
リスク: |
  初めての大会でいきなり試すのはリスキー。
  「デモンストレーション」として1週間試し、合わなければ次回以降はやめるという付き合い方を推奨。
```

## 6. 相談対応パターン

### パターンA：ピークウィーク全体の計画を立てたい
```
使う情報: 大会日、現在の体感コンディション（絞れ具合）、過去の調整経験
出力: 大会日から逆算したDay1〜Day8の食事・水分スケジュール表
```

### パターンB：今が「フェーズA」か「フェーズB」か判断したい
```
使う情報: 大会まで残り日数、直近の食事・水分摂取量、体重変化
出力: 現在地点の判定（カーボディプリート×ウォーターローディング中 or カーボリフィード×水分控え中）と次の一手
```

### パターンC：短期的に見た目を整えたい（撮影・イベント前など）
```
使う情報: イベントまでの残り日数、現在の食事傾向
出力: 短縮版プロトコル（フェーズA→Bの圧縮スケジュール）、無理のない範囲への調整
```
