# 日常ブリッジ台本スキル

> **「伝えたいこと」を直接言わない。視聴者の日常から入って、気づいたら伝わっている。**

## 参照リポジトリ（GitHub・おっくん自身のナレッジ）

このスキルで投稿案作成・分析・壁打ちを行う際は、`marketing` リポジトリ（github.com/younghastle3-source/marketing）を一次情報として参照すること。

1. `gh api repos/younghastle3-source/marketing/contents/AI_CONTEXT.md` を読み、リポジトリの構成・性格を把握する
2. 相談内容に関連しそうなファイル（Be Co Gym戦略、LP原稿、メイカラ講座メモ、SNS戦略メモ等）を `gh api` で探して読む
3. 一般論より、ここにある実体験・実データ・実際に学んだ内容を優先して回答に使う

## このスキルでできること

1. 「伝えたいテーマ」から、**視聴者の日常に刺さる入口**を逆算
2. **3層のブリッジ構造**で「宣伝っぽくならない台本」を自動生成
3. PR案件・自社サービス・オピニオンなど、あらゆるテーマに対応

## 連携スキル

このスキルは **「何を入口にするか（構成の設計）」** に特化しています。

フック（一言目の型）や文体（一文の長さ・数字の使い方）を仕上げるには、**フック型ショート台本スキル**（`short-video-hook/SKILL.md`）と組み合わせてください。

| スキル | 役割 | いつ使う？ |
|---|---|---|
| **このスキル（日常ブリッジ）** | 構成の設計（日常→本題への導線） | 「何を入口にするか」を決めるとき |
| **フック型ショート台本** | 一言目の型＋台本の文体 | 台本の「書き方」を決めるとき |

## このスキルが解決すること

SNSで伸びない最大の原因は、**「伝えたいこと」から話し始めてしまうこと**。

- ❌「コワーキングスペース作りました！」→ 他人の事業に興味ない
- ❌「地方創生やってます」→ 自分ごとにならない
- ❌「フリーランスになる方法」→ ノウハウ動画は再生されない

しゅうへいの台本は、これらの話を直接しない。代わりに**視聴者が「自分にも関係ある」と感じる日常**から入り、気づいたらコワーキングや地方創生の話を聞いている。

## 分析で見えた「日常ブリッジ構造」

しゅうへいの全台本を分析した結果、**3層のブリッジ構造**が浮かび上がりました。

### 構造図

```
┌─────────────────────────────────────────┐
│  Layer 1 : 日常の入口（＝視聴者の世界）   │
│  「家賃」「会社辞めたい」「借金」「軽トラ」  │
│  → 誰でも自分ごとに感じるワード           │
└─────────────┬───────────────────────────┘
              │ 数字×感情でギャップを作る
              ▼
┌─────────────────────────────────────────┐
│  Layer 2 : 感情のエスカレーション          │
│  「2,000円 vs 300万」「年収2,000万→手取り5万」│
│  → 理想と現実のギャップで没入させる        │
└─────────────┬───────────────────────────┘
              │ 物語の結果として自然に着地
              ▼
┌─────────────────────────────────────────┐
│  Layer 3 : 本当に伝えたいこと（＝発信者の世界）│
│  「コワーキング建設」「地方創生」「SNS」     │
│  → ストーリーの帰結として届く              │
└─────────────────────────────────────────┘
```

**ポイント：Layer 3 は「結論」ではなく「結果」として登場する。**
「だから〇〇をやってます」ではなく、「こうなったので〇〇が生まれました」。

## 実例で見るブリッジ構造

### 実例1：コワーキングスペースを知ってもらいたい場合

| Layer | しゅうへいの台本 | 一般的なNG台本 |
|-------|-----------------|---------------|
| **L1：日常の入口** | 「会社のトイレで2時間昼寝」 | 「離島にコワーキングスペース作りました！」 |
| **L2：感情の加速** | マルチ商法失敗→借金500万→島に強制送還→スタバもない | 設備紹介、こだわりポイント |
| **L3：本題の着地** | 「パソコンできる場所すらないから建設した」 | 「ぜひ来てください！」 |

> **視聴者の内心**：「会社嫌だな」→「この人もそうだったんだ」→「え、島でスタバもないのに頑張ってるの？」→「コワーキング…なんか応援したい」

### 実例2：PR案件（FlexiSpot）を自然に届けたい場合

| Layer | しゅうへいの台本 | 一般的なPR台本 |
|-------|-----------------|---------------|
| **L1** | 「正直PR案件よりも現金が欲しい」 | 「FlexiSpotさんとタイアップしました！」 |
| **L2** | 赤字でヒーヒー→そんなアカウントにPR来た？→「現金でいいですか」と聞く勇気はない | 製品スペック紹介 |
| **L3** | 耐荷重160kgの紹介がギャグに変わる | 「リンクはプロフから！」 |

### 実例3：SNS継続の大変さを伝えたい場合

| Layer | しゅうへいの台本 | 一般的なNG |
|-------|-----------------|-----------| 
| **L1** | 「愛媛の島でゼロからSNSやってみた結果」 | 「SNS毎日投稿は大変だけど大事」 |
| **L2** | スローライフ勢は嘘→AI使えば10分も嘘→三脚立ていったりきたり→睡眠削って | SNS運用のコツ3選 |
| **L3** | 「175日連続投稿。誰か助けてください」 | 「みなさんも頑張りましょう！」 |

## 日常ブリッジの5つの入口パターン

分析した台本から、**視聴者の日常に刺さる入口**は5つに分類できます。

### ① お金の痛み

視聴者の大半が持つ「お金の不安」に接続する。

- 家賃、借金、リボ払い、給料、手取り
- 例：「家賃8万円が月2,000円」「リボ払い200万」

**使い方**：金額を2つ並べてギャップを作る。大きい数字と小さい数字のセット。

### ② 仕事のモヤモヤ

「会社辞めたい」「向いてない」は最強の共感ワード。

- 会社のトイレ、上司、逃げ癖、昼寝、社会不適合
- 例：「会社のトイレで2時間昼寝」「入社3ヶ月で逃げた」

**使い方**：みんなが密かに思っているけど言えないことを代弁する。

### ③ 暮らしのリアル

「こんな生活してみたい」「いや実際どうなの？」の好奇心に接続。

- 古民家、田舎、軽トラ、虫、草刈り、猫
- 例：「27万の中古軽トラ」「猫が障子を通路にした」

**使い方**：憧れと現実のギャップ。「いいな」→「やっぱ大変じゃん」の往復。

### ④ 人間関係の痛み

家族、夫婦、近所の人。誰もが抱える人間関係の摩擦。

- 妻に隠してた、親にバレた、近所の噂、炎上
- 例：「親にバレて愛媛に強制送還」「猫を使って金集めるなと叩かれた」

**使い方**：「他者の反応」を入れると一気にドラマになる。

### ⑤ 失敗・しくじり

「この人でも失敗するんだ」という安心感と好奇心。

- 騙された、間違えた、後悔した、無駄だった
- 例：「完全に騙されてました」「1ヶ月ブログ書いたら売上24円」

**使い方**：失敗の「具体的な数字」が命。「うまくいかなかった」ではなく「24円」。

## 台本テンプレート

与えられたテーマを「日常ブリッジ」で書く手順です。

### Step 1：ゴール（本当に伝えたいこと）を書き出す

まず「最終的に視聴者に知ってほしいこと」を1行で書く。

```
例：コワーキングスペースの存在を知ってほしい
例：ビットコインを少額でも持ってほしい
例：フリーランスという選択肢に気づいてほしい
例：債務整理という選択肢を知ってほしい
```

### Step 2：ゴールから「日常の入口」を逆算する

**「これに興味がある人は、日常でどんなことを感じているか？」**と考える。

| ゴール | 視聴者の日常 | 入口ワード |
|--------|------------|-----------| 
| コワーキングを知ってほしい | 会社嫌だ、カフェで仕事したい | 「会社のトイレで昼寝」 |
| ビットコインを持ってほしい | 円安で生活苦しい、将来不安 | 「円安対策なにもしてない人」 |
| 地方移住に興味を持ってほしい | 家賃が高い、満員電車が辛い | 「家賃8万円が月2,000円」 |
| 債務整理を知ってほしい | リボ払いの返済が終わらない | 「明細を見ない現実逃避」 |

### Step 3：ブリッジ台本を書く

```
【Layer 1：日常の入口（0-3秒）】
→ 5つの入口パターンから選択
→ 必ず数字を入れる

【Layer 2：感情のエスカレーション（3-30秒）】
→ 理想と現実のギャップを展開
→ 「〜と思ったら」「甘かった」「蓋を開けたら」で転回
→ 数字の対比で衝撃を加速（2,000円 vs 300万）

【Layer 3：本題の自然な着地（30-50秒）】
→ ゴールをストーリーの「結果」として出す
→ 「だから〇〇です」ではなく「こうなりました」で終わる
→ 説教しない。感想を述べるだけ。

【締め：余韻（最後の1行）】
→ 自分の現在地を示す一文（例：借金残り〇〇万円）
→ または感情で終わる（例：「誰か助けてください」）
```

## ジャンル別・日常ブリッジ変換表

「伝えたいテーマ」を「日常の入口」に変換する早見表。

| 伝えたいテーマ | ❌ 直接言う（伸びない） | ✅ 日常から入る（伸びる） |
|:---|:---|:---|
| コワーキングスペース | 「島にコワーキング作りました」 | 「スタバがない島で絶望した結果」 |
| 地方創生 | 「地方創生やってます」 | 「近所に謎の建物が建ちました」 |
| フリーランス | 「フリーランスになる方法」 | 「入社3ヶ月でトイレに引きこもった」 |
| SNS運用 | 「SNSの伸ばし方教えます」 | 「175日連続投稿。誰か助けてください」 |
| 投資（BTC） | 「ビットコイン買いましょう」 | 「FXで1日16万失いました」 |

## チェックリスト

生成した台本を以下で確認する。

- [ ] **冒頭に「伝えたいこと」が直接出ていないか？**（出ていたら失格）
- [ ] **Layer 1 に視聴者の日常ワードが入っているか？**
- [ ] **Layer 1 に具体的な数字が入っているか？**
- [ ] **Layer 2 でギャップ（理想→現実 or 現実→さらに現実）があるか？**
- [ ] **Layer 3 の本題が「結果」として自然に出てくるか？**（説教になっていないか）
- [ ] **全体を通して「ノウハウを教えてる感」がゼロか？**
- [ ] **一文が20字以内か？**（テロップ表示のため）
- [ ] **数字が3つ以上入っているか？**

## しゅうへいの台本で検証された法則

分析の結果、以下のパターンが確認できました。

### 「伝えたいこと」と「入口」の距離が遠いほど伸びる

| 距離 | 例 | 結果 |
|------|-----|------|
| 近い | 「コワーキングスペース建設！」 | 伸びない |
| 中間 | 「6,000万借りてコワーキング建てた結果」 | そこそこ |
| 遠い | 「会社のトイレで2時間昼寝してた男が島で…」 | 385万再生 |

### 「自分が」ではなく「視聴者が」主語

- ❌「ぼくはコワーキングスペースを作りました」
- ✅「スタバのない島で絶望」（視聴者も「スタバない場所やだな」と共感）

### 本題は「副産物」として届ける

しゅうへいの台本では、コワーキングスペースは「スタバがない島でPC作業する場所がなかった」という問題解決の副産物として登場する。視聴者は「なるほど、だからコワーキングが必要だったのか」と腑に落ちる。

**「買ってください」と言わなくても、物語を追っていたら自然に興味が湧いている状態を作る。**

## このスキルの使い方

1. ユーザーから**「伝えたいテーマ」**を受け取る
2. テーマから**「視聴者の日常ワード」**を逆算する（Step 2の変換表を参考）
3. **3層のブリッジ構造**に沿って台本を作成する
4. チェックリストで「直接言ってないか」を確認する
5. 台本（約300字）を出力する

**より効果的な台本を作るには：** `short-video-hook/SKILL.md`（フック型ショート台本スキル）で「一言目の型」と「文体のルール」を仕上げると、構成と掴みの両方が強い台本になります。

---

**このスキルは「何を言うか」ではなく「どの入口から入るか」を決めるスキルです。**
**台本の文体やフックの型は `short-video-hook/SKILL.md` と組み合わせて使ってください。**
