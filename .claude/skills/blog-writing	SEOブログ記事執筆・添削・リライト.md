## 第2章：Webライティングの基本ルール

### 6つの基本ルール

| # | ルール | 内容 |
|---|--------|------|
| 1 | **文末表現の重複を避ける** | 「〜です」「〜ます」を3回以上連続させない |
| 2 | **一文を短くする** | Webユーザーは拾い読み。一文は簡潔に |
| 3 | **接続詞を乱用しない** | 「そして」「だから」など不要な接続詞は削る |
| 4 | **「〜たり」はセットで** | 必ず2つ以上セットで使う |
| 5 | **「〜こと」の重複を避ける** | 一文に2回以上使わない |
| 6 | **冗長表現をなくす** | 「〜してしまいます」→「〜します」 |

### 指示代名詞は使わない

- ❌「その宿には」→ ✅「寺田屋というお宿には」
- 読者は上から順に読むとは限らない。文章単体で意味が成立するよう**具体的な名詞を繰り返す**

### PREP法（分かりやすい文章構成）

```
P（Point）   → 結論を最初に述べる
R（Reason）  → 理由を説明する
E（Example） → 具体例を挙げる
P（Point）   → 再度結論で締める
```

## 第3章：SEO基礎

### SEOに強い記事の3条件

1. **滞在時間が長い**（記事をしっかり読んでいる）
2. **読了率が高い**（最後までスクロールされている）
3. **再検索されない**（その記事だけで悩みが解決している）

### ペルソナ設定の5点

1. 悩み・目的（何に困り、何を解決したいか）
2. 現在の状態（初心者か経験者か）
3. 知りたいこと（1〜3個に絞る）
4. 前提知識（どのレベルで説明するか）
5. **読後の理想状態**（読み終えた後どうなっていたいか）

### キーワード選定の4ステップ

1. ペルソナが検索しそうな言葉を推測する
2. 検索ボリュームを確認する（キーワードプランナー等）
3. 競合調査（上位10記事の内容・ドメインパワー）
4. サジェスト・関連語を調べる

### タイトルとディスクリプション

| 要素 | 文字数 | ポイント |
|------|--------|---------|
| **タイトル** | 28〜32文字 | キーワード必須 ＋ クリックしたくなる表現 |
| **ディスクリプション** | 150〜160文字 | キーワードを自然に含める ＋ 読むメリット ＋ 独自性 |

## 第4章：サイト設計

### コンセプト設計（最重要フェーズ）

> 「何を・誰に・いくらで売るのか」を決めないと伸びない。

### ジャンル選びの3視点

1. **実体験がある分野**（初心者に最もおすすめ）
2. 趣味・これから挑戦したい分野
3. 報酬が高いジャンル（中級者以上向け）

### 商材選定の基準

- 自分が良いと思える商品（熱量が文章に乗る）
- 業界で有名な商品
- **報酬単価が高いもの**（1万円の商品を1個 > 100円の商品を100個）

### 商材選定の数値指標

| 指標 | 目安 |
|------|------|
| **EPC**（1クリックあたり平均収益） | 100円以上 |
| **確定率**（承認率） | 80%以上 |

## 第6章：記事の型

### 商標記事（購入・登録の最終判断を後押しする記事）

```
1. タイトル（28〜35文字、キーワード含む）
2. 基本情報（サービス概要を簡潔に）
3. 体験談【最重要】（実体験があれば最優先で配置）
4. 口コミ・評判（良い・悪い両方）
5. メリット・魅力
6. デメリット・注意点（信頼性担保）
7. おすすめな人・向いていない人
8. 登録方法【マネタイズの核】（スクショ付き ＋ AFリンク）
9. よくある質問（FAQ）3問程度
10. まとめ（ボタン型リンクで登録促進）
```

### 比較ランキング記事

- 複数サービスを比較し、読者を最適な**商標記事へ誘導**する
- 役割：集客（流入）→ 商標記事：成約

## 第7章：セールスライティング

### 3つの前提知識

**① ユーザー理解（最重要）**
- 読者が誰で、何に悩み、何を求めているかを言語化できているかがすべての起点
- **セールス以前に、理解が9割**

**② 人間の購買心理**
- 人は**感情・直感で買い、後から理屈をつける**
- トレーニング：コンビニで「なぜその商品を選んだか？」を毎回言語化する

**③ 価格帯で売り方を変える**

| 価格帯 | 売り方 |
|--------|--------|
| **高単価** | 根拠・データ・実績が必須。信頼構築優先 |
| **低単価** | 「これが一番お得」シンプルな推奨 |

### セールスライティングの心理トリガー

| トリガー | 使い方 |
|---------|--------|
| 希少性・緊急性 | 「今だけ」「残り〇名」 |
| 社会的証明 | 「利用者〇万人」「口コミ平均4.8」 |
| 権威性 | 専門家監修、メディア掲載実績 |
| 損失回避 | 「やらないと〇〇のリスク」 |
| 具体的数字 | 「3日で」「87%が改善」 |

## 第8章：データ分析

### 主要ツールの役割

| ツール | 役割 |
|--------|------|
| **Google Search Console** | 検索キーワード・順位の把握。記事と検索意図のズレを発見 |
| **Microsoft Clarity** | ユーザー行動の可視化。どこで読まれ、どこで離脱しているか |

### Search Console の目標値

| 指標 | 目安 |
|------|------|
| 平均掲載順位 | 20位以内 |
| 平均CTR | 10%以上 |

### 改善サイクル

```
勝てるキーワードで上位を取る
    ↓
サイト全体のCTR・順位を底上げ
    ↓
徐々に大きなキーワードへ挑戦
```

## 第9章：リライト

> リライトは「やったほうがいい作業」ではなく**必須の中核作業**。

### リライトがもたらす4効果

1. SEO評価の向上（更新を続けるページをGoogleが評価）
2. 情報の最新化
3. 読者満足度の向上
4. 内部リンクの最適化

### リライト8ステップ

```
1. キーワード順位確認（Search Console）
2. タイトル・見出しの見直し（CTR改善）
3. 競合リサーチ（上位記事にあって自記事にない情報を追加）
4. 内部リンク最適化（孤立記事をなくす）
5. 文章・装飾の調整
6. ファーストビューの改善
7. CTAの見直し（アフィリンクの位置・文言）
8. 公開日の更新
```

### 効率的な運営戦略

- 初期は完璧を目指さず、**100〜200記事を高速公開**
- データを見ながら後から質を上げる（リライト前提）
- 1サイト30〜50記事でも十分。複数特化サイトでリスク分散
