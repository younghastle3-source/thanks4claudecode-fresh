# マーケティング基礎スキル（メイカラ）

> **「誰に・どんな価値を・どう届けて・関係を築くか」の一貫したストーリーを設計するスキルです。**

## このスキルでできること

1. **3C・STP・4P** の分析フレームワークで現状を整理する
2. **USP（独自の強み）** を言語化する
3. **集客チャネル** を事業規模・ターゲット別に選定する
4. **ファネル（販売動線）** を設計する
5. **戦略ロードマップ** を作る

---

## 📌 マーケティングの定義

- **マーケティング**：「売れる・売れ続ける仕組み」を作ること（長期的）
- **セールス**：目の前の顧客に商品を売る行為（短期的）

> 優れたマーケティングがあれば、セールスは容易になる（あるいは不要になる）

---

## 🔎 第1章：現状分析フレームワーク

### ① 3C分析（必ずこの順で行う）

1. **Customer**（顧客）：市場規模、ニーズ、購買心理
2. **Competitor**（競合）：競合の強み・弱み、シェア、戦略
3. **Company**（自社）：上記を踏まえた自社の強み（USP）

### ② STP戦略（誰に・どう戦うか）

| ステップ | 内容 |
|---------|------|
| **Segmentation** | 属性・心理で市場を分ける |
| **Targeting** | 自社の強みが活きるセグメントを絞る |
| **Positioning** | 競合との違いを1文で明確にする |

### ③ 4P・4C整合チェック

| 4P（企業視点） | 4C（顧客視点） | チェック観点 |
|---------------|--------------|------------|
| Product（製品） | Customer Value（価値） | 顧客にとってどんな価値か？ |
| Price（価格） | Cost（コスト） | 時間・手間含む総コストに見合うか？ |
| Place（流通） | Convenience（利便性） | 入手しやすいか？ |
| Promotion（販促） | Communication（対話） | 一方的な宣伝ではなく対話になっているか？ |

## 👤 第2章：顧客理解

### ペルソナ設定の鉄則

- **「30代女性」ではなく「〇〇に悩む山田花子さん（32歳）」まで具体化する**
- ターゲットを広げると誰にも刺さらなくなる

### リサーチ手法の使い分け

| 手法 | 目的 | 使う場面 |
|------|------|---------|
| アンケート | 定量データ・傾向把握 | 仮説の裏付け |
| インタビュー | 定性データ・「なぜ？」の深掘り | 行動の理由を知りたい時 |
| 観察 | 無意識の行動発見 | 実際の購買シーン分析 |

> **言葉（アンケート回答）と行動（実際の購入）は矛盾する。迷ったら行動を信じる。**

## 💎 第3章：USP・商品設計

### USP（独自の強み）の3条件

1. **簡潔さ**：1文で伝わるか
2. **具体性**：「最高品質」などの曖昧な言葉を避ける
3. **顧客視点**：顧客にとってのメリットか

### 機能 vs ベネフィット

| 項目 | 例（コーヒーメーカー） |
|------|---------------------|
| **機能**（Feature） | 「90秒で抽出完了する」 |
| **ベネフィット**（Benefit） | 「忙しい朝でも手軽に美味しいコーヒーで1日を始められる」 |

**黄金の伝え方**：
```
「[ベネフィット] になれます。なぜなら [機能] があるからです」
まず理想の未来を見せ、根拠としてスペックを提示する。
```

### 価格設計の鉄則

- **絶対NG**：安易な安売り（価格競争）
- 値下げ → 利益減 → 品質低下 → 顧客離れ → さらなる値下げ の負のスパイラル
- 個人・中小は「価格」ではなく「オファー（特典・保証・体験）」で単価を上げる

## 📡 第4章：集客チャネル選定

### ストック型 vs フロー型

| 種類 | チャネル | 特徴 |
|------|---------|------|
| **ストック型（資産）** | SEO、YouTube | 時間はかかるが自動集客できる資産になる |
| **フロー型（拡散）** | X、Instagram、TikTok | 即効性・拡散力があるが投稿し続けないと埋もれる |

### チャネルミックスの基本

```
認知   → SNS（X・Instagram・TikTok）
信頼   → YouTube・ブログ・メルマガ
検索   → SEO・MEO（Googleマップ）
今すぐ → リスティング広告
```

> **「インスタだけ」等の単一本足打法は危険。まずは一点突破してから広げる。**

### コンテンツ再利用（ワンソース・マルチユース）

TikTok動画 → YouTubeショート → Instagramリール に横展開して効率化する。

## 🔄 第5章：ファネル（販売動線）設計

### 購買の5段階

```
認知 → 興味（自分事化）→ 比較検討 → 購入 → 継続（ファン化）
```

各段階の通過率（CVR）を1%改善するだけで、売上は複利的に跳ね上がる。

### 売れるLP構成（4ステップ）

```
1. キャッチコピー  ：「誰のどんな悩みを解決するか」を一瞬で伝える
2. 共感・課題     ：「こんな悩みありませんか？」と寄り添い課題を顕在化
3. 解決策        ：課題を解決する手段として自社商品を提示（ベネフィット優先）
4. CTA（行動喚起）：「今すぐ申し込む」ボタン。選択肢は1つにする
```

### 信頼構築の3本柱

1. **実績**：客観的な証拠（導入事例、お客様の声、ポートフォリオ）
   - 実績ゼロの場合：無料モニターで実績を作るか、自分自身の成果を見せる
2. **共感**：ストーリー（失敗談、起業の想い）で感情的な繋がりを作る
3. **一貫性**：メッセージをブレさせず、約束を守り続ける

### 心理トリガー

| トリガー | 使い方 |
|---------|--------|
| 損失回避 | 「今だけ」「残り3名」 |
| 社会的証明 | 「満足度98%」「導入100社」 |
| 具体性 | 「高機能」→「作業時間が半分になる」 |

## 🗺️ 第6章：戦略立案・実行

### 戦略立案の5ステップ

```
1. 現状把握  ：自分が今どこにいるか（リソース・ポジション）
2. 課題抽出  ：理想と現状のギャップを特定する
3. 目標設定  ：どこへ行きたいか（数値目標）
4. 戦略策定  ：どうやって行くか（ロードマップ）
5. 戦術実行  ：具体的に何をするか（アクション）
```

### 事業規模別・勝ち筋

| 規模 | 戦略 | 勝ち筋 |
|------|------|--------|
| **個人・副業** | 選択と集中 | 既存顧客満足度を最大化 → リピート・口コミ |
| **中小企業** | 組織化＋ブランド構築 | 集客（短期）とブランディング（長期）を両立 |
| **個人コンテンツ** | 信頼の資産化 | SNS認知 → LINE/メルマガで教育 → ファン化してから販売 |

### KPI管理の鉄則

- **結果指標（売上）**：コントロール不可。結果として出るもの
- **行動指標（投稿数・アプローチ数）**：コントロール可能。**こちらを管理して徹底的に追う**

### 高速PDCA

> **「小さく、早く試す」**
> 大失敗を避けるため、小規模テストで反応を見てから大きく展開する。

## ✅ 戦略設計チェックリスト

- [ ] **誰に**届けるか（ペルソナが「〇〇さん」レベルで具体化されているか）
- [ ] **USP**が1文で言えるか（曖昧な言葉を使っていないか）
- [ ] **機能ではなくベネフィット**で伝えているか
- [ ] **チャネル**はターゲットが最もいる場所か
- [ ] **ファネルの各段階**に施策があるか（入口・中間・出口）
- [ ] **行動指標（KPI）**が設定されているか
- [ ] **安売り**になっていないか

## このスキルの使い方

1. ユーザーから「事業内容」「現状の課題」「目標」を受け取る
2. 3C → STP の順で現状を整理する
3. 課題に対して最適なフレームワーク・施策を提示する
4. チェックリストで確認する

**連携スキル：**
- `x-operation.md`：Xアカウントの投稿・運用設計
- `instagram-hook.md`：リール・ショート動画の台本設計
- `instagram-bridge.md`：日常ブリッジ構造での台本設計
