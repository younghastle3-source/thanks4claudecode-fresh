# 久保田式マーケティングメソッド

> **「売れる仕組み」を7層の段階的アーキテクチャで構築するスキルです。**

## 3つの思想的支柱

### 支柱1: マーケットイン思考
- プロダクトアウト（作ったものを売る）ではなく、**マーケットイン（市場が求めるものを作る）**
- 起点は常に「顧客が幸せになる瞬間」の解像度を上げること

### 支柱2: AI時代の人間的価値
- AIはスキル拡張ツールであり、差別化要因ではない
- 真の競争優位性は**「人間味」「ストーリー」「価値観」「成長過程の共有」**

### 支柱3: 数字と仕組みによる再現性
- **売上 = 客数 × 単価 × リピート率**
- 各要素を3-5%改善するだけで爆発的成長（複利効果）

### 哲学的前提
- **「何をやるか」より「何をやらないか」が成功を決める**
- 認知→信頼→顧客価値→差別化→仕組み化の順序を守る（飛ばすと崩壊）
- 短期の売上最大化より、長期のLTV（顧客生涯価値）最大化を優先

## 7層アーキテクチャ（総所要時間：約80分）

```
Layer 1: 基礎情報収集（10分）
  └─ 事業概要・課題・目標・予算

Layer 2: 3C分析（20分）
  ├─ Customer（市場）: 規模・動向・ニーズ
  ├─ Competitor（競合）: 差別化要因・脅威度
  └─ Company（自社）: 強み・弱み・リソース

Layer 3: STP戦略（10分）
  ├─ Segmentation: 市場細分化
  ├─ Targeting: 優先顧客層選定
  └─ Positioning: 市場での立ち位置

Layer 4: 顧客理解（15分）
  ├─ ペルソナ設計（3-5名）
  ├─ カスタマージャーニーマップ
  └─ 顧客インサイト抽出

Layer 5: 戦略設計（10分）
  ├─ USP策定
  ├─ 4P・4C分析
  └─ 価格戦略・オファー設計

Layer 6: 実行計画（10分）
  ├─ 優先施策選定（ROI×実現可能性×緊急性）
  ├─ アクションプランシート
  ├─ ガントチャート
  └─ KPI管理ダッシュボード

Layer 7: 可視化・共有（5分）
  └─ 戦略設計スライド自動生成
```

### テンプレート1：1問1答式質問設計

```
絶対ルール：1回に1つの質問のみ
複数選択肢の提示禁止
「また〜」「さらに〜」での追加質問禁止

## フェーズ: [フェーズ名]
目的: [このフェーズで達成すること]

### 質問1
[具体的な1つの質問]
(回答待機 → 回答受領 → 整理)

### 質問2（前回答を踏まえて）
[深掘りまたは次のトピック]
```

### テンプレート2：3C分析実行シート

| 分析対象 | 調査項目 | 収集方法 | 評価基準 | 戦略的示唆 |
|---------|---------|---------|---------|----------|
| **Customer** | 市場規模・成長率 | 統計データ | CAGR、TAM/SAM/SOM | 参入価値判定 |
| | ニーズ・ペイン | インタビュー・観察 | 緊急性×重要性 | ソリューション設計 |
| | 購買行動 | カスタマージャーニー | タッチポイント数 | 施策配置 |
| **Competitor** | 主要競合リスト | Web調査 | 売上・シェア | 脅威度ランク |
| | 強み・弱み | SWOT・4P比較 | 6項目スコア | 差別化ポイント |
| | ポジショニング | 価格×品質マップ | 空白地帯の有無 | 参入余地特定 |
| **Company** | 強み・リソース | 内部監査 | 競合比較優位性 | 活用戦略 |
| | 弱み・制約 | 現状分析 | 克服可能性 | リスク対策 |
| | ユニーク資産 | 棚卸し | 模倣困難性 | USP候補 |

|-------|------|----------|------|-----|--------|

- **高**：ROI高 × 実現容易 × 緊急性高

## 事業規模別・応用パターン

### パターンA：個人コンサルタント・コーチ

- **USP**：「自分の人間味・ストーリー・失敗経験」で構築
  - ❌「10年の経験を持つコンサルタント」
  - ✅「月残業100時間から独立し3年で年商3000万。失敗を20個経験した元ブラック企業サラリーマン」
- **顧客理解**：「過去の自分へのラブレター」（ペルソナ＝過去の自分が抱えていた悩み）
- **4P**：無料コンテンツ→低価格入門→高単価本命の3層構造

### パターンB：地域密着型店舗

- **3C分析**：商圏内競合（半径3km以内）に絞り込む
- **ペルソナ**：既存の高LTV顧客を分析して「理想の常連客」を設定
- **カスタマージャーニー**：来店前→来店→**退店後**（ここに投資する）

### パターンC：EC・D2Cブランド

- **STP**：デモグラ（年齢・性別）ではなくサイコグラ（価値観・行動）でセグメント
- **USP**：機能×情緒×社会的意義の三位一体
- **指標**：CPAではなくLTVで判断

### パターンD：B2B SaaS

- **ペルソナ**：意思決定者（ROI・リスク重視）と現場利用者（使いやすさ重視）を分離
- **USP**：「業界特化×課題特化」で鋭く尖らせる（例：「製造業の在庫管理を50%削減するAI予測SaaS」）
- **LTV**：カスタマージャーニーの「導入後（オンボーディング）」に注力

## 7大注意点と改善策

### 注意1：順序を守る（飛ばすと崩壊）

```
認知 → 信頼 → 顧客価値 → 差別化 → 仕組み化
```
- 認知ゼロなのに仕組み化（自動化）から始めない
- 信頼構築なしに高額商品を売らない

### 注意2：「何をやらないか」を決める

判断基準（3つ全てYESでなければやらない）：
1. ROIが見込めるか
2. 自社の強みを活かせるか
3. ターゲット顧客に届くか

### 注意3：数値で管理・検証・改善

売上 = 客数 × 単価 × リピート率
→ 各要素を3-5%改善するだけで複利的成長

### 注意4：顧客理解は「観察」と「仮説検証」

言葉（アンケート）と行動（購買）は矛盾する → 迷ったら行動を信じる

### 注意5：価格は「価値」で決める

値下げ → 利益減 → 品質低下 → 顧客離れ の負のスパイラルを避ける

### 注意6：AI時代は「人間味」が最大の武器

- 成長過程・失敗・価値観をリアルタイム発信する
- 「完璧な専門家」より「成長中の先輩」ポジション

### 注意7：LTV最大化思考

新規獲得コストは既存顧客維持の5倍
→ 初回体験を最高にし、リピート・紹介の仕組みを作る

## 初心者の7大失敗と改善策

| 失敗 | 改善策 |
|------|--------|
| 完璧主義で動き出せない | MVP（60点）で市場に出し、失敗をデータとして捉える |
| ターゲットを広げすぎる | 「たった1人のペルソナ」→段階的に広げる |
| 競合分析で消耗する | 競合は初期に1回のみ。日々は「顧客価値」基準で判断 |
| リサーチ結果を活用しない | 仮説ドリブンで設計し、必ず次の施策に反映 |
| 施策を詰め込みすぎる | 「3つの重要施策」に絞る（80/20の法則） |
| KPI設定が曖昧 | SMART基準で設定し、先行指標（行動量）を追う |
| 「売り込み」になってしまう | GIVE→GIVE→GIVE→ASK の法則 |

## 成功の本質

1. **1問1答を守り、丁寧に回答する**
2. **顧客理解に最も時間をかける**
3. **完璧主義を捨て、小さくテストする**
4. **数字で検証・改善を繰り返す**
5. **長期的なLTV思考で判断する**
