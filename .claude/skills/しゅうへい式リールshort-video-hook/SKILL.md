# フック型ショート台本スキル

> **バズる一言目（フック）と、視聴維持される台本構成を作るスキルです。**

## 参照リポジトリ（GitHub・おっくん自身のナレッジ）

このスキルで投稿案作成・分析・壁打ちを行う際は、`marketing` リポジトリ（github.com/younghastle3-source/marketing）を一次情報として参照すること。

1. `gh api repos/younghastle3-source/marketing/contents/AI_CONTEXT.md` を読み、リポジトリの構成・性格を把握する
2. 相談内容に関連しそうなファイル（Be Co Gym戦略、LP原稿、メイカラ講座メモ、SNS戦略メモ等）を `gh api` で探して読む
3. 一般論より、ここにある実体験・実データ・実際に学んだ内容を優先して回答に使う

## このスキルでできること

1. テーマを伝えるだけで、**伸びるフック＋台本（約300字）** を自動生成
2. 既存の台本を貼り付けると、**チェックリストに基づいて添削**
3. しゅうへいの実績データに基づいた「伸びるパターン」で構成

## 連携スキル

このスキルは **「フック（掴み）」と「文体（一文の長さ・数字の使い方）」** に特化しています。

「何を言うか」ではなく **「どの入口から入るか」** を設計したい場合は、**日常ブリッジ台本スキル**（`daily-bridge/SKILL.md`）と組み合わせてください。

| スキル | 役割 | いつ使う？ |
|---|---|---|
| **このスキル（フック型）** | 一言目の型＋台本の文体 | 台本の「書き方」を決めるとき |
| **日常ブリッジ台本** | 構成の設計（日常→本題への導線） | 「何を入口にするか」を決めるとき |

## 📌 伸びるフック（一言目）の3パターン

分析の結果、以下の3つのフックパターンが最も効果的であることが判明しています。**必ずいずれかのパターンを使用してください。**

### ① 数字×悲劇（Gap Hook）
「異常値」を最初に叩きつけ、視聴者のスクロールを止める。

**フォーマット**: `[年齢]歳[ネガティブ状況][数字]`

**例**:
- 「36歳借金6,000万」
- 「年収2,000万なって病みました」
- 「600万失いました」
- 「月60万返済が10年続く」

### ② 行動×ネガティブ結果（Action-Result Hook）
「〜した結果」というフォーマットで、悪い結末を先出しする。

**フォーマット**: `[行動]した結果、[ネガティブな結末]`

**例**:
- 「うつっぽいので東京から愛媛に移住した結果」
- 「年収2000万から200万に下げてみた結果」
- 「27万の中古の軽トラで捕まりました」
- 「1,700万で土地を買ったら大変なことになりました」

### ③ 告白・暴露（Confession Hook）
他者からの叱責や自己否定を連想させ、野次馬根性を刺激する。

**フォーマット**: `[ネガティブな事象]されました / [自己否定]でした`

**例**:
- 「商工会議所に呼び出されました」
- 「完全に間違っていました」
- 「会社のトイレで寝てるのバレてますよ」

## 🚫 使ってはいけないNGフック

以下のフックパターンは再生数が伸びないため、**絶対に使用禁止**です。

- ❌ 抽象的すぎる: 「たった一言で失敗し続けた」（何の一言かわからない）
- ❌ お知らせ系: 「〇〇スタート！」「嬉しい報告です！」
- ❌ 説教・上から目線: 「〇〇は気をつけなはれや」「〇〇する方法3選」
- ❌ じらし: 「どうなったでしょう？」（答えを先に言え）
- ❌ ノウハウ系キーワード: 「理由」「方法」「コツ」「選」

## 📝 台本構成テンプレート（300字）

以下の4パート構成で台本を作成します。約300字（40秒〜60秒）を目安にします。

```
【1. フック（0-2秒）】約20字
[上記3パターンのいずれかを使用]

【2. 展開（3-15秒）】約80字
[理想と現実のギャップを見せる]
[「〜と思ったら」「甘かった」「現実は」などを使う]

【3. 本題（15-45秒）】約150字
[具体的な「痛み」を列挙する]
[数字、固有名詞、具体的エピソードを入れる]

【4. オチ（45-60秒）】約50字
[哀愁漂うポジティブ、または救いのないリアル]
[「借金残り〇〇万円」で締める]
```

## ✅ 台本生成時のチェックリスト

生成した台本は、以下のチェックリストで必ず確認してください。

- [ ] **一言目**に「数字」または「ネガティブな結果」が入っているか？
- [ ] 「理由」「方法」「コツ」などのNGワードが入っていないか？
- [ ] 一文が20字以内に収まっているか？（テロップ表示のため）
- [ ] 具体的な数字（金額、年齢、日数など）が3つ以上入っているか？
- [ ] 最後に「借金残り〇〇万円」または同等の「リアリティの締め」があるか？
- [ ] 全体が300字前後（40〜60秒読み上げ相当）に収まっているか？

## このスキルの使い方

1. ユーザーから「ネタ」「テーマ」「伝えたいこと」を受け取る
2. このスキルのフックパターンと台本構成テンプレートに従ってドラフト作成
3. チェックリストで確認し、必要に応じて修正
4. タイトル案（一言目）と台本（300字）を出力

**より効果的な台本を作るには：** `daily-bridge/SKILL.md`（日常ブリッジ台本スキル）で「どの日常から入るか」を先に設計し、このスキルでフックと文体を仕上げると、構成と掴みの両方が強い台本になります。
