# 信頼を育てる投稿作り

## 核心の気づき

```yaml
数字よりも安心感・信頼: |
  フォロワーが少ない、バズらない、数字が伸びない。
  そんな焦りから「伸びている人の真似」ばかりしていると、
  正しいことは書いているのに温度感がなく、
  反応があっても「この人にお願いしたい」という信頼まで育たない。
  
  大事なのは数字ではなく、安心感と信頼。

お客様はサービス内容だけで申し込まない: |
  「この人は私の悩みを分かってくれそう」
  「この人の人柄が伝わってくる」
  「この人だったら安心して申し込める」
  
  そう感じた時に、お客様は一歩踏み出せる。

あなただから選ばれる: |
  同じサービスをしている人は他にもたくさんいる。
  その中で選ばれるのは「安いから」「近いから」だけではなく、
  「あなただから、この人にお願いしたい」と思ってもらえるかどうか。
  日々の投稿の中で信頼を育てていくことが大事になる。
```

## 申し込みにつながる4つの投稿テーマ

### テーマ1：お客様の悩みに寄り添う

```yaml
目的: 「この人、私のことわかってくれる」を生む

なぜ効くか: |
  お客様は申し込む前にいろんな不安を持っている。
  その不安を言葉にしてあげるだけで、
  読んだ人は「あ、この人は私の気持ちがわかってくれる」と感じやすくなる。

業種別の不安の例:
  フォトグラファー:
    - 人見知りで泣いちゃったらどうしよう
    - 写真があんまり好きじゃない子だけど大丈夫かな
    - パパが乗り気じゃないけど大丈夫かしら
    - 急に体調崩したらどうなるんだろう
  親子教室・ベビーマッサージ:
    - 初めての場所に行くのがちょっと緊張するな
    - うちの子だけうまくできなかったらどうしよう

お悩みが見つからない時のヒント:
  - お問い合わせで過去に聞かれたことを思い出す
  - リサーチしていいねが多い投稿から読者の悩みを把握する
  - 同業者の投稿のコメント欄を見る
```

---

### テーマ2：解決のヒントを渡す

```yaml
目的: 「この人、専門性があるんだな」という信頼感を生む

ポイント: |
  難しい内容じゃなくて大丈夫。
  「あ、これなら私にもできそう」「今すぐ試してみよう」
  と思えるレベルの小さなノウハウでOK。

業種別の例:
  フォトグラファー（七五三撮影）: |
    当日いきなり着物を着せるのではなく、
    一緒に着物を選んだり写真を見せながら
    「当日はこれを着るんだよ」と声をかけておくだけで、
    お子さんの不安が減りますよ。

  ベビーマッサージ（便秘の悩み）: |
    お腹を優しく時計回りに撫でると腸の動きをサポートしやすくなります。
    足を自転車のようにゆっくり動かすとお腹周りが緩みやすくなります。
    お家で試せる小さなケアを渡してあげる。

効果: |
  「あ、これなら私にもできそう」という安心にもつながり、
  同時に「この人ってすごく専門性があるんだな」という信頼感も生まれる。
```

### テーマ3：お客様の声・変化を見せる

```yaml
目的: 初めてサービスを受ける人への「一番大きな安心」を作る

なぜ効くか: |
  自分が言うより、実際に受けたお客様の言葉の方が信頼性が高い。
  「サービス内容」より「受けた後の変化」を見せることで、
  申し込み前のお客様が「私もこうなれるかも」とイメージしやすくなる。

投稿の形:
  感想を紹介する: |
    こんな感想をもらいましたって紹介する。
    例：人見知りで不安だったママが、
    レッスン後に他のママと繋がって今度ブランチに行くことになった、
    というお声をいただきました。

  参加前後の変化を見せる: |
    参加前の不安 → 参加後の変化のセットで見せる。
    例：便秘が気になっていた赤ちゃんが
    マッサージを続けたら少しずつリズムが整ってきた、
    という報告をいただきました。

  雰囲気・写真で見せる: |
    サービス当日の写真や空間の様子をお伝えすることで
    お客様が「行った後のイメージ」を持ちやすくなる。
    「初めての方もこういう風に過ごしました」という見せ方が効果的。
```

### テーマ4：自分の思い・経験を伝える

```yaml
目的: 「この人らしさ・温度感」が伝わり、あなたで選ばれる投稿になる

伝えること:
  - なぜこの仕事をしているのか
  - どんな経験が今につながっているのか
  - サービスで大切にしていることは何なのか

感情まで入れると: |
  経験を語るだけでなく、感情まで入れると温度感が伝わる。
  自分を知ってもらうっていうところで、
  読んでいる人との距離が縮まる。

AI活用時の注意: |
  ChatGPTなどAIを使って文章を書くケースも増えている。
  時短になるし投稿の整理にも役立つが、
  個人サービスで「あなたで選んでもらう」部分では、
  AIを使った場合にも必ず自分の経験と感情を入れること。
  自分の経験・感情が入ることで「自分にしか作れない投稿」になる。
```

## 実践ガイド

### 今日の投稿に1つ入れてみる

| テーマ | どんな時に使う | 一言キーワード |
|---|---|---|
| お悩みに寄り添う | 共感・関係性を作りたい時 | 「〜で不安じゃないですか？」 |
| 解決のヒントを渡す | 専門性・信頼を示したい時 | 「〜するだけで変わります」 |
| お客様の声・変化 | 申し込みへの後押しをしたい時 | 「こんな変化がありました」 |
| 自分の思い・経験 | 人柄・温度感を届けたい時 | 「私がこの仕事をする理由」 |

### 投稿ネタが見つからない時のリサーチ法

```yaml
お客様の悩みリサーチ:
  - 過去のお問い合わせ・DMで聞かれたことを振り返る
  - Threadsでリサーチし、いいねが多い投稿のテーマを確認する
  - 同業者の投稿のコメントから読者の本音を掴む

お客様の声ストック:
  - サービス後にメッセージや感想をもらったらメモしておく
  - ない場合はモニター募集で体験してもらい声を集める

自分の思い・経験の棚卸し:
  - この仕事を始めたきっかけ
  - 過去に自分が困ったこと・悩んだこと
  - お客様と関わる中で気づいたこと
```

### 日々の投稿への散りばめ方

```yaml
考え方: |
  4つのテーマを毎投稿に全部入れる必要はない。
  週の中で少しずつ散りばめていくことで、
  「投稿を見て → 固定投稿を見て → 申し込みへ」
  という自然な流れが生まれていく。

目安: |
  今日の投稿に4つのどれか1つを入れてみることから始める。
  続けることで、安心感が積み重なり「あなただから」と選ばれるようになる。
```
