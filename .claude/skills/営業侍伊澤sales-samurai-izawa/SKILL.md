# 営業侍・伊澤流 セールススキル

> 「売りたい」というエゴを捨て、「目の前の人を勝たせたい」という純粋な貢献心を持った時、顧客はあなたを最強のパートナーとして選び取る。

## 営業の本質定義

```yaml
営業とは:
  - 「商品を売ること」ではない
  - 「顧客の夢や課題解決を手伝うパートナーになること」
  - 顧客自身が「買う」という選択をするよう導く行為

全商談のゴール:
  - 契約ではなく「あなたに会えてよかった」と思ってもらうこと

ABC理論:
  A: 当たり前のことを
  B: バカになって
  C: ちゃんとやる
  → 時間厳守・清潔感・即レスを徹底するだけで信頼残高は貯まる
```

## 信頼構築：3段階の法則（ラポール形成）

相手を気持ちよく自己開示させるステップ：

| ステップ | やること | 例 |
|---|---|---|
| ① 褒める | 具体的な行動を承認 | 「時間ぴったりですね」 |
| ② 価値を高める | エビデンスを加える | 「できる人は1割もいません」 |
| ③ 前提で振る | 本題へ繋げる | 「だからこそ、お仕事でも素晴らしい成果を出されているのでは？」 |

---

## 対話の黄金ルート（マジョリティ層への3ステップ）

> 営業の主戦場は「マジョリティ層」（みんなが使えば使う層）。いきなり機能を売り込んでも壁にぶつかる。

```
Step 1: 一般論の提示
  誰もが否定できない社会的事実を出す
  例：「最近、AIがいろんな仕事を代替し始めてるって話、よく聞きますよね」

Step 2: 個別具体論へのブリッジ（キラークエスチョン）
  「もし来月からAIに仕事を取られて、給料が10万円下がったら生活できますか？」
  → 相手が「自分ごと」として課題を認識する

Step 3: 解決策の提示
  相手が課題を認識したタイミングで初めて自社サービスを出す
```

## 潜在ニーズの掘り下げ方

**NG（尋問になる）：**
> 「なぜそう思ったんですか？」

**OK（承認＋質問）：**
> 「**〇〇さんのような優秀な方が**、あえてその選択をされた理由は何ですか？」

相手を「特別な存在」として扱うことで本音を引き出す。

---

## ノンクロージングの実現

信頼関係とニーズ喚起が完璧なら、クロージング（売り込み）は不要。

```
信頼構築（承認・共感で心の壁を取り払う）
    ↓
ニーズ顕在化（潜在的な不満を「解決したい欲求」に変える）
    ↓
自己選択（顧客が「これが必要だ」と自覚し、自ら購入を決断）
```

---

## 反論処理：「検討します」への切り返し

「検討します」＝「先延ばし」のサイン。3段階で対処する：

1. **具体化**：「どの点を検討されますか？」と焦点を絞る
2. **損失提示**：「1年悩めば、成功も1年遅れます」
3. **仮定法**：「もし価格の問題がなければ、やりたいですか？」→ 真の懸念（本音）を炙り出す

---

## 断られた後のリカバリー戦術

**フェーズ1（即リカバリー）：**
> 「私の説明不足でした。また数分だけお時間いただけませんか？」

**フェーズ2（ダム決壊）：**
1. 「最近どうですか？」（軽い接触）
2. 「以前おっしゃっていた〇〇の件、どうなりました？」（記憶していたことを示す）
3. 相手が話し出す（ダム決壊）→ 再提案

> 断られるのは「重力」と同じ自然現象。人格否定ではない。

## AI×人間 ハイブリッド営業（セミナー②・④）

**AIに任せること：**
- トークスクリプトのドラフト生成
- 提案資料の骨子作成
- 想定問答集の作成
- 「2年かかる準備が半年で完了」するほどの時間圧縮

**AIに任せてはいけないこと：**
- 思考停止した「AI自動テレアポ」→ 成果ゼロのリスク
- フォーム営業の一斉送信（3万件送って0件の事例あり）

**人間がやること：**
> 「人は論理でなく感情で動く」

- 場の空気・微細な反応を察知する肌感覚
- 「この人から買いたい」と思わせる信頼構築
- 感情を動かすコミュニケーション

## アポ取りの鉄則（B2B・テレアポ）

- **電話の目的は「アポ日時を決めること」だけ**。商品説明は不要
- **ターゲット**：商工会議所・法人会の役員（承認欲求が強い層）
- **キラーワード**：「お力貸してください」→ 貢献した上で素直に頼む

```
時給換算の考え方：
1,000コール → 1件成約 → 報酬400万円
= 1コールあたり4,000円 = 時給24万円
→ ビビらず数をこなす根拠になる
```

## LISAセミナー（10月合宿）追加ナレッジ

### 伊藤式：事業構築4段階フレームワーク

```
1. 計画作成（MVV → 全社戦略 → 事業戦略 → 機能戦略）
    ↓
2. 土壌作り（セールスロジック構築）
    ↓
3. 計画コントロール（リスクヘッジ）
    ↓
4. ビジネスモデル洗練
```

**出口設計を最初に決める**
- 生存戦略 / 売却 / 上場 / 廃業の4択を事業開始時に決める
- 営業利益から逆算：営業利益2億円 → 売却価格6〜8億円

**セールスが財務を作る**
- 集客で困る企業の9割は実はセールスが問題
- セールスで売れる → 財務が生まれる → マーケ予算に回せる（この順序）
- 社長が最初に営業する理由：①財務（材料）を作る ②セールスロジックを検証する

**CPA vs LTVの正しい理解**
- CPA（獲得単価）を下げるだけが正解ではない
- LTVを上げることで**許容CPAを上げる**方が競合優位になる
- 例：LTV10万円の事業は許容CPA3万円。LTV100万円なら許容CPA30万円

**KPI と KDA の役割分離**
| 役割 | 指標 | 責任 |
|---|---|---|
| 代表・経営者 | KPI（結果指標） | 戦略責任 |
| スタッフ | KDA（行動ベース指標） | 実行責任 |

**セールスロジック構築手順**
1. 商談を録音・録画して保存
2. 断り理由を分類・分析
3. キラートーク（成約パターン）を資料化
4. 全メンバーに展開 → 成約率5%→10%（売上2倍）

---

### 西田式：事業をやる7つの問い（汎用フレームワーク）

経営者レベル・マネージャーレベル・メンバーレベル全てで使える。この問いを繰り返すだけで事業が伸びる仕組み。

```
1. ゴール・KGI（定性的ゴール + 定量的ゴール）
    ↓
2. 重要指標・KPI（3つ以内に絞る）
    ↓
3. 現状把握（事実 vs 解釈を分ける）
    ↓
4. 本質課題の特定（技術課題 or 適応課題？）
    ↓
5. アクションプラン（優先度行列：ROI高×実行簡単×緊急度）
    ↓
6. 振り返り＋ネクストアクション
    ↓
7. 適応課題の定期チェック（KSFを定期見直し）
```

**技術課題 vs 適応課題**
| 種類 | 内容 | 対応アプローチ |
|---|---|---|
| **技術課題** | お金・スキル・仕組みで解決可能 | ツール導入・研修・採用 |
| **適応課題** | マインドブロック・価値観の問題 | コーチング・対話・内省 |

※クライアントが「もっといい方法はないか」と探し続けているなら、それは適応課題のサイン

**組織構築の2原則（この順序で）**
1. 個人と組織のゴールを重ね合わせる
2. 役割 → 責任 → 報酬を明確に決める

**変数を定数化**：成功事例（キラートーク等）を仕組みに落とし込んで再現性を高める
