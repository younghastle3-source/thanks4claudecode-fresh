# 開業戦略ロードマップ：2026年4月→2027年開業

> 現在地（2026年4月）から2027年のジム開業までの約12〜18ヶ月を、
> フェーズ別に整理したロードマップです。各フェーズのマイルストーンと行動リストを参考に、
> 自分のスケジュールに落とし込んでください。

---

## 全体スケジュール概観

```
2026年4月〜6月   [Phase 1] 構想・市場調査・ビジョン確定
2026年7月〜9月   [Phase 2] 事業計画書作成・資金調達開始
2026年10月〜12月 [Phase 3] 物件探し・設備計画・許認可準備
2027年1月〜3月   [Phase 4] 内装工事・設備導入・開業前集客
2027年4月〜6月   [OPEN] グランドオープン・安定期突入
```

---

### Phase 1: 構想・リサーチ期（2026年4月〜6月）

**目標**: 「どんなジムを、どこに、誰に向けて開く」を確定する

#### アクションリスト

- [ ] 自分がやりたいジムの業態・コンセプトを言語化する（1ページで書けるレベルに）
- [ ] 候補エリアの競合ジムを現地調査する（最低5店舗）
- [ ] 市場調査リサーチを実施（市場規模・顧客ニーズ・立地条件の確認）
- [ ] ターゲット顧客のペルソナを3つ以上設定する
- [ ] 自分のスキル・経験を棚卸しする（資格・トレーナー経験・接客経験等）
- [ ] 日本政策金融公庫の創業融資制度について情報収集する
- [ ] 商工会議所・地域の起業支援窓口に相談に行く
- [ ] 参考になるジムを5〜10店舗体験入会・見学する

#### フェーズ完了の条件
- ジムのコンセプト・ターゲット・立地エリアの方向性が決まっている
- 開業に必要な資金の概算（初期投資・運転資金）が把握できている

---

### Phase 2: 事業計画書作成・資金調達（2026年7月〜9月）

**目標**: 融資申請できる水準の事業計画書を完成させ、資金調達の目処をつける

#### アクションリスト

- [ ] 事業計画書を作成する（本リポジトリの `business-plan-template.md` を活用）
  - エグゼクティブサマリー
  - 市場分析・競合分析
  - マーケティング戦略
  - 財務計画（初期投資・月次収支・損益分岐点）
  - リスク分析
- [ ] 必要な資格・認定を確認・取得（NSCA-CPT、JATI-ATI、普通救命講習等）
- [ ] 税理士・中小企業診断士に事業計画書のレビューを依頼する
- [ ] 資金調達ルートを確定する（下記「資金調達の選択肢」参照）
- [ ] 日本政策金融公庫への融資申請書類を準備する
- [ ] 法人設立 or 個人事業主の選択と手続き（推奨：会社設立は専門家に依頼）

#### フェーズ完了の条件
- 融資申請が完了 or 自己資金の確保目処が立っている
- 事業計画書が第三者にレビューされている

---

### Phase 3: 物件・設備・許認可（2026年10月〜12月）

**目標**: 開業場所を決定し、内装・設備の準備を進める

#### アクションリスト

- [ ] 候補物件を10件以上内見し、最終候補を3件に絞る
  - チェックポイント：床荷重・換気・給排水・用途地域・賃料
- [ ] 物件の建築用途を確認（スポーツ施設として使用可能か）
- [ ] 内装業者に見積もりを依頼（2〜3社から相見積もり）
- [ ] 設備・器具の発注先を選定（リース vs 購入の比較）
- [ ] 消防署への届出（防火対象物使用開始届等）
- [ ] 保健所への届出（シャワー設備がある場合）
- [ ] 会員管理システムの選定と契約（hacomono、FitBoxなど）
- [ ] セキュリティ・入退館システムの選定（24h型の場合は必須）
- [ ] ロゴ・ブランドデザインの確定
- [ ] ジム名・ドメインの取得、SNSアカウント開設

#### フェーズ完了の条件
- 物件の賃貸借契約が締結されている
- 内装工事の契約・着工スケジュールが確定している

---

### Phase 4: 内装工事・設備導入・開業前集客（2027年1月〜3月）

**目標**: 施設を完成させながら、開業日に向けた集客を最大化する

#### アクションリスト

##### 施設整備
- [ ] 内装工事の進捗管理（週次で確認）
- [ ] 器具・設備の搬入・設置
- [ ] スタッフ採用・研修（オープン前に完了）
- [ ] 消防・保健所の完了検査を受ける
- [ ] AED・救急用品の設置
- [ ] グランドオープン前の社内テスト運営（内覧会・関係者向け試運転）

##### 開業前集客（プレマーケティング）
- [ ] SNS（Instagram・TikTok・X）で開業ビハインドザシーンを発信する
- [ ] 近隣へのポスティング・チラシ配布
- [ ] Googleビジネスプロフィールの登録
- [ ] 先行入会キャンペーン（開業前割引・無料体験期間）を開始
- [ ] プレスリリースを地域メディアに配信
- [ ] 開業記念イベント（内覧会・無料体験DAY）の企画・告知

#### フェーズ完了の条件
- 開業日時点で先行入会者が損益分岐点の30〜50%以上確保できている
- 全ての許認可が完了している

## 資金調達・融資の選択肢

### 選択肢1: 日本政策金融公庫（創業融資）

| 項目 | 内容 |
|------|------|
| 制度名 | 新創業融資制度、女性・若者/シニア起業家支援資金 |
| 融資上限 | 3,000万円（新創業融資の場合） |
| 金利 | 2〜3%前後（時期によって変動） |
| 担保・保証人 | 原則不要 |
| 審査のポイント | 事業計画書の精度・自己資金比率・経験・熱意 |
| 申請窓口 | 最寄りの日本政策金融公庫支店 |

**推奨理由**: 創業者向けに特化した制度で、民間銀行より審査が通りやすい。自己資金が開業費の1/3程度あれば申請できるケースが多い。

---

### 選択肢2: 民間銀行・信用金庫の創業融資

| 項目 | 内容 |
|------|------|
| 融資上限 | 金融機関・担保力によって異なる |
| 金利 | 1〜4%前後 |
| 担保・保証人 | 求められることが多い |
| 審査のポイント | 信用力・担保・事業計画 |

**ポイント**: 公庫との協調融資（両方から借りる）も可能。地域密着の信用金庫は事業主への支援に積極的なケースも多い。

---

### 選択肢3: 補助金・助成金

| 制度 | 対象 | 給付上限目安 |
|------|------|-------------|
| 小規模事業者持続化補助金 | 小規模事業者の販路開拓 | 50〜250万円 |
| 事業再構築補助金 | 業態転換・新分野展開 | 100〜8,000万円（規模による） |
| 地域の創業補助金 | 自治体によって異なる | 50〜500万円 |
| 雇用関連助成金（厚労省） | 採用・研修費用の補助 | 数万〜数百万円 |

**注意**: 補助金は後払い（先に使って後から受け取る）が基本。補助金だけで開業資金を賄うことはできない。公募期間・採択率を確認した上で申請する。

---

### 選択肢4: 自己資金

| 項目 | 内容 |
|------|------|
| 目安 | 開業費用の30〜50%は自己資金で用意するのが理想 |
| 調達方法 | 給与からの積み立て、副業収入、不動産売却、家族からの借入等 |

**ポイント**: 自己資金比率が高いほど審査が有利になる。2027年開業目標なら、2026年4月時点で300〜500万円以上の自己資金があるとベスト。

---

## 重要なリスクと対策

| リスク | 発生タイミング | 対策 |
|--------|-------------|------|
| 物件が見つからない | Phase 3 | 候補エリアを広げる、不動産業者を複数使う |
| 工事費が予算超過 | Phase 4 | 予備費として総工事費の15〜20%を確保 |
| 開業前集客が不振 | Phase 4 | SNS発信を早期化、紹介制度を強化 |
| 融資審査が通らない | Phase 2 | 自己資金を積み増す、事業計画書を専門家に再レビュー |
| オープン後の会員減少 | オープン後 | 入会後フォロー体制を事前設計、コミュニティ形成 |

## 開業に必要な主要手続き一覧

| 手続き | 担当窓口 | タイミング |
|--------|---------|----------|
| 個人事業主の開業届 | 税務署 | 開業後1ヶ月以内 |
| 法人設立（株式会社等） | 法務局 | 資金調達前に完了推奨 |
| 防火対象物使用開始届 | 消防署 | 使用開始7日前まで |
| 防火管理者選任届 | 消防署 | 収容人員30人以上の場合 |
| 公衆浴場法の届出 | 都道府県 | シャワー・浴槽設備がある場合 |
| 社会保険・労働保険 | 年金事務所・労働基準監督署 | 従業員雇用時 |

> **注意**: 上記は代表的なものです。業態・施設規模・所在地によって必要な手続きが異なります。開業前に行政書士・社会保険労務士に確認することを強く推奨します。
