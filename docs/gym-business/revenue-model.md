# 収益モデル設計ガイド：ジム開業の料金体系と損益試算

> このドキュメントは、ジムの料金プラン設計と収益シミュレーションの枠組みを提供します。
> 記載の数値はあくまで参考値です。自身のビジネスモデルに合わせて書き換えてください。

---

## 1. ジムの主要料金プランの種類

### 月額固定プラン（会員制）

**特徴**: 毎月定額を支払い、月内は何度でも利用できる最も一般的なモデル。

| サブプラン | 月額相場 | 特徴 |
|-----------|---------|------|
| マシンのみ | 3,000〜7,000円 | 低価格で入会ハードル低い |
| マシン＋スタジオ | 7,000〜12,000円 | グループレッスン込み |
| 全施設フルアクセス | 10,000〜20,000円 | プール・サウナ含む総合型 |
| 学生・シニア割引 | 通常の60〜80% | 特定層の入会促進 |
| 法人契約 | 個別交渉 | 近隣企業・団体との一括契約 |

**メリット**: 毎月安定した収入が見込める（ストック型収益）  
**デメリット**: 解約が増えると収入が一気に落ちる。入会キャンペーンで一時的にコストがかかる

---

### 都度利用プラン（ドロップイン）

**特徴**: 利用した日だけ料金を払う。会員にならずに使える柔軟なプラン。

| 種類 | 料金相場 |
|------|---------|
| 1回利用（当日） | 800〜2,000円/回 |
| 回数券（10回） | 7,000〜15,000円 |
| 週2回プラン（月8回まで） | 4,000〜8,000円/月 |

**メリット**: 試し利用、旅行者・単発ニーズに対応できる  
**デメリット**: 利用数に収入が連動するため不安定。固定費をカバーしにくい

---

### パーソナルトレーニングプラン

**特徴**: トレーナーが1対1（またはセミパーソナルで2〜4人）で指導するプレミアムプラン。

| 種類 | 料金相場 |
|------|---------|
| 1セッション（60分） | 5,000〜15,000円 |
| パーソナル月額プラン（週1回・4回/月） | 20,000〜50,000円/月 |
| 短期コース（2〜3ヶ月集中） | 150,000〜500,000円 |
| セミパーソナル（2〜4人）60分 | 3,000〜8,000円/人 |

**メリット**: 単価が高く、1人あたりの収益が大きい  
**デメリット**: トレーナーの時間が直接収益に結びつくため、人材依存・スケールしにくい

---

### その他の収益源（サブ収益）

| 収益源 | 収益規模感 |
|--------|----------|
| プロテイン・サプリ販売 | 月2〜10万円（小規模店） |
| ウェア・グッズ販売 | 月1〜5万円 |
| オンラインレッスン | 月2〜20万円（会員数×サブスク単価） |
| 法人・団体契約 | 月5〜30万円 |
| イベント・合宿 | 年数回・単発収益 |

## 3. 損益分岐点の計算

### 基本公式

```
損益分岐会員数（BEP）= 月間固定費 ÷ 会員1人あたり平均月額収益
```

### 計算例

```
月間固定費 = 130万円（家賃50万 + 人件費50万 + 光熱費15万 + その他15万）
会員1人あたり平均月額 = 8,000円

損益分岐会員数 = 1,300,000 ÷ 8,000 = 163名
```

この例では、**163名の月額固定会員**がいれば黒字化します。

### 損益分岐点の改善方法

| 方法 | 効果 |
|------|------|
| 平均単価を上げる | パーソナルトレーニング・オプション販売を増やす |
| 固定費を下げる | 賃料の低い物件選定、省人化（24h無人化） |
| 会員数を増やす | 紹介制度、SNS集客、開業前先行入会 |
| 解約率を下げる | 入会後のフォロー、コミュニティ形成 |

## 5. ユニットエコノミクスの考え方

### LTV（顧客生涯価値）の計算

```
LTV = 月額単価 × 平均継続月数

例: 8,000円 × 18ヶ月（1.5年継続）= 144,000円/人
```

### CAC（顧客獲得コスト）の計算

```
CAC = 月間広告・集客費 ÷ 新規入会者数

例: 100,000円 ÷ 10名 = 10,000円/人
```

### ユニットエコノミクスの健全性

```
LTV / CAC ≥ 3 が目安（ジムの場合は5以上が理想）

例: 144,000円 ÷ 10,000円 = 14.4 ← 健全な状態
```
