## 1. 国内フィットネス市場の規模と成長トレンド

### 市場規模（推計）
- 国内フィットネスクラブ市場は売上ベースで約5,000〜5,500億円規模（コロナ禍前水準）
- フィットネス参加人口は国内人口の約3〜4%程度とされており、欧米（10〜15%）と比較して普及余地が大きい
- コロナ禍（2020〜2021年）で一時大幅縮小したが、2022年以降は回復傾向
- 24時間ジム・パーソナルトレーニングジムの出店が特に顕著な成長を示している

### 成長ドライバー
1. **健康意識の高まり**: 生活習慣病予防・メタボ対策に対する個人意識の向上
2. **高齢化社会**: シニア層（60〜75歳）の運動需要が増加中。介護予防の観点から行政支援もある
3. **24時間ジムの普及**: 月額3,000〜5,000円台の低価格24時間ジムが若年層・会社員に浸透
4. **パーソナルトレーニング需要**: 効率的な結果を求める層が増加。月額3〜10万円帯の市場が拡大
5. **女性専用・ボクシング特化などニッチ特化型**: 差別化により大手チェーンとの競合を回避するモデルが増加

### 2027年に向けた市場予測
- AI・IoT を活用したスマートジム（体組成計自動記録、AIフォームチェック等）が普及し始める見込み
- アウトドアフィットネス・オンラインとのハイブリッドモデルが標準化される可能性
- 大手チェーンの多店舗展開が続く一方、地域密着型の小規模ジムの需要も維持される見込み

## 2. 顧客セグメント分析

### 主要顧客層の分類

#### セグメントA: 20〜40代 ダイエット・ボディメイク志向
| 属性 | 詳細 |
|------|------|
| 年齢 | 25〜45歳 |
| 性別 | 女性が中心（男性も一定数） |
| 目的 | 減量、体型維持、ウェディング・イベント前の短期集中 |
| 支払い意欲 | 月額5,000〜15,000円、または短期パーソナル |
| 離脱リスク | 高（目標達成後に退会する層が多い） |

#### セグメントB: 30〜50代 健康維持・ストレス解消層
| 属性 | 詳細 |
|------|------|
| 年齢 | 30〜55歳 |
| 性別 | 男女両方 |
| 目的 | 生活習慣病予防、運動習慣化、メンタルヘルス |
| 支払い意欲 | 月額7,000〜20,000円 |
| 離脱リスク | 低〜中（習慣化すると長期継続する傾向） |

#### セグメントC: 60〜75歳 シニア・介護予防層
| 属性 | 詳細 |
|------|------|
| 年齢 | 60〜75歳 |
| 性別 | 女性比率が高め |
| 目的 | 転倒予防、筋力維持、社交 |
| 支払い意欲 | 月額5,000〜12,000円 |
| 離脱リスク | 低（通う習慣が定着すると長く続ける） |

#### セグメントD: 20〜35歳 筋トレ・パフォーマンス志向（ガチ層）
| 属性 | 詳細 |
|------|------|
| 年齢 | 20〜35歳 |
| 性別 | 男性中心 |
| 目的 | 筋肥大、競技パフォーマンス向上、コンテスト出場 |
| 支払い意欲 | 月額3,000〜8,000円（設備重視・価格感度高め） |
| 離脱リスク | 低（施設・設備に満足なら継続。不満があれば即移籍） |

## 3. 立地選定の観点

### 商圏分析の基本
- ジムの主要顧客は施設から **半径2〜3km以内** に居住・勤務する人が中心
- 徒歩15分 or 自転車10分 or 車10分が通いやすさの目安

### 立地タイプ別の特徴

| 立地タイプ | 特徴 | 向いている業態 |
|-----------|------|---------------|
| 駅前・繁華街 | 集客力高、賃料高 | 小規模パーソナル、24h型 |
| 住宅街 | 地元密着、競合少なければ安定 | 総合型、シニア向け |
| オフィス街 | 昼・夜の需要、平日中心 | 短時間特化、ランチフィット |
| 郊外ロードサイド | 広い床面積確保しやすい、駐車場必須 | 総合型、設備充実型 |
| ショッピングモール内 | 通行量多、テナント条件要交渉 | 女性向け、ヨガ系 |

### 立地調査で確認すべき項目
- 半径2km以内の人口・世帯数（住民基本台帳・国勢調査で確認）
- 競合ジムの数・種類・価格帯
- 対象物件の建築用途（スポーツ施設として使用可能か）
- 駐車場の有無・近隣の駐輪・駐車場事情
- 物件の床荷重（器具設置のため1㎡あたり300〜500kgの荷重が必要な場合がある）
- 換気・排水設備（シャワー設置の場合）
