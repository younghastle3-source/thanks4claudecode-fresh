## 実行前提と検証規約

> **本セクションの規約は全 test_command に適用される。**

- **CWD**: 全 test_command はリポジトリルート（`/Users/kosei/thanks4claudecode-fresh`）を
  カレントディレクトリとして実行する。相対パスは全てリポジトリルート起点。
  **CWD を間違えると `$I`（正典）が開けず、awk が黙って空を返して偽 PASS になる**ため、
  正典を読む test_command には必ず `test -f "$I"` ガードと**抽出行数の期待値チェック**を入れてある
  （p1.5 / p1.6 / p_final.6。pm の自己点検記録 4-N8 で実際に踏んだ）。
- **シェル**: `bash` / `zsh` のどちらでも同じ結果になるよう記述する。
- **ネットワーク不要**: 検証は全てローカルで完結する（`gh api` を使わない）。
- **base_commit の固定**: 非改変検証（DW3）と回帰検証（DW12）は
  **`f39feb9`（新ブランチ作成時の HEAD）を起点**にする。Phase 途中でコミットしても判定がぶれない。
- **ファイル変数**: 全 test_command は先頭で以下を定義する（パスに非 ASCII を含むため必ずクォートする）。

  ```bash
  P=".claude/skills/久保田式提案書ノートmeikara-proposal/SKILL.md"
  I="plan/inputs-kubota-proposal-notebooklm-20260901.md"
  M=".claude/skills/久保田式マーケメソッドmeikara-marketing/SKILL.md"
  B=".claude/skills/久保田式ライティングmeikara-blog/SKILL.md"
  ```

- **区間抽出・H2 計数は必ずフェンス対応版を使う**（state.md の known_issues
  `playbook_section_extraction_needs_fence_awareness` 参照）。
  **本スキルは H2 区間の中にコピペ用のコードフェンスを2つ持つため、フェンス非対応版は必ず壊れる。**

  ```bash
  SEC() { awk -v h="$2" '/^`{3}/{fence=!fence; if(f)print; next} fence{if(f)print;next} $0 ~ h {f=1;next} /^## /{f=0} f' "$1"; }
  H2C() { awk '/^`{3}/{fence=!fence;next} !fence && /^## /{c++} END{print c+0}' "$1"; }
  ```

  `SEC` は**見出し行そのものを出力しない**。したがって見出し文字列に含まれる語
  （例: `ステップ8：週1回10分の追加運用` の `10分`）は**区間本文にも書かないと FAIL する**。
  これは意図した仕様であり、見出しだけ作って中身を空にする逃げ道を塞いでいる。
- **日本語・記号を含む固定文字列の照合は必ず `grep -qF` / `grep -cF`**（正規表現メタ誤爆の防止）。
- **表の行数は `grep -c '^|'` で数える。`grep -E '^| ... |'` は使わない**
  （`|` は ERE の選択演算子で空文字列にマッチし、検査が黙って無効化される。
  state.md の known_issues `playbook_table_verification_pipe_in_ere` 参照）。
- **git のパスは常に `git -c core.quotepath=false`**。付けないと非 ASCII パスが8進エスケープされる。
- **見出し文字列に半角スペースを含めない**（test_command が `for H in ...` で単語分割するため）。
  本 playbook で作る H2 は全て半角スペースを含まない文字列に設計済み（実測確認）。
- **変数をコマンド名として展開しない**（`G="git -c ..."; $G diff` は zsh で失敗する）。
- **`grep -vc` を空入力に対して実行しない**（空文字列が1行として数えられ偽 FAIL になる）。
  該当箇所は全て `if [ -z "$X" ]` でガードしている。
- **python3 は必ず1行で書く**（`test_command: |` ブロックがインデントされているため、
  複数行の heredoc / `-c` 文字列はインデントエラーを起こす）。
